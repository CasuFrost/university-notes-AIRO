\chapter{Wheeled Mobile Robots}
\section{Configuration Space}   
We can define a robot as a collection of $n_b$ bodies moving in an operative space, denoted $W$ and called the \textbf{workspace}. $W$ can be $\R^2$ (if the robot moves on a plane, like a planar 2R) as well as $\R^3$, if the robot moves in the space. For example, an elbow-type spatial manipulator is a system of $n_b=3$ rigid bodies moving in $W=\R^3$. A quadrotor is a single body ($n_b=1$) moving in the same workspace $W=\R^3$. 

To describe the complete pose of a planar 2R manipulator, we might use the position vector and roll-pitch-yaw angles for the two bodies, which requires a total of 12 parameters for the whole system, despite that, we know that 2 variables are enough to describe the whole configuration of the system.
\begin{boxdefinition}{Configuration}{}
The configuration of a robot is a \textbf{minimum} set of parameters that allows one to specify the posture\footnote{
    with posture, we indicate the position of all the points of the robot.
} of the robot in the workspace.
\end{boxdefinition}
The configuration of a robot can be defined in several ways, and a choice of a set of parameters is not unique, however, each robot always has a \textit{minimum number} of parameters. We usually denote $\q$ the configuration vector:\begin{equation}
    \q=\begin{pmatrix}
        q_1\\ \vdots\\ q_n 
    \end{pmatrix}
\end{equation}
in our context, it usually describes the Cartesian coordinates of a single body robot, or the angular coordinates of the body parts. The Cartesian coordinates have values in a Euclidean space, as $\R^2$ or $\R^3$, while the angular coordinates take values in a non-Euclidean space, such as the special orthogonal group $SO(3)$, the group of all the orthogonal $3\times 3$ matrices  with determinant $+1$, this group describes the orientation of a body in a 3D Euclidean space.
\begin{boxdefinition}{Configuration Space}{}
    The configuration space, usually denoted $\mathcal C$, is the set of all possible values of the configuration of a robot. The \textit{dimension} of $\mathcal C$ is the number $n$ of parameters (generalized coordinates) in $\q$.
\end{boxdefinition}
Let's see an example: consider a disk robot that moves on a plane, that can also rotate about its vertical axis to point towards a desired direction, shown in Figure \ref{disc_tick}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.2\textwidth ]{images/disc_tick.eps}
    \caption{Disc robot with a tick in $\R^2$.}
    \label{disc_tick}
\end{figure}
Its configuration is given by two Cartesian coordinates $(x,y)$ and a value $\varphi\in SO(2)$ representing the angle between the tick and the horizontal axis. Hence, its configuration space is:\begin{equation}
    \mathcal C = \R^2\times SO(2)=SE(2)
\end{equation}
and it's not Euclidean, despite being called \textit{special Euclidean group}. A polyhedral robot that can freely move in space is described by three Cartesian coordinates $(x,y,z)$ and three roll-pitch-yaw angles $(\alpha,\beta,\gamma)$ describing its orientation, hence the configuration space is $SE(3)$:
\begin{equation}
    \mathcal C = \R^3\times SO(3)=SE(3).
\end{equation}
We have seen in previous courses of robotics that the number of generalized coordinates of an  $n$-link serial manipulator is exactly $n$.
\subsection{Topology of a Space}
We are interested in describing the configuration space of a given manipulator, since it's not Euclidean (in most cases), we would like to have an idea of how to navigate this space. Before defining formally what a \textit{topology} is, we give some examples.\bigskip 

A 2R planar manipulator can be described by two angles, hence two values in $SO(2)$, so its configuration space is\begin{equation}
    \mathcal C = SO(2)\times SO(2)=SO(2)^2
\end{equation}
Let's try to represent graphically $\mathcal C$. We might represent a configuration as a point in the Cartesian plane:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/configuration_2R.eps}
\end{figure}
The problem of this representation is that different configurations $\q\in \mathcal C$ map to the same posture of the robot in $W$, as shown in Figure \ref{not_injective}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/configuration_2R_notInjective.eps}
    \caption{Different configurations map to the same posture.}
    \label{not_injective}
\end{figure}
To overcome this problem, we might try to represent the configuration space as a square in the plane $[0,2\pi)\times [0,2\pi)$:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.3\textwidth ]{images/2pi_times_2pi.eps}
\end{figure}
This representation also presents a problem: The distance between two configurations in $\mathcal C$ does not represent the true distance between two postures in the workspace: Two very distant configurations $\q_a$ and $\q_b$ in $\mathcal C$ can be mapped to two very close postures in $W$:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth ]{images/a_b_distance.pdf}
\end{figure}
This representation is said to be \textbf{not topologically correct}. To give a correct representation of $\mathcal C$ we need to introduce the concept of \textbf{manifold}. We will not give a formal and complete definition (as given in topology or differential geometry courses).
\begin{boxdefinition}{Manifold (loose definition)}{}
    A \textbf{manifold} is a topological space that is locally homeomorphic to $\R^n$.
\end{boxdefinition}
As we should know from previous robotics courses, the configuration space of a 2R is a torus, a manifold that is locally homeomorphic to $\R^2$, and can be visualized in the 3D space through an embedding as shown in Figure \ref{torus}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/torus.pdf}
    \caption{3D representation of a torus.}
    \label{torus}
\end{figure}
\subsection{Distance in the Configuration Space}
\begin{boxdefinition}{Distance in the Configuration Space}{distance}
    Given a configuration space $\mathcal C$, the \textbf{distance} is a function $d:\mathcal C\times \mathcal C \to \R$ such that, for each $\q_a,\q_b,\q_c$ in $\mathcal C$ we have:\begin{align}
        &d(\q_a,\q_b)\ge 0\\ 
        &d(\q_a,\q_b)=0\iff \q_a=\q_b\\
        &d(\q_a,\q_b)=d(\q_b,\q_a)\\
        &d(\q_a,\q_b)\le d(\q_a,\q_c)+d(\q_c,\q_b).
    \end{align}
\end{boxdefinition}
\noindent We know how the distance between two vectors $\mathbf u,\mathbf v$ in $\R^n$ is given by $\|\mathbf u - \mathbf v\|$. The distance between two points is the \textit{shortest path} between them, for a general manifold, this path is not always a straight line as for the Euclidean space.
\begin{boxdefinition}{Geodesic}{}
    For a general manifold, the shortest path between two points is called \textbf{geodesic}, and the distance between the points is the length of their geodesic.
\end{boxdefinition}
\noindent For example, consider the shortest path between two points on the surface of a sphere (a 2-manifold): the geodesic lies on the great circle (the circle with the biggest radius that passes through the two points), as shown in Figure \ref{sphere_geodesic}. In general, for an arbitrary manifold, it is hard to determine the geodesic between two points.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.25\textwidth ]{images/geodesic_sphere.eps}
    \caption{Geodesic on a sphere.}
    \label{sphere_geodesic}
\end{figure}
In the robotics context, we want to define the distance between two postures of a robot, this distance is defined in the workspace $W$, and to define that we don't need to specify directly the distance between their respective configurations in $\mathcal C$ (it would be harder to find the geodesic on $\mathcal C$).\bigskip 

\noindent Given a robot and its current configuration $\q$, we can define two functions:\begin{itemize}
    \item $B(\q)$ is a function that assigns to $\q$ the volume (exact region) of the workspace that the robot occupies when it is in the configuration $\q$, so it assigns to each configuration  $\q\in\mathcal C$ a set of points in $\R^3$.
    \item $\mathbf p(\q)$ is a function that assigns to $\q$ the exact position of a certain point of the robot when it's in the configuration $\q$.
\end{itemize}
For example, we might let $\mathbf p$ be the center of mass of the manipulator, and observe how it changes by varying $\q\in \mathcal C$. One simple way to define a distance metric is to consider the maximum Euclidean distance between two points of the manipulator in two different configurations:\begin{equation}\label{displacement_metric}
    d(\q_a,\q_b)=\max_{\mathbf p\in \text{robot}}\|\mathbf p(\q_a)-\mathbf p(\q_b)\|
\end{equation}
This distance is called \textbf{displacement metric}. Notice how in the definition we are writing $\mathbf p \in \text{robot}$, by letting robot be the set of all the points in the structure of the manipulator, which clearly depend on the current configuration. This kind of metric works under the assumption that, if the region occupied by the robot is similar in two different postures, then the distance between their respective configurations is small:\begin{equation}
    B(\q_a)\simeq B(\q_b)\implies d(\q_a,\q_b)\simeq 0.
\end{equation}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/displacement_metric.eps}
\end{figure}
To compute the distance in Equation \eqref{displacement_metric}, we should check each point of the robot, and in general this is an uncountably infinite set. If the links are polygonal shapes, the problem becomes finite, since it is possible to find the maximum distance between any pair of polytopes in the three dimensional space. 

A more computationally feasible approach is to check only for a finite set of points in the robot structure, called \textbf{control points}. Let \begin{equation}
    P=\{\mathbf p_1,\mathbf p_2,\dots, \mathbf p_c\}
\end{equation}
be a set of $c$ points of the robot (in general, they all depend on the configuration $\q$). We compute the distance between two postures in the following way:\begin{equation}\label{cp_metric}
    d(\q_a,\q_b)=\max_{1\le i \le c}\|\mathbf p_i(\q_a)-\mathbf p_i(\q_b)\|.
\end{equation}
Not all the points of a robot are feasible control points, for example, the base of a manipulator usually doesn't change with the configuration. $P$ is a set of \textit{proper control points} if the function $d$ as defined in Equation \eqref{cp_metric} satisfies the properties of a distance given in Definition \ref{def:distance}.
\begin{boxobservation}{Approximation for Local Motion}{}
Since a manifold is locally homeomorphic to $\R^n$, for sufficiently close configurations we can approximate the distance on the manifold (assuming it is smooth) with the Euclidean distance.
\end{boxobservation}
\begin{boxobservation}{Prismatic Joints}{}
The configuration space of a robot with \textit{only} prismatic joints is Euclidean.
\end{boxobservation}
\section{Mechanics of Mobile Robots}
The main sources of movement for a mobile robot are:\begin{itemize}
    \item Wheels: wheeled robots usually consist of one single rigid body, with the wheels in contact with ground.
    \item Feet: legged robots, several rigid bodies articulated through joints.
\end{itemize}
The wheels are in contact with the ground, and this introduces some constraints. Each wheel defines a point of contact with the ground, we call the \textbf{support polygon} the convex hull of all the contact points. A wheeled robot is in \textbf{static balance} if the projection on the ground of its center of mass, falls inside the support polygon. Of course a robot must be balanced in order to not fall to the ground.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/balance.pdf}
\end{figure}
The convex hull of two points is a line segment, hence a robot with only two wheels can't be easily balanced in a static fashion.\bigskip

\noindent There are three main types of wheels:\begin{itemize}
    \item \textbf{Fixed Wheels}: They have a fixed orientation: Can roll but can't steer on their $z$-axis (see Figure \ref{fixed_wheel}). They are usually actuated, if passive, are used for balance and offer a contact point.
    \item \textbf{Steerable Wheels}: They can steer and are used for orientation, hence they are typically active (e.g. the front wheels of a car).
    \item \textbf{Caster Wheels}: They have a variable orientation but they are typically not actuated. Their axis of orientation are not aligned, this property makes the wheels align automatically with the direction of motion, hence they are ``invisible'' kinematically, but offer a contact point.
\end{itemize}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.65\textwidth ]{images/wheels.png}
    \caption{Fixed, steerable and caster wheels.}
    \label{fixed_wheel}
\end{figure}
\subsection{Main Kinematic Structures}
The simplest wheeled robot that we can have is the \textbf{differential drive} robot: it uses two aligned fixed wheels that are independently actuated, and one caster wheel added for balance. The \textbf{synchro-drive} mobile robots have three steerable wheels and two actuators: one controls simultaneously the orientation of all the wheels, and the other rolls them together. The base over the wheels hence will never change orientation. This type of configuration is preferable when the body to move is particularly heavy.
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth ]{images/structures.eps}
\end{figure}
The tricycle has two fixed wheels in the back and one actuated steerable wheel in the front, the car-like is similar, but with two steerable wheels.\bigskip

Consider the following path taken by a car-like robot:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/differential.eps}
\end{figure}
In the same time interval, the wheels on the outer path travels a longer distance with respect to the wheels on the inner path, hence their rotation speed must be higher. In order to avoid using two distinct actuators for the front wheels we use a device called \textbf{differential}.
\begin{boxdefinition}{Differential}{}
   A mechanical differential is a gear assembly (usually using bevel or planetary gears) connected to a single drive motor. It splits power to two wheels on the same axle while allowing them to rotate at different speeds. When a robot with a single motor turns, the outside wheel must travel a larger arc than the inside wheel. The differential lets the wheels spin at their own natural speeds, preventing tire slip, scrubbing, and mechanical strain on the drivetrain.
\end{boxdefinition}

\section{Constraints and Mobility}
The presence of the wheels in contact with the ground introduces a series of \textit{geometric} and \textit{kinematic} constraints. We will also see the relationship between these two types of constraints and the implications in mobility.
\subsection{Geometric Constraints}
We have seen how the configuration $\q$ is in general a point of a manifold $\mathcal C$, that is locally homeomorphic to $\R^n$, with $n$ being the dimensionality of the configuration space $\mathcal C$.
We will focus on equality time-invariant constraints. All the geometric constraints are expressed in the following form:\begin{equation}
    h(\q)=0
\end{equation}
and they depend only on the configuration. Usually we have $k<n$ geometric constraints, and they are reflected in the degrees of freedom of a robot:\begin{align}
   &h_1(\q)=0\\
   &\vdots\\ 
   &h_k(\q)=0.
\end{align}
If the configuration space is a 2-manifold, one single geometric constraint will reduce the degrees of freedom of the robot, constraining it to move on a 1-dimensional manifold (a curve).
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/1-constraint.eps}
    \caption{If the configuration space is $\R^2$, one constraint will let the configurations lie on a curve in the plane.}
\end{figure}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/1-constraint_3D.pdf}
    \caption{If the configuration space is $\R^3$, one constraint will let the configurations lie on a surface in the space.}
\end{figure}
In general, a robot with a configuration space that is an $n$-manifold with $k$ independent geometric constraints, will move on an $(n-k)$-manifold. Instead of using the vector $\q$, we can reduce the number of coordinates in many ways, like for one constraint:\begin{equation}
    h(\q)=0
\end{equation}
we can solve the equation for a coordinate $q_i$:\begin{equation}
    q_i=\tilde h(q_1,\dots,q_{i-1},q_{i+1},\dots, q_n).
\end{equation}
For example, consider a 2 degrees of freedom robot with the following constraint:\begin{equation}
    q_1^2+q_2^2=1
\end{equation}
the configuration space is limited to the unit circle in $\R^2$ (1-manifold), we solve the constraint for $q_2$:\begin{equation}
    q_2=\pm\sqrt{1-q_1^2}.
\end{equation}
Actually this is not a good way to choose a coordinate, since the $\pm$ term prevents us from assigning a single value of $q_2$ to each value of $q_1$, requiring a local resolution. For this example of the circle it is better to use the arc length $s\in[0,2\pi)$ as the single coordinate.
\begin{boxobservation}{Sub-Manifold}{}
    If the configuration space $\mathcal C$ is an $n$-manifold, the $k$ constraints define a $(n-k)$-manifold embedded in $\mathcal C$, that we also call sub-manifold.
\end{boxobservation}
\subsection{Kinematic Constraints}
A kinematic constraint is local, it prevents the configuration from moving towards some directions. A general constraint of this kind is in the form:\begin{equation}
    a(\q,\dq)=0
\end{equation}
it depends on the state of the robot. In every given configuration $\q^*$, we can immediately infer from $a(\q^*,\dq)=0$ which velocities are allowed. All the relevant kinematic constraints in the robotic domain are in \textbf{Pfaffian form}:\begin{equation}
   \mathbf a^T(\q)\dq=0
\end{equation}
with $\mathbf a$ being an $n$ dimensional vector that depends on the configuration. The Pfaffian form expresses a condition of orthogonality: in a given configuration the velocity must be orthogonal to the vector $\mathbf a$. More kinematic constraints can be arranged in matrix form:\begin{equation}
    \begin{pmatrix}
        \mathbf a_1^T(\q)\\
        \mathbf a_2^T(\q)\\ \vdots\\ 
        \mathbf a_k^T(\q)
    \end{pmatrix}\dq=\mathbf 0\implies A(\q)\dq=\mathbf 0\implies \dq\in\mathcal N(A).
\end{equation}
The admissible velocities are the ones that lie in the null space of $A$\footnote{
    Sometimes, we let the dependencies of a term implicit.
}, hence they lie in a linear space. 
\begin{boxobservation}{Relationship Between Geometric and Kinematic Constraints}{}
    Any geometric constraint implies a kinematic constraint.
\end{boxobservation}
Consider a geometric constraint\begin{equation}
    h(\q)=0
\end{equation}
this constraint must be satisfied as the time goes on, hence its derivative should also satisfy the following relation:\begin{equation}
    \dot h(\q)=0
\end{equation}
by applying the chain rule:\begin{equation}
    \dot h(\q)=\frac{\partial h}{\partial \q}\dq =0
\end{equation}
$\frac{\partial h}{\partial \q}$ is a row vector, the transpose of the gradient of $h$:\begin{equation}
    (\nabla_\q h)^T\dq=0
\end{equation}
this is exactly a kinematic constraint in Pfaffian form. The gradient of $h$ evaluated on a point is the vector orthogonal to the manifold on which the configuration is constrained to move, hence the resulting kinematic constraint is preventing the robot from going out of the sub-manifold defined by the geometric constraints.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.45\textwidth ]{images/tangent_plane.eps}
    \caption{The admissible velocities are the ones that lie on the tangent space of the sub-manifold in the given configuration.}
\end{figure}
We have seen how a geometric constraint always implies a kinematic one. The opposite is not generally true, consider a generic kinematic constraint:\begin{equation}
    \mathbf a^T(\q)\dq=0
\end{equation}
this implies a geometric constraint if there exists a function $h(\q)$ such that \begin{equation}\label{holonomic}
    \nabla_\q h=\mathbf a
\end{equation}
hence the constraint defined by $\mathbf a(\q)$ should be \textit{integrable}.
\begin{boxdefinition}{Holonomic Constraint}{}
    An integrable kinematic constraint is called \textbf{holonomic}, and it defines a geometric constraint.
\end{boxdefinition}
What conditions determine if a constraint is integrable or not? In general, the conditions are stated in the \textit{Frobenius Theorem}, we will not discuss this result, which belongs to the domain of differential geometry. We will determine if a given constraint is holonomic or not by a different way.

Consider the following kinematic constraint for a 2-dimensional robot:\begin{equation}
     q_1\dot q_1+q_2\dot q_2=0
\end{equation}
is this integrable? The answer is yes. The resulting geometric constraint is\begin{equation}
    q_1^2+q_2^2=c, \quad c>0.
\end{equation}
In general, in Equation \eqref{holonomic} we can add a scalar integrating factor that depend on the configuration:
\begin{equation}
    \frac{\partial h}{\partial \q}=\gamma(\q)\mathbf a^T(\q)
\end{equation}
since the right-hand side is zero, $\gamma$ can be dropped.
\subsection{Non-Holonomic Constraints}\label{sec:nonhol}
A non-holonomic constraint defines a local limitation, it stops the robot from moving towards a certain direction when it is in that specific configuration, it does not prevent the robot from reaching a configuration by following an allowed path. The simplest example of a system with a non-holonomic constraint is a rolling disk.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/rolling_disk.eps}
\end{figure}
The configuration is given by the vector $\begin{pmatrix}
    x&y&\theta
\end{pmatrix}^T$, $\theta$ is its orientation with respect to the horizontal axis. It is clear that the disk in pure rolling (no slippage) can move \textit{only} in the direction that is pointing (by rolling), hence can't move laterally. This constraint is expressed as follows:\begin{equation}
    \sin\theta\dot x-\cos\theta \dot y = 0
\end{equation}
or in vector form:\begin{equation}
    \begin{pmatrix}
        \sin\theta& -\cos\theta& 0 
    \end{pmatrix}\begin{pmatrix}
   \dot x\\\dot y\\\dot \theta
\end{pmatrix}=0
\end{equation}
$\mathbf{n}^T=\begin{pmatrix}
        \sin\theta& -\cos\theta 
\end{pmatrix}$
is the vector \textit{normal} to the direction. Any velocity that has a component on the line spanned by $\mathbf{n}$ is not allowed.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/rolling_disk2.eps}
\end{figure}
This constraint does not imply any global limitation, any configuration is still reachable, hence it is a non-holonomic constraint. To prove this, instead of using the Frobenius theorem, we give a non-formal proof by showing that, for any pair of configurations $\q_s,\q_g$, there exists a trajectory in the configuration space that connects these two configurations without violating the kinematic constraint. Let\begin{equation}
    \q_s=\begin{pmatrix}
        x_s\\y_s\\\theta_s
    \end{pmatrix},\quad \q_g=\begin{pmatrix}
        x_g\\y_g\\\theta_g
    \end{pmatrix}.
\end{equation}
\begin{enumerate}
    \item $\dot \theta$ is not constrained, first of all we move the orientation from $\theta_s$ to $\theta^*$, where $\theta^*$ is defined as the angle such that\begin{equation}
        \begin{pmatrix}
        \sin\theta^*& -\cos\theta^*
    \end{pmatrix}\begin{pmatrix}
    x_g-x_s\\y_g-y_s
\end{pmatrix}=0.
    \end{equation}
    \item Then, we can move on the direction $\begin{pmatrix}
    x_g-x_s&y_g-y_s
\end{pmatrix}^T$, in this way we can reach the desired position $\begin{pmatrix}
    x_g&y_g
\end{pmatrix}^T$.
    \item At the end, we move the orientation from $\theta^*$ to $\theta_g$.
\end{enumerate}
This is called \textbf{universal maneuver}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/universal_man.pdf}
    \caption{The universal maneuver in five steps.}
\end{figure}
There are no global mobility limitations. We can also observe this trajectory in the configuration space:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/manuvre_C_space.eps}
\end{figure}
Note how for simplicity we have drawn the configuration space as Euclidean. Of course it is not Euclidean because $\theta\in SO(2)$.
\section{Kinematic Models}
We have seen how  the kinematic constraints are defined in Pfaffian form as $A(\q)\dq=\mathbf 0$, with $A$ being a $k\times n$ matrix. We are interested in finding a basis for the null space of $A(\q)$:\begin{equation}
    \mathcal N(A(\q))=\text{span}\left\{ 
        \mathbf g_1(\q),\mathbf g_2(\q),\dots,\mathbf g_m(\q)
    \right\}
\end{equation}
$\mathcal N(A(\q))$ has dimension $m:=n-k$. Each vector $\mathbf g_i(\q)$ of the base is a vector field on $\mathcal C$ with values in $\R^n$, any admissible velocity is a linear combination of the vectors in the base:\begin{equation}
    \dq=\sum_{i=1}^m u_i\mathbf g_i(\q)
\end{equation}
we can write any admissible velocity in compact form by using an $m$ dimensional vector $\mathbf u$:\begin{equation}
    \dq=\underbrace{\begin{pmatrix}
        | &|&&|\\
        \mathbf g_1(\q)&\mathbf g_2(\q)&\dots&\mathbf g_m(\q)\\
        | &|&&|
    \end{pmatrix}}_{G(\q)}\underbrace{\begin{pmatrix}
    u_1\\ \vdots\\ u_m
    \end{pmatrix}}_{\mathbf u}
\end{equation}
the \textbf{kinematic model} is:\begin{equation}
    \dq=G(\q)\mathbf u
\end{equation}
with $\mathbf u$ being a velocity-level quantity. We can see the model as a dynamical system, with $\q$ being the $n$-dimensional state vector and $\mathbf u$ the $m$-dimensional input vector, of course it is a nonlinear system due to $G(\q)$ that depends (in general) nonlinearly on $\q$.
This system satisfies the \textbf{driftless property}:\begin{equation}
    \mathbf u = \mathbf 0 \implies \dq=\mathbf 0
\end{equation}
it does not have a free evolution. The kinematic model is not unique, since we can select a different choice for the basis vectors $\mathbf g_1,\dots, \mathbf g_m$, all the bases are equivalent for the description of the system, but the interpretation of the vector $\mathbf u$ depends on the choice of the basis. We can interpret $\mathbf u$ as the ``virtual'' velocities in the kinematically constrained configuration space.\bigskip

Now we want to observe the differences between a kinematically constrained robot and an unconstrained robot. Consider an open-chain manipulator with revolute joints, with $\q$ being the DH frames. This choice of coordinates makes the manipulator free from any constraint, the configuration can ``fly'' in the configuration space, any joint velocity $\dq$ is always admissible, hence its kinematic model is\begin{equation}
    \dq=\mathbf u.
\end{equation}
This is a simple integrator, we can impose any joint velocity. For a robot with non-holonomic constraint this does not hold. The kinematic model is not a simple integrator since it has a \textit{filtering} component given by the matrix $G(\q)$, the vector $\mathbf u$ does not represent directly the joint velocity, but is called \textbf{pseudo velocity}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/constrained_vs_unconstrained.eps}
\end{figure}
\noindent Let's discuss about controllability of the constrained model. The controllability of a system can be proved formally through nonlinear control theory, or constructively, by the definition of a universal maneuver (as we did in the previous section).
\begin{boxdefinition}{Controllability}{}
    The kinematic model of a manipulator is controllable if any desired state $\q$ of the configuration space can be reached.
\end{boxdefinition}
A holonomic constraint defines a geometric constraint that prevents the robot from accessing a specific region in the configuration space, hence a robot with geometric constraints is never controllable. By this reasoning, there is a 1-to-1 correspondence between controllability and the presence of holonomic constraints.
\begin{boxobservation}{}{}
    The kinematic model of a robot is controllable \textbf{if and only if}  the set of kinematic constraints is non-holonomic.
\end{boxobservation}
\subsection{The Unicycle Model}
Let's define the kinematic model of a unicycle, that is equivalent to the rolling disk seen in Section \ref{sec:nonhol}. It has one kinematic constraint, the pure rolling condition imposes that:\begin{equation}
    \sin\theta\dot x-\cos\theta\dot y=0.
\end{equation}
It says that the velocity of the contact point must be aligned with the \textit{sagittal axis} defined by $\theta$, i.e. it can't have components on the zero-motion line. In matrix form the constraint is:\begin{equation}
    \underbrace{\begin{pmatrix}
    \sin\theta&-\cos\theta&0
    \end{pmatrix}}_{A(\q)}\begin{pmatrix}
        \dot x\\ \dot y\\ \dot\theta 
    \end{pmatrix}=0.
\end{equation}
The dimension of $\mathcal N(A)$ is 2, hence we will have a 2-dimensional vector of the pseudo velocity.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/unicycle.eps}
\end{figure}
\noindent A basis for the null space of $A$ is the following:\begin{equation}
    \mathbf g_1(\q)=\begin{pmatrix}
        \cos\theta\\\sin\theta\\ 0
    \end{pmatrix},\quad 
     \mathbf g_2(\q)=\begin{pmatrix}
       0\\0\\1
    \end{pmatrix}
\end{equation}
the kinematic model is\begin{equation}
  \dq=  G(\q)\mathbf u=\begin{pmatrix}
         \cos\theta&0\\\sin\theta&0\\ 0&1
    \end{pmatrix}\begin{pmatrix}
       u_1\\ u_2
    \end{pmatrix}\implies\begin{cases}
        \dot x = \cos\theta u_1\\ 
        \dot y = \sin\theta u_1\\ 
        \dot\theta = u_2
    \end{cases}.
\end{equation}
$u_1$ is the scalar velocity along the sagittal axis
\begin{equation}
    u_1=\pm\sqrt{\dot x^2+\dot y^2}
\end{equation}
while $u_2$ is exactly $\dot\theta$. We rename these quantities:\begin{align}
    &v=u_1\\ &\omega=u_2
\end{align}
$v$ is related to the rolling velocity $\omega_{\text{roll}}$ and the radius of the wheel:\begin{equation}
    v=\omega_{\text{roll}}\cdot r.
\end{equation}
We can rewrite the kinematic model by splitting the cartesian part from the angular one:\begin{equation}
    \dq=\begin{pmatrix}
        \cos\theta\\\sin\theta\\0 
    \end{pmatrix}v+\begin{pmatrix}
        0\\0\\1 
    \end{pmatrix}\omega.
\end{equation} 
Is this model controllable? Yes, we already proved for the rolling disk that a universal maneuver exists.\bigskip

What are the real world robots that are kinematically and mechanically equivalent to the unicycle? First of all the differential drive, since it can rotate along its vertical axis, and move in the cartesian plane only towards its sagittal axis (it can't slide laterally). It has two actuated wheels, of radius $r$ and rolling velocities $\omega_R,\omega_L$. Its cartesian velocity $v$ is given by the average angular velocity of the two wheels:\begin{equation}
    v=r\frac{\omega_R+\omega_L}{2}
\end{equation}
while its angular velocity is given by the difference:\begin{equation}
    \omega=(\omega_R-\omega_L)\frac{r}{d}
\end{equation}
where $d$ is the distance between the contact points of the wheels.\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/diff_drive.eps}
\end{figure}
The other robot that is equivalent to the unicycle is the synchro-drive, it has two motors equipped with a pulley and belt mechanism, one controls the orientation of all the wheels, the other the rolling speed, hence these motors directly controls $v$ and $\omega$, where $v$ is relative to the velocity of the geometric center of the three contact points.

\section{Nonlinear Controllability}
Let's discuss about the controllability of a nonlinear \textit{driftless} system:\begin{equation}\label{driftless_system}
    \dot{\mathbf x}=\sum_{i=1}^m\mathbf g_i(\mathbf x)u_i 
\end{equation}
with $\mathbf g_i:\R^n\rightarrow\R^n$ being a vector field and $u_1,\dots,u_m$ the inputs. In this general discussion we use the symbol $\mathbf x$ to denote the state of our system, despite we usually use $\q$ (in the robotics domain).
\begin{boxdefinition}{Controllability of a Nonlinear System}{}
    The system in Equation \eqref{driftless_system} is \textbf{controllable} if, for any pair of states $(\mathbf x_i,\mathbf x_f)$, with $\mathbf x(0)=\mathbf x_i$, there exists a profile $\tilde{\mathbf u}(t)$ for the inputs in $t\in [0,T]$ such that the closed loop system will reach at the end the state $\mathbf x(T)=\mathbf x_f$.
\end{boxdefinition} 
In linear systems, the controllability is guaranteed when the controllability matrix of the system have full rank, we will see how also for the nonlinear case, the controllability test will result in the derivation of the rank of a matrix.
\begin{boxdefinition}{Lie Brackets}{}
    Let $\mathbf g_1,\mathbf g_2$ be two vector fields on $\R^n$. The \textbf{Lie Bracket} of these vector fields is the new vector field $[\mathbf g_1,\mathbf g_2]$ defined as follows:\begin{equation}
        [\mathbf g_1,\mathbf g_2](\mathbf x)=\frac{\partial \mathbf g_2}{\partial \mathbf x}\mathbf g_1(\mathbf x)-\frac{\partial \mathbf g_1}{\partial \mathbf x}\mathbf g_2(\mathbf x).
    \end{equation}
\end{boxdefinition}
\noindent Let's see an example in $\R^3$:\begin{equation}
    \mathbf g_1=\begin{pmatrix}
        \cos x_3\\\sin x_3\\ 0 
    \end{pmatrix},\quad\mathbf g_2=\begin{pmatrix}
        0\\0\\ x_1 
    \end{pmatrix}
\end{equation}
the Jacobians are:\begin{equation}
    \frac{\partial  \mathbf g_1}{\partial \mathbf x}=\begin{pmatrix}
        0&0&-\sin x_3\\ 
        0&0&\cos x_3\\ 
        0&0&0
    \end{pmatrix},\quad 
    \frac{\partial  \mathbf g_2}{\partial \mathbf x}=\begin{pmatrix}
        0&0&0\\ 
        0&0&0\\ 
        1&0&0
    \end{pmatrix}
\end{equation}
hence:\begin{equation}
     [\mathbf g_1,\mathbf g_2](\mathbf x)=\begin{pmatrix}
        x_1\sin x_3\\ 
        -x_1\cos x_3 \\ 
        \cos x_3
     \end{pmatrix}
\end{equation}
notice how in this case $[\mathbf g_1,\mathbf g_2]$ is linearly independent from $\mathbf g_1,\mathbf g_2$. Now we want to give an \textit{interpretation} of the Lie bracket. Consider the following 2-inputs system:\begin{equation}
    \dot{\mathbf x}=\mathbf g_1(\mathbf x)u_1+\mathbf g_2(\mathbf x)u_2
\end{equation}
the interpretation of the Lie brackets can be defined by considering the following time profilo for $u_1,u_2$ in $t\in [0,4\varepsilon]$:
\begin{align}
    &(u_1,u_2)=(1,0)\quad  t\in[0,\varepsilon]\\ 
    &(u_1,u_2)=(0,1)\quad  t\in[\varepsilon,2\varepsilon]\\ 
    &(u_1,u_2)=(-1,0)\quad t\in[2\varepsilon,3\varepsilon]\\ 
    &(u_1,u_2)=(0,-1)\quad t\in[3\varepsilon,4\varepsilon].
\end{align}\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/lie_inputs.eps}
\end{figure}
After applying this input profile the system will be in the state:\begin{equation}
    \mathbf x(4\varepsilon)=\mathbf x(0)+\underbrace{\varepsilon^2[\mathbf g_1,\mathbf g_2](\mathbf x(0))+O(\varepsilon^3)}_{\text{displacement}}.
\end{equation}
This results affirms that the displacement will be in the direction of the Lie bracket, with an error given by the term $O(\varepsilon^3)$: if $\varepsilon\rightarrow 0$, the terms in $O(\varepsilon^3)$ will vanishes faster, and the displacement will be defined mainly by  $\varepsilon^2[\mathbf g_1,\mathbf g_2](\mathbf x(0))$.
\begin{boxobservation}{}{}
    The Lie bracket gives the direction of the displacement of that particular input sequence.
\end{boxobservation} 
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/lie_bracket_direction.eps}
\end{figure}
\begin{boxdefinition}{Distribution}{}
    Let $\mathcal C$ be a smooth manifold. A \textit{Distribution} $\Delta$ is a map that assign at each point $\mathbf x\in \mathcal C$ a subspace of the tangent space $T_\mathbf x\mathcal C$:\begin{equation}
        \Delta : \mathbf x \mapsto \Delta(\mathbf x)\subset T_\mathbf x\mathcal C.
    \end{equation}
\end{boxdefinition}
The tangent space in each point of a $n$-manifold have at most dimension $n$, hence the dimension of the subspace $\Delta (\mathbf x)$ can be at most $n$ (depending on the point on where we are evaluating $\Delta$). For a system in the form \eqref{driftless_system}, the \textit{input distribution} is defined as follows:\begin{equation}
    \Delta(\mathbf x)=\text{span}\{\mathbf g_1(\mathbf x),\mathbf g_2(\mathbf x),\dots,\mathbf g_m(\mathbf x)\}.
\end{equation}
The controllability problem for nonlinear systems is strictly correlated to a particular distribution, called the \textbf{accessibility distribution} $\Delta_{\mathcal A}$, defined as follows:\begin{equation}
    \Delta_{\mathcal A}(\mathbf x)=\text{span}\{\mathbf g_1(\mathbf x),\dots,\mathbf g_m(\mathbf x),\dots,[\mathbf g_i,\mathbf g_j](\mathbf x),\dots,[\mathbf g_i,[\mathbf g_j,\mathbf g_k]](\mathbf x),\dots\}.
\end{equation}
Let's break it down:\begin{itemize}
    \item With $[\mathbf g_i,\mathbf g_j]$  we denote all Lie brackets given by all the possible pairs of vector fields for $1\le i,j\le m$. These are also called first order Lie brackets.
    \item Each pair $\mathbf g_i,\mathbf g_j$ (with $i\ne j$) appears only one time, we don't have to add also $[\mathbf g_j,\mathbf g_i]$ since it is equal to $-[\mathbf g_i,\mathbf g_j]$ (they are linearly dependent, the span needs only one of them).
    \item $[\mathbf g_i,[\mathbf g_j,\mathbf g_k]]$ for $1\le i,j,k\le m$ are the second order Lie brackets.
    \item This nested definition can continue, for example the third order Lie brackets are in the form  $[\mathbf g_i,[\mathbf g_j,[\mathbf g_k,\mathbf g_h]]]$.
    \item The definition of $\Delta_{\mathcal A}$ consider all the possible combination of Lie brackets, for each possible order, up to infinity.
\end{itemize}
Of course $\Delta_{\mathcal A}(\mathbf x)$ can have different dimension depending on $\mathbf x$, for a nonlinear system, to assert controllability, is \textit{mandatory} that $\Delta_{\mathcal A}(\mathbf x)$ have the same dimension on every single $\mathbf x\in\mathcal C$.
\begin{boxdefinition}{Dimension of a Distribution}{}
    The distribution $\Delta_{\mathcal A}$ have dimension $k$ if $\dim\Delta_{\mathcal A}(\mathbf x)=k$ for every $\mathbf x\in\mathcal C$. In that case we write $\dim\Delta_{\mathcal A}=k$.
\end{boxdefinition}
\noindent The nonlinear controllability problem is fully described by the following result.
\begin{boxtheorem}{Accessibility Criterion}{}
    A nonlinear system of the form \eqref{driftless_system} with an $n$-dimensional state vector is controllable \textit{if and only if} its accessibility distribution have dimension $n$:\begin{equation}
        \dim\Delta_{\mathcal A}=n.
    \end{equation}
\end{boxtheorem}
So in practice, we have to build the matrix $M$ which the columns are the vector fields $\mathbf g_i$ and all their Lie brackets, and check if the rank is full.\begin{equation}
    M(\mathbf x)=\begin{pmatrix}
          |& &| & &| & &|&\\
        \mathbf g_1(\mathbf x)&\dots&\mathbf g_m(\q)&\dots &[\mathbf g_i,\mathbf g_j](\mathbf x)&\dots&[\mathbf g_i,[\mathbf g_j,\mathbf g_k]](\mathbf x)\dots\\
         |& &| & &| & &|&
    \end{pmatrix}
\end{equation}
