\chapter{Wheeled Mobile Robots}
\section{Configuration Space}   
We can define a robot as a collection of $n_b$ bodies moving in an operative space, denoted $W$ and called the \textbf{workspace}. $W$ can be $\R^2$ (if the robot moves on a plane, like a planar 2R) as well as $\R^3$, if the robot moves in the space. For example, an elbow-type spatial manipulator is a system of $n_b=3$ rigid bodies moving in $W=\R^3$. A quadrotor is a single body ($n_b=1$) moving in the same workspace $W=\R^3$. 

To describe the complete pose of a planar 2R manipulator, we might use the position vector and roll-pitch-yaw angles for the two bodies, which requires a total of 12 parameters for the whole system, despite that, we know that 2 variables are enough to describe the whole configuration of the system.
\begin{boxdefinition}{Configuration}{}
The configuration of a robot is a \textbf{minimum} set of parameters that allows one to specify the posture\footnote{
    bt posture we mean the position of all the points of the robot.
} of the robot in the workspace.
\end{boxdefinition}
The configuration of a robot can be defined in several ways, and a choice of a set of parameters is not unique, however, each robot always has a \textit{minimum number} of parameters. We usually denote $\q$ the configuration vector:\begin{equation}
    \q=\begin{pmatrix}
        q_1\\ \vdots\\ q_n 
    \end{pmatrix}
\end{equation}
in our context, it usually describes the Cartesian coordinates of a single body robot, or the angular coordinates of the body parts. The Cartesian coordinates have values in a Euclidean space, as $\R^2$ or $\R^3$, while the angular coordinates take values in a non-Euclidean space, such as the special orthogonal group $SO(3)$, the group of all the orthogonal $3\times 3$ matrices  with determinant $+1$, this group describes the orientation of a body in a 3D Euclidean space.
\begin{boxdefinition}{Configuration Space}{}
    The configuration space, usually denoted $\mathcal C$, is the set of all possible values of the configuration of a robot. The \textit{dimension} of $\mathcal C$ is the number $n$ of parameters (generalized coordinates) in $\q$.
\end{boxdefinition}
Let's see an example: consider a disk robot that moves on a plane, that can also rotate about its vertical axis to point towards a desired direction, shown in Figure \ref{disc_tick}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.2\textwidth ]{images/disc_tick.eps}
    \caption{Disk robot with a tick in $\R^2$.}
    \label{disc_tick}
\end{figure}
Its configuration is given by two Cartesian coordinates $(x,y)$ and a value $\varphi\in S^1$ representing the angle between the tick and the horizontal axis. Hence, its configuration space is:\begin{equation}
    \mathcal C = \R^2\times SO(2)=SE(2)
\end{equation}
and it's not Euclidean, despite being called \textit{special Euclidean group}. A polyhedral robot that can freely move in space is described by three Cartesian coordinates $(x,y,z)$ and three roll-pitch-yaw angles $(\alpha,\beta,\gamma)$ describing its orientation, hence the configuration space is $SE(3)$:
\begin{equation}
    \mathcal C = \R^3\times SO(3)=SE(3).
\end{equation}
We have seen in previous courses of robotics that the number of generalized coordinates of an  $n$-link serial manipulator is exactly $n$.
\subsection{Topology of a Space}
We are interested in describing the configuration space of a given manipulator, since it's not Euclidean (in most cases), we would like to have an idea of how to navigate this space. Before defining what a \textit{manifold} is, we give some examples.\bigskip 

A 2R planar manipulator can be described by two angles, hence two values in $SO(2)$, so its configuration space is\begin{equation}
    \mathcal C = SO(2)\times SO(2)=SO(2)^2
\end{equation}
Let's try to represent graphically $\mathcal C$. We might represent a configuration as a point in the Cartesian plane:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/configuration_2R.eps}
\end{figure}
The problem of this representation is that different configurations $\q\in \mathcal C$ map to the same posture of the robot in $W$, as shown in Figure \ref{not_injective}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/configuration_2R_notInjective.eps}
    \caption{Different configurations map to the same posture.}
    \label{not_injective}
\end{figure}
To overcome this problem, we might try to represent the configuration space as a square in the plane $[0,2\pi)\times [0,2\pi)$:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.3\textwidth ]{images/2pi_times_2pi.eps}
\end{figure}
This representation also presents a problem: The distance between two configurations in $\mathcal C$ does not represent the true distance between two postures in the workspace: Two very distant configurations $\q_a$ and $\q_b$ in $\mathcal C$ can be mapped to two very close postures in $W$:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth ]{images/a_b_distance.pdf}
\end{figure}
This representation is said to be \textbf{not topologically correct}. To give a correct representation of $\mathcal C$ we need to introduce the concept of \textbf{manifold}. We will not give a formal and complete definition (as given in topology or differential geometry courses).
\begin{boxdefinition}{Manifold (loose definition)}{}
    A \textbf{manifold} is a topological space that is locally homeomorphic to $\R^n$.
\end{boxdefinition}
As we should know from previous robotics courses, the configuration space of a 2R is a torus, a manifold that is locally homeomorphic to $\R^2$, and can be visualized in the 3D space through an embedding as shown in Figure \ref{torus}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/torus.pdf}
    \caption{3D representation of a torus.}
    \label{torus}
\end{figure}
\subsection{Distance in the Configuration Space}
\begin{boxdefinition}{Distance in the Configuration Space}{distance}
    Given a configuration space $\mathcal C$, the \textbf{distance} is a function $d:\mathcal C\times \mathcal C \to \R$ such that, for each $\q_a,\q_b,\q_c$ in $\mathcal C$ we have:\begin{align}
        &d(\q_a,\q_b)\ge 0\\ 
        &d(\q_a,\q_b)=0\iff \q_a=\q_b\\
        &d(\q_a,\q_b)=d(\q_b,\q_a)\\
        &d(\q_a,\q_b)\le d(\q_a,\q_c)+d(\q_c,\q_b).
    \end{align}
\end{boxdefinition}
\noindent We know that the distance between two vectors $\mathbf u,\mathbf v$ in $\R^n$ is given by $\|\mathbf u - \mathbf v\|$. The distance between two points is the length of the \textit{shortest path} between them, for a general manifold, this path is not always a straight line as for the Euclidean space.
\begin{boxdefinition}{Geodesic}{}
    For a general manifold, the shortest path between two points is called \textbf{geodesic}, and the distance between the points is the length of their geodesic.
\end{boxdefinition}
\noindent For example, consider the shortest path between two points on the surface of a sphere (a 2-manifold): the geodesic lies on the great circle (the circle with the biggest radius that passes through the two points), as shown in Figure \ref{sphere_geodesic}. In general, for an arbitrary manifold, it is hard to determine the geodesic between two points.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.25\textwidth ]{images/geodesic_sphere.eps}
    \caption{Geodesic on a sphere.}
    \label{sphere_geodesic}
\end{figure}
In the robotics context, we want to define the distance between two postures of a robot, this distance is defined in the workspace $W$, and to define that we don't need to specify directly the distance between their respective configurations in $\mathcal C$ (it would be harder to find the geodesic on $\mathcal C$).\bigskip 

\noindent Given a robot and its current configuration $\q$, we can define two functions:\begin{itemize}
    \item $B(\q)$ is a function that assigns to $\q$ the volume (exact region) of the workspace that the robot occupies when it is in the configuration $\q$, so it assigns to each configuration  $\q\in\mathcal C$ a set of points in $\R^3$.
    \item $\mathbf p(\q)$ is a function that assigns to $\q$ the exact position of a certain point of the robot when it's in the configuration $\q$.
\end{itemize}
For example, we might let $\mathbf p$ be the center of mass of the manipulator, and observe how it changes by varying $\q\in \mathcal C$. One simple way to define a distance metric is to consider the maximum Euclidean distance between two points of the manipulator in two different configurations:\begin{equation}\label{displacement_metric}
    d(\q_a,\q_b)=\max_{\mathbf p\in \text{robot}}\|\mathbf p(\q_a)-\mathbf p(\q_b)\|
\end{equation}
This distance is called \textbf{displacement metric}. Notice how in the definition we are writing $\mathbf p \in \text{robot}$, by letting robot be the set of all the points in the structure of the manipulator, which clearly depend on the current configuration. This kind of metric works under the assumption that, if the region occupied by the robot is similar in two different postures, then the distance between their respective configurations is small:\begin{equation}
    d(\q_a,\q_b)\simeq 0\implies B(\q_a)\simeq B(\q_b).
\end{equation}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/displacement_metric.eps}
\end{figure}
To compute the distance in Equation \eqref{displacement_metric}, we should check each point of the robot, and in general this is an uncountably infinite set. If the links are polyhedral shapes, the problem becomes finite, since it is possible to find the maximum distance between any pair of polytopes in the three dimensional space. 

A more computationally feasible approach is to check only for a finite set of points in the robot structure, called \textbf{control points}. Let \begin{equation}
    P=\{\mathbf p_1,\mathbf p_2,\dots, \mathbf p_c\}
\end{equation}
be a set of $c$ points of the robot (in general, they all depend on the configuration $\q$). We compute the distance between two postures in the following way:\begin{equation}\label{cp_metric}
    d(\q_a,\q_b)=\max_{1\le i \le c}\|\mathbf p_i(\q_a)-\mathbf p_i(\q_b)\|.
\end{equation}
Not all the points of a robot are feasible control points, for example, the base of a manipulator usually doesn't change with the configuration. $P$ is a set of \textit{proper control points} if the function $d$ as defined in Equation \eqref{cp_metric} satisfies the properties of a distance given in Definition \ref{def:distance}.
\begin{boxobservation}{Approximation for Local Motion}{}
Since a smooth manifold is locally homeomorphic to $\R^n$, for sufficiently close configurations we can approximate the distance on the manifold (assuming it is smooth) with the Euclidean distance.
\end{boxobservation}
\begin{boxobservation}{Prismatic Joints}{}
The configuration space of a robot with \textit{only} prismatic joints is Euclidean.
\end{boxobservation}
\section{Mechanics of Mobile Robots}
The main sources of movement for a mobile robot are:\begin{itemize}
    \item Wheels: wheeled robots usually consist of one single rigid body, with the wheels in contact with the ground.
    \item Feet: legged robots, several rigid bodies articulated through joints.
\end{itemize}
The wheels are in contact with the ground, and this introduces some constraints. Each wheel defines a point of contact with the ground, we call the \textbf{support polygon} the convex hull of all the contact points. A wheeled robot is in \textbf{static balance} if the projection on the ground of its center of mass falls inside the support polygon. Of course a robot must be balanced in order not to fall to the ground.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/balance.pdf}
\end{figure}
The convex hull of two points is a line segment, hence a robot with only two wheels can't be easily balanced in a static fashion.\bigskip

\noindent There are three main types of wheels:\begin{itemize}
    \item \textbf{Fixed Wheels}: They have a fixed orientation: Can roll but can't steer about their vertical axis (see Figure \ref{fixed_wheel}). They are usually actuated, if passive, they are used for balance and offer a contact point.
    \item \textbf{Steerable Wheels}: They can steer and are used for orientation, hence they are typically active (e.g. the front wheels of a car).
    \item \textbf{Caster Wheels}: They have a variable orientation but they are typically not actuated. Their axis of orientation are not aligned, this property makes the wheels align automatically with the direction of motion, hence they are ``invisible'' kinematically, but offer a contact point.
\end{itemize}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.65\textwidth ]{images/wheels.png}
    \caption{Fixed, steerable and caster wheels.}
    \label{fixed_wheel}
\end{figure}
\subsection{Main Kinematic Structures}
The simplest wheeled robot that we can have is the \textbf{differential drive} robot: it uses two aligned fixed wheels that are independently actuated, and one caster wheel added for balance. The \textbf{synchro-drive} mobile robots have three steerable wheels and two actuators: one controls simultaneously the orientation of all the wheels, and the other rolls them together. The base over the wheels hence will never change orientation. This type of configuration is preferable when the body to move is particularly heavy.
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth ]{images/structures.eps}
\end{figure}
The tricycle has two fixed wheels in the back and one actuated steerable wheel in the front, the car-like is similar, but with two steerable wheels.\bigskip

Consider the following path taken by a car-like robot:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/differential.eps}
\end{figure}
In the same time interval, the wheels on the outer path travels a longer distance with respect to the wheels on the inner path, hence their rotation speed must be higher. In order to avoid using two distinct actuators for the front wheels we use a device called \textbf{differential}.
\begin{boxdefinition}{Differential}{}
   A mechanical differential is a gear assembly (usually using bevel or planetary gears) connected to a single drive motor. It splits power to two wheels on the same axle while allowing them to rotate at different speeds. When a robot with a single motor turns, the outside wheel must travel a larger arc than the inside wheel. The differential lets the wheels spin at their own natural speeds, preventing tire slip, scrubbing, and mechanical strain on the drivetrain.
\end{boxdefinition}

\section{Constraints and Mobility}
The presence of the wheels in contact with the ground introduces a series of \textit{geometric} and \textit{kinematic} constraints. We will also see the relationship between these two types of constraints and the implications in mobility.
\subsection{Geometric Constraints}
We have seen how the configuration $\q$ is in general a point of a manifold $\mathcal C$, that is locally homeomorphic to $\R^n$, with $n$ being the dimensionality of the configuration space $\mathcal C$.
We will focus on equality time-invariant constraints. All the geometric constraints are expressed in the following form:\begin{equation}
    h(\q)=0
\end{equation}
and they depend only on the configuration. Usually we have $k<n$ geometric constraints, and they are reflected in the degrees of freedom of a robot:\begin{align}
   &h_1(\q)=0\\
   &\vdots\\ 
   &h_k(\q)=0.
\end{align}
If the configuration space is a 2-manifold, one single geometric constraint will reduce the degrees of freedom of the robot, constraining it to move on a 1-dimensional manifold (a curve).
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/1-constraint.eps}
    \caption{If the configuration space is $\R^2$, one constraint will let the configurations lie on a curve in the plane.}
\end{figure}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/1-constraint_3D.pdf}
    \caption{If the configuration space is $\R^3$, one constraint will let the configurations lie on a surface in the space.}
\end{figure}
In general, a robot with a configuration space that is an $n$-manifold with $k$ independent geometric constraints, will move on an $(n-k)$-manifold. Instead of using the vector $\q$, we can reduce the number of coordinates in many ways, like for one constraint:\begin{equation}
    h(\q)=0
\end{equation}
we can solve the equation for a coordinate $q_i$:\begin{equation}
    q_i=\tilde h(q_1,\dots,q_{i-1},q_{i+1},\dots, q_n).
\end{equation}
For example, consider a 2 degrees of freedom robot with the following constraint:\begin{equation}
    q_1^2+q_2^2=1
\end{equation}
the configuration space is limited to the unit circle in $\R^2$ (1-manifold), we solve the constraint for $q_2$:\begin{equation}
    q_2=\pm\sqrt{1-q_1^2}.
\end{equation}
Actually this is not a good way to choose a coordinate, since the $\pm$ term prevents us from assigning a single value of $q_2$ to each value of $q_1$, requiring a local resolution. For this example of the circle it is better to use the arc length $s\in S^1$ as the single coordinate.
\begin{boxobservation}{Sub-Manifold}{}
    If the configuration space $\mathcal C$ is an $n$-manifold, the $k$ independent constraints define a $(n-k)$-manifold embedded in $\mathcal C$, that we also call sub-manifold.
\end{boxobservation}
\subsection{Kinematic Constraints}
A kinematic constraint is local, it prevents the configuration from moving towards some directions. A general constraint of this kind is in the form:\begin{equation}
    a(\q,\dq)=0
\end{equation}
it depends on the state of the robot. In every given configuration $\q^*$, we can immediately infer from $a(\q^*,\dq)=0$ which velocities are allowed. All the relevant kinematic constraints in the robotic domain are in \textbf{Pfaffian form}:\begin{equation}
   \mathbf a^\top(\q)\dq=0
\end{equation}
with $\mathbf a$ being an $n$ dimensional vector that depends on the configuration. The Pfaffian form expresses a condition of orthogonality: in a given configuration the velocity must be orthogonal to the vector $\mathbf a$. More kinematic constraints can be arranged in matrix form:\begin{equation}
    \begin{pmatrix}
        \mathbf a_1^\top(\q)\\
        \mathbf a_2^\top(\q)\\ \vdots\\ 
        \mathbf a_k^\top(\q)
    \end{pmatrix}\dq=\mathbf 0\implies A(\q)\dq=\mathbf 0\iff \dq\in\mathcal N(A).
\end{equation}
The admissible velocities are the ones that lie in the null space of $A$\footnote{
    Sometimes, we let the dependencies of a term implicit.
}, hence they lie in a linear space. 
\begin{boxobservation}{Relationship Between Geometric and Kinematic Constraints}{}
    Any geometric constraint implies a kinematic constraint.
\end{boxobservation}
Consider a geometric constraint\begin{equation}
    h(\q)=0
\end{equation}
this constraint must be satisfied as the time goes on, hence its derivative should also satisfy the following relation:\begin{equation}
    \dot h(\q)=0
\end{equation}
by applying the chain rule:\begin{equation}
    \dot h(\q)=\frac{\partial h}{\partial \q}\dq =0
\end{equation}
$\frac{\partial h}{\partial \q}$ is a row vector, the transpose of the gradient of $h$:\begin{equation}
    (\nabla_\q h)^\top\dq=0
\end{equation}
this is exactly a kinematic constraint in Pfaffian form. The gradient of $h$ evaluated on a point is the normal vector, i.e. orthogonal to the manifold on which the configuration is constrained to move, hence the resulting kinematic constraint is preventing the robot from going out of the sub-manifold defined by the geometric constraints.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.45\textwidth ]{images/tangent_plane.eps}
    \caption{The admissible velocities are the ones that lie on the tangent space of the sub-manifold in the given configuration.}
\end{figure}
We have seen how a geometric constraint always implies a kinematic one. The opposite is not generally true, consider a generic kinematic constraint:\begin{equation}
    \mathbf a^\top(\q)\dq=0
\end{equation}
this implies a geometric constraint if there exists a function $h(\q)$ such that \begin{equation}\label{holonomic}
    \nabla_\q h=\mathbf a
\end{equation}
hence the constraint defined by $\mathbf a(\q)$ should be \textit{integrable}.
\begin{boxdefinition}{Holonomic Constraint}{}
    An integrable kinematic constraint is called \textbf{holonomic}, and it defines a geometric constraint.
\end{boxdefinition}
What conditions determine if a constraint is integrable or not? In general, the conditions are stated in the \textit{Frobenius Theorem}, we will not discuss this result, which belongs to the domain of differential geometry. We will determine if a given constraint is holonomic or not by a different way.

Consider the following kinematic constraint for a 2-dimensional robot:\begin{equation}
     q_1\dot q_1+q_2\dot q_2=0
\end{equation}
is this integrable? The answer is yes. The resulting geometric constraint is\begin{equation}
    q_1^2+q_2^2=c, \quad c>0.
\end{equation}
In general, in Equation \eqref{holonomic} we can add a scalar integrating factor that depend on the configuration:
\begin{equation}
    \frac{\partial h}{\partial \q}=\gamma(\q)\mathbf a^\top(\q)
\end{equation}
since the right-hand side is zero, $\gamma$ can be dropped.
\subsection{Non-Holonomic Constraints}\label{sec:nonhol}
A non-holonomic constraint defines a local limitation, it stops the robot from moving towards a certain direction when it is in that specific configuration, it does not prevent the robot from reaching a configuration by following an allowed path. The simplest example of a system with a non-holonomic constraint is a rolling disk.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/rolling_disk.eps}
\end{figure}
The configuration is given by the vector $\begin{pmatrix}
    x&y&\theta
\end{pmatrix}^\top$, $\theta$ is its orientation with respect to the horizontal axis. It is clear that the disk in pure rolling (no slippage) can move \textit{only} in the direction that is pointing (by rolling), hence can't move laterally. This constraint is expressed as follows:\begin{equation}
    \sin\theta\dot x-\cos\theta \dot y = 0
\end{equation}
or in vector form:\begin{equation}
    \begin{pmatrix}
        \sin\theta& -\cos\theta& 0 
    \end{pmatrix}\begin{pmatrix}
   \dot x\\\dot y\\\dot \theta
\end{pmatrix}=0
\end{equation}
$\mathbf{n}^\top=\begin{pmatrix}
        \sin\theta& -\cos\theta 
\end{pmatrix}$
is the vector \textit{normal} to the direction. Any velocity that has a component on the line spanned by $\mathbf{n}$ is not allowed.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/rolling_disk2.eps}
\end{figure}
This constraint does not imply any global limitation, any configuration is still reachable, hence it is a non-holonomic constraint. To prove this, instead of using the Frobenius theorem, we give a non-formal proof by showing that, for any pair of configurations $\q_s,\q_g$, there exists a trajectory in the configuration space that connects these two configurations without violating the kinematic constraint. Let\begin{equation}
    \q_s=\begin{pmatrix}
        x_s\\y_s\\\theta_s
    \end{pmatrix},\quad \q_g=\begin{pmatrix}
        x_g\\y_g\\\theta_g
    \end{pmatrix}.
\end{equation}
\begin{enumerate}
    \item $\dot \theta$ is not constrained, first of all we move the orientation from $\theta_s$ to $\theta^*$, where $\theta^*$ is defined as the angle such that\begin{equation}
        \begin{pmatrix}
        \sin\theta^*& -\cos\theta^*
    \end{pmatrix}\begin{pmatrix}
    x_g-x_s\\y_g-y_s
\end{pmatrix}=0.
    \end{equation}
    \item Then, we can move on the direction $\begin{pmatrix}
    x_g-x_s&y_g-y_s
\end{pmatrix}^\top$, in this way we can reach the desired position $\begin{pmatrix}
    x_g&y_g
\end{pmatrix}^\top$.
    \item At the end, we move the orientation from $\theta^*$ to $\theta_g$.
\end{enumerate}
This is called \textbf{universal maneuver}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/universal_man.pdf}
    \caption{The universal maneuver in five steps.}
\end{figure}
There are no global mobility limitations. We can also observe this trajectory in the configuration space:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/manuvre_C_space.eps}
\end{figure}
Note how for simplicity we have drawn the configuration space as Euclidean. Of course it is not Euclidean because $\theta\in S^1$.
\section{Kinematic Models}
We have seen how  the kinematic constraints are defined in Pfaffian form as $A(\q)\dq=\mathbf 0$, with $A$ being a $k\times n$ matrix. We are interested in finding a basis for the null space of $A(\q)$:\begin{equation}
    \mathcal N(A(\q))=\text{span}\left\{ 
        \mathbf g_1(\q),\mathbf g_2(\q),\dots,\mathbf g_m(\q)
    \right\}
\end{equation}
$\mathcal N(A(\q))$ has dimension $m:=n-k$. Each vector $\mathbf g_i(\q)$ of the basis is a vector field on $\mathcal C$ with values in $\R^n$, any admissible velocity is a linear combination of the vectors in the base:\begin{equation}
    \dq=\sum_{i=1}^m u_i\mathbf g_i(\q)
\end{equation}
we can write any admissible velocity in compact form by using an $m$ dimensional vector $\mathbf u$:\begin{equation}
    \dq=\underbrace{\begin{pmatrix}
        | &|&&|\\
        \mathbf g_1(\q)&\mathbf g_2(\q)&\dots&\mathbf g_m(\q)\\
        | &|&&|
    \end{pmatrix}}_{G(\q)}\underbrace{\begin{pmatrix}
    u_1\\ \vdots\\ u_m
    \end{pmatrix}}_{\mathbf u}
\end{equation}
the \textbf{kinematic model} is:\begin{equation}
    \dq=G(\q)\mathbf u
\end{equation}
with $\mathbf u$ being a velocity-level quantity. We can see the model as a dynamical system, with $\q$ being the $n$-dimensional state vector and $\mathbf u$ the $m$-dimensional input vector, of course it is a nonlinear system due to $G(\q)$ that depends (in general) nonlinearly on $\q$.
This system satisfies the \textbf{driftless property}:\begin{equation}
    \mathbf u = \mathbf 0 \implies \dq=\mathbf 0
\end{equation}
it does not have a free evolution. The kinematic model is not unique, since we can select a different choice for the basis vectors $\mathbf g_1,\dots, \mathbf g_m$, all the bases are equivalent for the description of the system, but the interpretation of the vector $\mathbf u$ depends on the choice of the basis. We can interpret $\mathbf u$ as the ``virtual'' velocities in the kinematically constrained configuration space.\bigskip

Now we want to observe the differences between a kinematically constrained robot and an unconstrained robot. Consider an open-chain manipulator with revolute joints, with $\q$ being the joint variables (DH coordinates). This choice of coordinates makes the manipulator free from any constraint, the configuration can ``fly'' in the configuration space, any joint velocity $\dq$ is always admissible, hence its kinematic model is\begin{equation}
    \dq=\mathbf u.
\end{equation}
This is a simple integrator, we can impose any joint velocity. For a robot with non-holonomic constraint this does not hold. The kinematic model is not a simple integrator since it has a \textit{filtering} component given by the matrix $G(\q)$, the vector $\mathbf u$ does not represent directly the joint velocity, but is called \textbf{pseudo-velocity}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/constrained_vs_unconstrained.eps}
\end{figure}
\noindent Let's discuss about controllability of the constrained model. The controllability of a system can be proved formally through nonlinear control theory, or constructively, by the definition of a universal maneuver (as we did in the previous section).
\begin{boxdefinition}{Controllability}{}
    The kinematic model of a manipulator is controllable if any configuration can be reached from any initial configuration in finite time.
\end{boxdefinition}
A holonomic constraint defines a geometric constraint that prevents the robot from accessing a specific region in the configuration space, hence a robot with geometric constraints is never controllable. By this reasoning, there is a 1-to-1 correspondence between controllability and the presence of holonomic constraints.
\begin{boxobservation}{}{}
    The kinematic model of a robot is controllable \textbf{if and only if}  the set of kinematic constraints is non-holonomic.
\end{boxobservation}
\subsection{The Unicycle Model}
Let's define the kinematic model of a unicycle, that is equivalent to the rolling disk seen in Section \ref{sec:nonhol}. It has one kinematic constraint, the pure rolling condition imposes that:\begin{equation}
    \sin\theta\dot x-\cos\theta\dot y=0.
\end{equation}
It says that the velocity of the contact point must be aligned with the \textit{sagittal axis} defined by $\theta$, i.e. it can't have components on the zero-motion line. In matrix form the constraint is:\begin{equation}
    \underbrace{\begin{pmatrix}
    \sin\theta&-\cos\theta&0
    \end{pmatrix}}_{A(\q)}\begin{pmatrix}
        \dot x\\ \dot y\\ \dot\theta 
    \end{pmatrix}=0.
\end{equation}
The dimension of $\mathcal N(A)$ is 2, hence we will have a 2-dimensional vector of the pseudo-velocity.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/unicycle.eps}
\end{figure}
\noindent A basis for the null space of $A$ is the following:\begin{equation}
    \mathbf g_1(\q)=\begin{pmatrix}
        \cos\theta\\\sin\theta\\ 0
    \end{pmatrix},\quad 
     \mathbf g_2(\q)=\begin{pmatrix}
       0\\0\\1
    \end{pmatrix}
\end{equation}
the kinematic model is\begin{equation}
  \dq=  G(\q)\mathbf u=\begin{pmatrix}
         \cos\theta&0\\\sin\theta&0\\ 0&1
    \end{pmatrix}\begin{pmatrix}
       u_1\\ u_2
    \end{pmatrix}\implies\begin{cases}
        \dot x = \cos\theta u_1\\ 
        \dot y = \sin\theta u_1\\ 
        \dot\theta = u_2
    \end{cases}.
\end{equation}
$u_1$ is the scalar velocity along the sagittal axis
\begin{equation}
    u_1=\pm\sqrt{\dot x^2+\dot y^2}
\end{equation}
while $u_2$ is exactly $\dot\theta$. We rename these quantities:\begin{align}
    &v=u_1\\ &\omega=u_2
\end{align}
$v$ is related to the rolling velocity $\omega_{\text{roll}}$ and the radius of the wheel:\begin{equation}
    v=\omega_{\text{roll}}\cdot r.
\end{equation}
We can rewrite the kinematic model by splitting the Cartesian part from the angular one:\begin{equation}
    \dq=\begin{pmatrix}
        \cos\theta\\\sin\theta\\0 
    \end{pmatrix}v+\begin{pmatrix}
        0\\0\\1 
    \end{pmatrix}\omega.
\end{equation} 
Is this model controllable? Yes, we already proved for the rolling disk that a universal maneuver exists.\bigskip

What are the real world robots that are kinematically and mechanically equivalent to the unicycle? First of all the differential drive, since it can rotate along its vertical axis, and move in the Cartesian plane only towards its sagittal axis (it can't slide laterally). It has two actuated wheels, of radius $r$ and rolling velocities $\omega_R,\omega_L$. Its Cartesian velocity $v$ is given by the average angular velocity of the two wheels:\begin{equation}
    v=r\frac{\omega_R+\omega_L}{2}
\end{equation}
while its angular velocity is given by the difference:\begin{equation}
    \omega=(\omega_R-\omega_L)\frac{r}{d}
\end{equation}
where $d$ is the distance between the contact points of the wheels.\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/diff_drive.eps}
\end{figure}
The other robot that is equivalent to the unicycle is the synchro-drive, it has two motors equipped with a pulley and belt mechanism, one controls the orientation of all the wheels, the other the rolling speed, hence these motors directly controls $v$ and $\omega$, where $v$ is relative to the velocity of the geometric center of the three contact points.
\subsection{The Bicycle Model}
This kinematic model has two wheels, one fixed at the back (called rear wheel)  and one steerable in the front. 
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/bicycle.eps}
    \caption{The bicycle model.}
    \label{bicycle}
\end{figure}
As described in Figure \ref{bicycle}, the configuration space of the bicycle is $\mathcal C=\R^2\times SO(2)\times SO(2)$, the dimension is $n=4$. $l$ is the distance between the two contact points of the two wheels, the first identified by $(x,y)$, the second by $(x_f,y_f)$, clearly:\begin{align}
    x_f&=x+l\cos\theta\\
    y_f&=y+l\sin\theta
\end{align}
the configuration vector is\begin{equation}
    \q=\begin{pmatrix}
        x&y&\theta&\phi 
    \end{pmatrix}^\top.
\end{equation}
Since there are two wheels, we will have two constraints, that imposes the pure rolling condition both wheels. For the rear wheel and the front wheel, respectively::\begin{align}
    &\sin\theta\dot x-\cos\theta \dot y=0\\ 
    &\sin(\theta+\phi)\dot x_f-\cos(\theta+\phi)\dot y_f=0\label{front_wheel_constr}
\end{align}
in vector form:\begin{align}
    &\underbrace{\begin{pmatrix}
    \sin\theta&-\cos\theta
    \end{pmatrix}}_{\mathbf a^\top_1}\begin{pmatrix}
        \dot x\\ \dot y  
    \end{pmatrix}=0\\[1.5ex] 
    &\underbrace{\begin{pmatrix}
    \sin(\theta+\phi)&-\cos(\theta+\phi)
    \end{pmatrix}}_{\mathbf a^\top_2}\begin{pmatrix}
        \dot x_f\\ \dot y_f
    \end{pmatrix}=0
\end{align}
$\mathbf a_1$ and $\mathbf a_2$ identify the direction of the (forbidden) slide direction for both wheels. The two lines meet at the point known as \textbf{instantaneous center of rotation (ICR)}, as shown in Figure \ref{ICR}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/ICR.eps}
    \caption{The instantaneous center of rotation.}
    \label{ICR}
\end{figure}
The ICR represents the geometric point around which all the parts of the robot are rotating at a given instant. Now we want to make explicit $(\dot x_f,\dot y_f)$ in order to write the constraints only as a function of $\q$.\begin{align}
    &\begin{cases}
        x_f=x+l\cos\theta\\
        y_f=y+l\sin\theta
    \end{cases}\implies\\[1.5ex]
    &\begin{cases}
        \dot x_f=\dot x-\dot\theta l\sin\theta\\
        \dot y_f=\dot y+\dot\theta l\cos\theta
    \end{cases}
\end{align}
we rewrite the constraint in Equation \eqref{front_wheel_constr}:\begin{align}
   & \sin(\theta+\phi)\dot x_f-\cos(\theta+\phi)\dot y_f=0\implies\\
   & \sin(\theta+\phi)(\dot x-\dot\theta l\sin\theta)-\cos(\theta+\phi)(\dot y+\dot\theta l\cos\theta)=0\implies\\
   &\sin(\theta+\phi)\dot x-\cos(\theta+\phi)\dot y-l\dot\theta\cos\phi=0.
\end{align}
The constraints in matrix form are:\begin{equation}
    \underbrace{\begin{pmatrix}
        \sin\theta&-\cos\theta&0&0\\ 
        \sin(\theta+\phi)&-\cos(\theta+\phi)&-l\cos\phi&0
    \end{pmatrix}}_{A(\q)}\begin{pmatrix}
        \dot x\\\dot y\\\dot \theta\\\dot \phi 
    \end{pmatrix}=\mathbf 0
\end{equation}
with $\text{dim}\mathcal N(A)=2$, we should find two vectors for the basis of $\mathcal N(A)$. Since the last column of $A$ is zero, one of the two vectors is:\begin{equation}
    \mathbf g_2(\q)=\begin{pmatrix}
        0\\0\\0\\1 
    \end{pmatrix}.
\end{equation}
We want to find $\mathbf g_1(\q)$, a vector similar to the one used for the unicycle is\begin{equation}\mathbf g_1(\q)=\begin{pmatrix}
    \cos\theta\\\sin\theta\\\alpha\\0
\end{pmatrix}
\end{equation}
with $\alpha$ a term that has yet to be chosen. We see that:\begin{equation}
    \begin{pmatrix}
        \sin\theta&-\cos\theta&0&0\\ 
        \sin(\theta+\phi)&-\cos(\theta+\phi)&-l\cos\phi&0
    \end{pmatrix}\begin{pmatrix}
    \cos\theta\\\sin\theta\\\alpha\\0
\end{pmatrix}=\begin{pmatrix}
    0\\ 
     \sin(\theta+\phi)\cos\theta-\cos(\theta+\phi)\sin\theta-l\cos\phi\alpha
\end{pmatrix}
\end{equation}
now we choose $\alpha$ to make the second component zero:\begin{align}
     &\sin(\theta+\phi)\cos\theta-\cos(\theta+\phi)\sin\theta-l\cos\phi\alpha=0\implies\\
     &\sin\phi-l\cos\phi\alpha=0\implies \\ 
     &\alpha=\frac{1}{l}\tan\phi 
\end{align}
we have found our basis, now we can write out the kinematic model:\begin{equation}
    \dq=\begin{pmatrix}
        \dot x\\ \dot y \\ \dot\theta\\\dot\phi
    \end{pmatrix}=\begin{pmatrix}
        \cos\theta\\\sin\theta\\\frac{1}{l}\tan\phi \\0
    \end{pmatrix}u_1+\begin{pmatrix}
        0\\0\\0\\1 
    \end{pmatrix}u_2
\end{equation}
$u_1=\pm\sqrt{\dot x^2+\dot y^2}$ is the magnitude of the velocity of the rear wheel contact point. If the robot is driven by the front wheel this model isn't appropriate, since $u_1$ is the velocity of the rear wheel.\bigskip

This model has a singularity, since $\tan\phi$ isn't defined at $\phi=\pm\frac{\pi}{2}$, hence $\mathbf g_1$ can't be evaluated, this is due to the fact that the model assumes only pure rolling for the wheels, and if $\phi=\frac{\pi}{2}$ any non zero $u_1$ will make the front wheel slide.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/phi_singularity.eps}
\end{figure}
\noindent This problem is easily avoided by considering a limits on the joint values. Now let's derive a model where $u_1$ is the velocity of the front wheel, to do so, we have to modify the first vector of the basis:\begin{equation}
    \hat{\mathbf g}_1=\mathbf g_1\cos\phi
\end{equation}
then\begin{equation}
    \dq=\underbrace{\begin{pmatrix}
        \cos\theta\cos\phi\\\sin\theta\cos\phi\\\frac{1}{l}\sin\phi \\0
    \end{pmatrix}}_{\hat{\mathbf g}_1}u_1+\begin{pmatrix}
        0\\0\\0\\1 
    \end{pmatrix}u_2
\end{equation}
now $u_1$ is $\pm\sqrt{\dot x_f^2+\dot y_f^2}$. Now the singularity on $\phi$ disappears, here a non zero $u_1$ when $\phi=\frac{\pi}{2}$ represents a motion around $(x,y)$.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.3\textwidth]{images/phi_singularity2.eps}
\end{figure}
The bicycle constraints are non-holonomic and the model is controllable, we prove this fact by showing (in a non formal way) a universal maneuver. Consider two generic configurations $\q_s,\q_g$, we can draw the circles centered in the ICR that represent the Cartesian trajectory that the robot will perform by actuating just the rear wheel.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth]{images/bicycle_manuver_1.eps}
\end{figure}
The robot in $\q_s$ (left) can start tracking the circular trajectory until it is on the \textit{common tangent} between the two circles.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth]{images/bicycle_manuver_2.eps}
\end{figure}
There, it will steer by making $\phi=0$ and it will track the common tangent in order to reach the  circular path of $\q_g$. There, it will steer again and reach the goal configuration.\bigskip

Which robots are mechanically equivalent to a bicycle? One example is the tricycle. A tricycle with two rear wheels and one steerable front wheel can be modeled as a bicycle by defining the midpoint between the two rear wheels as $(x,y)$. A car-like robot can also be represented by the bicycle model, but it presents a kinematic challenge: because it has two steerable front wheels, their respective zero-motion lines might intersect the zero-motion line of the rear axle at different points. When this happens, a single Instantaneous Center of Rotation (ICR) cannot be identified. This situation is illustrated in Figure \ref{no_single_icr}.

To overcome this problem, we use a mechanism called \textbf{Ackermann steering}, which, during a circular path, automatically orients the front wheels so that their zero-motion lines intersect at a single ICR.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.7\textwidth]{images/no_single_icr.eps}
    \caption{The intersections identifies two ICR.}
    \label{no_single_icr}
\end{figure}
\chapter{Controllability of Mobile Robots}
\section{Nonlinear Controllability}
Let's discuss about the controllability of a nonlinear \textit{driftless} system:\begin{equation}\label{driftless_system}
    \dot{\mathbf x}=\sum_{i=1}^m\mathbf g_i(\mathbf x)u_i 
\end{equation}
with $\mathbf g_i:\R^n\rightarrow\R^n$ being a vector field and $u_1,\dots,u_m$ the inputs. In this general discussion we use the symbol $\mathbf x$ to denote the state of our system, although we usually use $\q$ (in the robotics domain).
\begin{boxdefinition}{Controllability of a Nonlinear System}{}
    The system in Equation \eqref{driftless_system} is \textbf{controllable} if, for any pair of states $(\mathbf x_i,\mathbf x_f)$, with $\mathbf x(0)=\mathbf x_i$, there exists a profile $\tilde{\mathbf u}(t)$ for the inputs in $t\in [0,T]$ such that the system will reach at the end the state $\mathbf x(T)=\mathbf x_f$.
\end{boxdefinition} 
In linear systems, the controllability is guaranteed when the controllability matrix of the system have full rank, we will see how also for the nonlinear case, the controllability test will result in the derivation of the rank of a matrix.
\begin{boxdefinition}{Lie Brackets}{}
    Let $\mathbf g_1,\mathbf g_2$ be two vector fields on $\R^n$. The \textbf{Lie Bracket} of these vector fields is the new vector field $[\mathbf g_1,\mathbf g_2]$ defined as follows:\begin{equation}
        [\mathbf g_1,\mathbf g_2](\mathbf x)=\frac{\partial \mathbf g_2}{\partial \mathbf x}\mathbf g_1(\mathbf x)-\frac{\partial \mathbf g_1}{\partial \mathbf x}\mathbf g_2(\mathbf x).
    \end{equation}
\end{boxdefinition}
\noindent Let's see an example in $\R^3$:\begin{equation}
    \mathbf g_1=\begin{pmatrix}
        \cos x_3\\\sin x_3\\ 0 
    \end{pmatrix},\quad\mathbf g_2=\begin{pmatrix}
        0\\0\\ x_1 
    \end{pmatrix}
\end{equation}
the Jacobians are:\begin{equation}
    \frac{\partial  \mathbf g_1}{\partial \mathbf x}=\begin{pmatrix}
        0&0&-\sin x_3\\ 
        0&0&\cos x_3\\ 
        0&0&0
    \end{pmatrix},\quad 
    \frac{\partial  \mathbf g_2}{\partial \mathbf x}=\begin{pmatrix}
        0&0&0\\ 
        0&0&0\\ 
        1&0&0
    \end{pmatrix}
\end{equation}
hence:\begin{equation}
     [\mathbf g_1,\mathbf g_2](\mathbf x)=\begin{pmatrix}
        x_1\sin x_3\\ 
        -x_1\cos x_3 \\ 
        \cos x_3
     \end{pmatrix}
\end{equation}
notice how in this case $[\mathbf g_1,\mathbf g_2]$ is linearly independent from $\mathbf g_1,\mathbf g_2$. Now we want to give an \textit{interpretation} of the Lie bracket. Consider the following 2-inputs system:\begin{equation}
    \dot{\mathbf x}=\mathbf g_1(\mathbf x)u_1+\mathbf g_2(\mathbf x)u_2
\end{equation}
the interpretation of the Lie brackets can be defined by considering the following time profile for $u_1,u_2$ in $t\in [0,4\varepsilon]$:
\begin{align}
    &(u_1,u_2)=(1,0)\quad  t\in[0,\varepsilon]\\ 
    &(u_1,u_2)=(0,1)\quad  t\in[\varepsilon,2\varepsilon]\\ 
    &(u_1,u_2)=(-1,0)\quad t\in[2\varepsilon,3\varepsilon]\\ 
    &(u_1,u_2)=(0,-1)\quad t\in[3\varepsilon,4\varepsilon].
\end{align}\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/lie_inputs.eps}
\end{figure}
After applying this input profile the system will be in the state:\begin{equation}
    \mathbf x(4\varepsilon)=\mathbf x(0)+\underbrace{\varepsilon^2[\mathbf g_1,\mathbf g_2](\mathbf x(0))+O(\varepsilon^3)}_{\text{displacement}}.
\end{equation}
This result affirms that the displacement will be in the direction of the Lie bracket, with an error given by the term $O(\varepsilon^3)$: if $\varepsilon\rightarrow 0$, the terms in $O(\varepsilon^3)$ will vanish faster, and the displacement will be defined mainly by  $\varepsilon^2[\mathbf g_1,\mathbf g_2](\mathbf x(0))$.
\begin{boxobservation}{}{}
    The Lie bracket gives the direction of the displacement of that particular input sequence.
\end{boxobservation} 
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth ]{images/lie_bracket_direction.eps}
\end{figure}
\begin{boxdefinition}{Distribution}{}
    Let $\mathcal C$ be a smooth manifold. A \textit{Distribution} $\Delta$ is a map that assign at each point $\mathbf x\in \mathcal C$ a subspace of the tangent space $T_\mathbf x\mathcal C$:\begin{equation}
        \Delta : \mathbf x \mapsto \Delta(\mathbf x)\subset T_\mathbf x\mathcal C.
    \end{equation}
\end{boxdefinition}
The tangent space in each point of a $n$-manifold has dimension $n$, hence the dimension of the subspace $\Delta (\mathbf x)$ can be at most $n$ (depending on the point on where we are evaluating $\Delta$). For a system in the form \eqref{driftless_system}, the \textit{input distribution} is defined as follows:\begin{equation}
    \Delta(\mathbf x)=\text{span}\{\mathbf g_1(\mathbf x),\mathbf g_2(\mathbf x),\dots,\mathbf g_m(\mathbf x)\}.
\end{equation}
The controllability problem for nonlinear systems is strictly correlated to a particular distribution, called the \textbf{accessibility distribution} $\Delta_{\mathcal A}$, defined as follows:\begin{equation}
    \Delta_{\mathcal A}(\mathbf x)=\text{span}\{\mathbf g_1(\mathbf x),\dots,\mathbf g_m(\mathbf x),\dots,[\mathbf g_i,\mathbf g_j](\mathbf x),\dots,[\mathbf g_i,[\mathbf g_j,\mathbf g_k]](\mathbf x),\dots\}.
\end{equation}
Let's break it down:\begin{itemize}
    \item With $[\mathbf g_i,\mathbf g_j]$  we denote all Lie brackets given by all the possible pairs of vector fields for $1\le i,j\le m$. These are also called first order Lie brackets.
    \item Each pair $\mathbf g_i,\mathbf g_j$ (with $i\ne j$) appears only one time, we don't have to add also $[\mathbf g_j,\mathbf g_i]$ since it is equal to $-[\mathbf g_i,\mathbf g_j]$ (they are linearly dependent, the span needs only one of them).
    \item $[\mathbf g_i,[\mathbf g_j,\mathbf g_k]]$ for $1\le i,j,k\le m$ are the second order Lie brackets.
    \item This nested definition can continue, for example the third order Lie brackets are in the form  $[\mathbf g_i,[\mathbf g_j,[\mathbf g_k,\mathbf g_h]]]$.
    \item The definition of $\Delta_{\mathcal A}$ consider all the possible combination of Lie brackets, for each possible order, up to infinity.
\end{itemize}
Of course $\Delta_{\mathcal A}(\mathbf x)$ can have different dimension depending on $\mathbf x$, for a nonlinear system, to assert controllability, is \textit{mandatory} that $\Delta_{\mathcal A}(\mathbf x)$ have dimension $n$ on every single $\mathbf x\in\mathcal C$.
\begin{boxdefinition}{Dimension of a Distribution}{}
    The distribution $\Delta_{\mathcal A}$ have dimension $k$ if $\dim\Delta_{\mathcal A}(\mathbf x)=k$ for every $\mathbf x\in\mathcal C$. In that case we write $\dim\Delta_{\mathcal A}=k$.
\end{boxdefinition}
\noindent The nonlinear controllability problem is fully described by the following result.
\begin{boxtheorem}{Accessibility Criterion}{}
    A nonlinear system of the form \eqref{driftless_system} with an $n$-dimensional state vector is controllable \textit{if and only if} its accessibility distribution have dimension $n$:\begin{equation}
        \dim\Delta_{\mathcal A}=n.
    \end{equation}
\end{boxtheorem}
So in practice, we have to build the matrix $M$ which the columns are the vector fields $\mathbf g_i$ and all their Lie brackets, and check if the rank is full.\begin{equation}
    M(\mathbf x)=\begin{pmatrix}
          |& &| & &| & &|&\\
        \mathbf g_1(\mathbf x)&\dots&\mathbf g_m(\mathbf x)&\dots &[\mathbf g_i,\mathbf g_j](\mathbf x)&\dots&[\mathbf g_i,[\mathbf g_j,\mathbf g_k]](\mathbf x)\dots\\
         |& &| & &| & &|&
    \end{pmatrix}
\end{equation}
It's impossible to write out all the columns, we can check each iteratively for the vector fields $\mathbf g_1,\dots,\mathbf g_m$, then for the first order Lie brackets, then for the higher order,  as soon as the rank of the matrix reaches size $n$, the criterion is satisfied ($\dim \Delta_{\mathcal{A}} = n$) and the system is controllable. All remaining infinite columns can be ignored. For systems described by analytic functions, the chain of Lie brackets stabilizes after a finite number of steps. If at a certain point the new Lie brackets no longer increase the rank and it remains lower than $n$, the process stops and the system is not controllable. \begin{boxproposition}{}{}
If the system is analytical, the accessibility distribution stabilizes. The chain of Lie brackets cannot generate distributions of infinitely increasing size in a space of dimension $n$. Consequently, in the worst case, it is not necessary to go beyond the Lie brackets of order $n-1$ (or in any case limited according to the size of the state).
\end{boxproposition}
In computational practice (for example using symbolic calculation software such as MATLAB or Python), the brackets are calculated in ascending order of degree and those that do not increase the rank are immediately discarded, blocking the algorithm as soon as the rank is equal to $n$.\bigskip 
\subsection{The Unicycle Case}
The unicycle model is:\begin{equation}
    \dq=\underbrace{\begin{pmatrix}
        \cos\theta\\\sin\theta\\0 
    \end{pmatrix}}_{\mathbf g_1}v+\underbrace{\begin{pmatrix}
        0\\0\\1  
    \end{pmatrix}}_{\mathbf g_2}\omega
\end{equation}
we compute the first order Lie bracket:\begin{equation}
    \mathbf g_3(\q):=[\mathbf g_1,\mathbf g_2](\q)=-\begin{pmatrix}
        0&0&-\sin\theta\\ 
        0&0&\cos\theta \\ 
        0&0&0
    \end{pmatrix}\begin{pmatrix}
        0\\0\\1 
    \end{pmatrix}=\begin{pmatrix}
       \sin\theta\\-\cos\theta\\ 0
    \end{pmatrix}
\end{equation}
we denote $\mathbf g_3$ the Lie bracket, notice how is the unit vector orthogonal to the sagittal axis, called the \textbf{slide vector field}. Let's check the matrix given by $\mathbf g_1,\mathbf g_2,\mathbf g_3$:\begin{equation}
    \text{rank}\begin{pmatrix}
        \cos\theta&0&\sin\theta\\ 
        \sin\theta&0&-\cos\theta\\ 
        0&1&0
    \end{pmatrix}= \text{rank}\begin{pmatrix}
        \cos\theta&\sin\theta&0\\ 
        \sin\theta&-\cos\theta&0\\ 
        0&0&1
    \end{pmatrix}=3
\end{equation}
The rank is full, we don't have to check the higher order Lie brackets, hence the system is controllable.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.3\textwidth ]{images/slide_vector.eps}
\end{figure}
In this case the Lie bracket defines a velocity that is immediately unrealizable, but specifies a direction achievable through a sequence of motions.
\subsection{The Bicycle Case}
The model of the bicycle is:\begin{equation}
    \dq=
\underbrace{\begin{pmatrix}
        \cos\theta\\\sin\theta\\\frac{1}{l}\tan\phi\\0 
    \end{pmatrix}}_{\mathbf g_1}u_1+\underbrace{\begin{pmatrix}
        0\\0\\0\\1  
    \end{pmatrix}}_{\mathbf g_2}u_2
\end{equation}
the first Lie bracket (we don't show the computation) is:\begin{equation}
    \mathbf g_3(\q):=[\mathbf g_1,\mathbf g_2](\q)=\begin{pmatrix}
        0\\0\\-\frac{1}{l\cos^2\phi}\\0
    \end{pmatrix}
\end{equation}
this vector is called \textbf{wriggle} and is clearly linearly independent from the others, hence the rank is at least 3. Let's compute the second order Lie bracket:\begin{equation}
    \mathbf g_4:=[\mathbf g_1,\mathbf g_3](\q)=\begin{pmatrix}
        -\frac{\sin\theta}{l\cos^2\phi} 
        \\\frac{\cos\theta}{l\cos^2\phi} \\0\\0
    \end{pmatrix}
\end{equation}
$\mathbf g_4$ is parallel to the slide vector field.
It can be verified that:\begin{equation}
    \text{rank}\begin{pmatrix}
        \cos\theta&0&0& -\frac{\sin\theta}{l\cos^2\phi} \\
        \sin\theta&0&0&\frac{\cos\theta}{l\cos^2\phi}\\
        \frac{1}{l}\tan\phi&0&-\frac{1}{l\cos^2\phi}&0\\
        0&1&0&0
    \end{pmatrix}=4
\end{equation}
hence the model is controllable.
\subsection{Chained-Form}
\begin{boxdefinition}{Chained-Form Systems}{}
    Consider a nonlinear system with an $n$-dimensional state vector $\mathbf z\in\R^n$ and $2$ inputs $\mathbf w\in \R^2$. The system is in chained-form if has the following structure:\begin{align}
        \dot z_1&=w_1\\ 
        \dot z_2&=w_2\\
        \dot z_3&=z_2w_1\\ 
        \dot z_4&=z_3w_1\\ \vdots \\ 
        \dot z_n&=z_{n-1}w_1.
    \end{align}
\end{boxdefinition}
\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth ]{images/chained_form.eps}
    \caption{Block diagram of a chained-form system.}
\end{figure}
We can observe how, if the inputs $\mathbf w$ are constant, the system becomes linear, hence in digital control, where the inputs are piece-wise constants, the system is piece-wise linear. 
\begin{boxproposition}{}{}
    Any chained-form system is controllable.
\end{boxproposition}
All the controllable driftless systems (that are the systems of our interest for the kinematic model of the mobile robots) can be rewritten in chained-form under a coordinate and inputs transformation:\begin{align}
    \mathbf z=&\alpha(\q)\\ 
    \mathbf w=&\beta(\q)\mathbf u.
\end{align}
Now we will show how to transform the unicycle model in chained-form. The original model is:\begin{align}
    \dot x&=v\cos\theta\\ 
    \dot y &= v\sin\theta\\ 
    \dot\theta&=\omega
\end{align}
we define the following transformation for the coordinates:\begin{equation}\label{coord_transform}
   \mathbf z=\alpha(\q)=\begin{cases}
   z_1=\theta\\
   z_2=x\cos\theta+y\sin\theta\\ 
   z_3=x\sin\theta-y\cos\theta
   \end{cases} 
\end{equation}
and the following transformation for the inputs:\begin{equation}
    \mathbf w=\beta(\q)\begin{pmatrix}
    v\\\omega
    \end{pmatrix}=\begin{cases}
   w_1=\omega\\ w_2=v-z_3\omega
   \end{cases}.
\end{equation}
Now we rewrite the model and see if it is in chained-form. From Equation \eqref{coord_transform} we get:\begin{align}
    \dot z_1=\dot\theta=\omega=w_1 
\end{align} 
then:\begin{align}
    \dot z_2&=\underbrace{\dot x\cos\theta+\dot y\sin\theta}_{v}-x\sin\theta\dot\theta+y\cos\theta\dot \theta\\
    &=v-\underbrace{\dot\theta}_{\omega}\underbrace{(x\sin\theta-y\cos\theta)}_{z_3}
    =\underbrace{v-\omega z_3=w_2}_{\text{input transformation}}
\end{align}
ultimately:\begin{align}
    \dot z_3&=\dot x\sin\theta-\dot y\cos\theta-x\cos\theta\dot\theta+y\sin\theta\dot\theta\\
    &= \underbrace{(\dot{x} \sin\theta - \dot{y} \cos\theta)}_{0\text{ due to the constraint}} + \dot{\theta}(x \cos\theta + y \sin\theta)\\[1.5ex]
    &=\underbrace{\dot{\theta}}_{\omega=w_1}\underbrace{(x \cos\theta + y \sin\theta)}_{z_2}=z_2w_1
\end{align}
so the model after the transformations is:\begin{align}
    \dot z_1&=w_1\\ 
    \dot z_2&=w_2\\ 
    \dot z_3&=z_2w_1
\end{align}
and it is in chained-form. $z_2$ and $z_3$ have a clear interpretation, are the coordinates of the unicycle in the reference frame with its horizontal axis rotated by $\theta$ with respect to the base frame, as shown in Figure \ref{z2z3}.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/z2z3.eps}
    \caption{Interpretation of $z_2$ and $z_3$.}
    \label{z2z3}
\end{figure}

Setting aside the unicycle model: an interesting property of \textbf{trailed vehicles} emerges when considering a car-like robot: if the trailer is hitched exactly at the midpoint between the two rear wheels (denoted by the point $(x,y)$), the resulting kinematic model can still be converted into chained-form. This property holds recursively if the trailer itself has two rear wheels and an additional trailer is hitched at their midpoint, the overall kinematic model can still be expressed in chained-form.
\section{Path and Trajectory Planning}
It is in our interest to define a method to \textit{plan} a motion that transfers a mobile robot from an initial configuration $\q_i$ to a final configuration $\q_f$, hence, we should define a trajectory:\begin{equation}
    \q(s),\quad s\in[s_i,s_f]
\end{equation}
such that $\q(t_i)=\q_i$ and $\q(t_f)=\q_f$, without violating the kinematic constraints on $\dq$. In general, as we have already seen in previous robotics courses, we separate the geometric path from the timing law:\begin{align}
    \q(s),\quad &s\in [s_i,s_f]\\
    s(t),\quad &t \in [t_i,t_f].
\end{align}
The path parameter $s$ is usually chosen as the arc length.\begin{itemize}
    \item By \textbf{path planning} we mean the plan of a geometric path $\q(s)$ in the configuration space.
    \item By \textbf{trajectory planning} instead, we also include the time, i.e. we mean the plan of a time evolution of the configuration: $\q(t)$. This is usually done indirectly: first plan a path, then add a timing law.
\end{itemize}
We already specified that a trajectory $\q(s(t))$ must satisfy the constraints:\begin{equation}
    \dq=\frac{d\q}{dt}=\frac{d\q}{ds}\dot s = \q'\dot s
\end{equation}
we denote $\q'$ the derivative of $\q$ with respect to $s$, this represents the \textit{tangent vector} of the geometric path in the configuration space. If $s$ is the arc length, then $\| \q'\|=1$.\bigskip

\noindent\textbf{Example}: Consider a robot with $\q=(x,y)$, we want to go from $(1,0)$ to $(0,1)$, one possible choice for the geometric path is:\begin{equation}
    \q(s)=\begin{cases}
        \cos s\\ 
        \sin s 
    \end{cases}
\end{equation}
with $s\in\left[0,\frac{\pi}{2}\right]$. This is exactly the arc length, indeed:\begin{equation}
    \q'(s)=\begin{cases}
        -\sin s\\ 
        \cos s 
    \end{cases}\implies \| \q'(s)\|=\sqrt{(-\sin s)^2+\cos^2 s }=1.
\end{equation}
Another choice of parametrization is\begin{equation}
    \q(s)=\begin{cases}
        \sqrt{1-s^2}\\
        s
    \end{cases}
\end{equation}
with $s\in [0,1]$, here it's not the arc length:\begin{equation}
    \q'(s)=\begin{cases}
        -\frac{s}{\sqrt{1 - s^2}}
        \\ 1
    \end{cases}\implies \| \q'(s)\|= \frac{1}{\sqrt{1 - s^2}}.
\end{equation}
Now we take into account the kinematic constraints, we know that:\begin{equation}
    A(\q)\dq=\mathbf 0 
\end{equation}
$\dq$ is the time derivative of the planned trajectory $\q(s(t))$:\begin{equation}
     A(\q)\dq=A(\q)\q'\dot s=\mathbf 0\implies A(\q)\q'=\mathbf 0  
\end{equation}
we have assumed $\dot s\ne 0$, the result is that the tangent vector $\q'$ must lie in the null space of $A$:\begin{equation}
    \q'\in \mathcal N(A )
\end{equation}
hence $\q'$ can be expressed as a linear combination of the basis vectors $\mathbf g_1,\dots, \mathbf g_m$, exactly as the kinematic model, hence we can write the so-called \textbf{geometric model}:\begin{equation}
    \q'=G(\q)\tilde{\mathbf u}
\end{equation}
this model describes explicitly the admissible tangent vectors. $\tilde{\mathbf u}$ is the vector of the \textbf{geometric inputs}, by multiplying both sides by $\dot s$ we can conclude that:\begin{equation}
   \underbrace{\mathbf u(t)}_{\text{pseudo velocity}} = \tilde{\mathbf u}(s)\dot s(t).
\end{equation}
After we have decided a profile for the geometric inputs $\tilde{\mathbf u}(s)$, we have determined a geometric path in the configuration space, only after having defined also $s(t)$ this will identify a particular trajectory.\bigskip

\noindent\textbf{Example}: Let's apply this reasoning to the unicycle model, the pure rolling constraint for the tangent vector is:\begin{equation}
    \begin{pmatrix}
        \sin\theta&-\cos\theta&0
    \end{pmatrix}\q'=0
\end{equation}
this means that the tangent vector $\q'$ must always be aligned with the sagittal axis of the unicycle: paths such as the one in Figure \ref{non_admissible_path} are not admissible.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth ]{images/inadmissible.eps}
    \caption{Geometric path with tangent vector non-aligned with the sagittal axis.}
    \label{non_admissible_path}
\end{figure}
\subsection{Flat Outputs}
\begin{boxdefinition}{Differential Flatness}{flatness}
    Consider a general nonlinear system \begin{equation}
        \dot{\mathbf x}=f(\mathbf x)+G(\mathbf x)\mathbf u.
    \end{equation}
    The system is \textbf{differentially flat} if there exists a vector $\y=\Psi(\mathbf x)$, called the \textbf{flat outputs}, such that the
state and the control inputs can be expressed
algebraically as a function of $\mathbf y$ and its time derivatives up to a finite order:\begin{align}
    \mathbf x &= \Phi_x(\y,\dy,\ddy,\dots,\mathbf y^{(r_x)})\\
    \mathbf u &= \Phi_u(\y,\dy,\ddy,\dots,\mathbf y^{(r_u)})
\end{align}
\end{boxdefinition}
In Definition \ref{def:flatness} we talk about time derivatives (since that is the domain of dynamical systems), but of course it also holds if all the derivatives are taken with respect to the parameter $s$ (the case of our geometric model). The flatness property is useful in control, if we define a trajectory for $\mathbf y$ that is differentiable up to the $\max(r_x,r_u)$ order, we can reconstruct the state evolution $\mathbf x$ and the required inputs $\mathbf u$ through the reconstruction maps $\Phi_x,\Phi_u$.\bigskip 

\noindent We immediately show this property with the unicycle model.\begin{align}
x'&=\tilde v\cos\theta\\
y'&=\tilde v\sin\theta\\
\theta'&=\tilde\omega
\end{align} The intuition behind flatness is the following: If I know perfectly the path of the Cartesian position of the unicycle $(x,y)$, I can infer what the path of the orientation $\theta$ is, together with the input profile that executes that path. For example, by knowing $(x(s),y(s))$, I can conclude that, at a given $s=s^*$, the orientation must be aligned with the direction of motion, i.e. the vector $(x'(s^*),y'(s^*))$.\begin{equation}
    \theta(s)=\Phi_x(x',y')=\text{atan2}(y'(s),x'(s))+k\pi.
\end{equation}
$k\in \{0,1\}$ is a constant that defines the direction of motion.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth ]{images/flat_output_1.eps}
\end{figure}
Also the input $\tilde v$ can be reconstructed from the path of $x,y$, since it is exactly the norm of the Cartesian velocity:\begin{equation}\label{tildev}
    \begin{cases}
       x'=\tilde v\cos\theta\\
y'=\tilde v\sin\theta
    \end{cases}\implies \tilde v = \pm\sqrt{(x')^2+(y')^2}
\end{equation}
the same can be done for the angular velocity (we skip the proof):\begin{equation}\label{tildeOmega}
    \tilde{\omega} = \frac{y'' x' - x'' y'}{(x')^2 + (y')^2}.
\end{equation}
Equations \eqref{tildev},\eqref{tildeOmega} are the reconstruction map for the input $\tilde{\mathbf u}=\Phi_u(x',y',x'',y'')$. These reconstructions have a problem that arises if $x'=y'=0$: atan2 is not defined and $\tilde\omega$ would have a zero in the denominator. This singularity has an intuitive meaning: if the robot stops and its Cartesian velocity is zero, we cannot know whether it is steering in place or not, hence we cannot infer the evolution of $\theta(s)$ when it is not moving.
\begin{boxproposition}{}{flat_chained}
    A driftless dynamic system is differentially flat if and only if it can be transformed into chained-form.
\end{boxproposition}
\begin{boxproposition}{}{}
    A general dynamic system is differentially flat if and only if it can be linearized via dynamic feedback.
\end{boxproposition}
The wheeled robots in our interest can be put in chained-form, hence, they admit flat outputs, this is a great simplification from a control point of view, since we can directly execute a desired trajectory through the reconstruction maps. Let's see the flat outputs for the bicycle, the model is:\begin{align}
    x'&=\tilde v\cos\theta\\
y'&=\tilde v\sin\theta\\
\theta'&=\frac{\tilde v}{l}\tan\phi\\
\phi'&=\tilde\omega
\end{align}
$x,y,\theta$ can be reconstructed in the same way as for the unicycle case, to reconstruct $\phi$ we use $\theta'$:\begin{align}
    \theta(s)&=\text{atan2}(y',x')+k\pi\\ 
    \implies \theta'(s)&= \frac{x' y'' - y' x''}{(x')^2 + (y')^2}
\end{align}
hence\begin{align}
    \theta'&=\frac{\tilde v}{l}\tan\phi\\
    \implies\phi(s)&=\arctan\left(\frac{l\theta'}{\tilde v}\right)\\[1.5ex]
    &=\arctan\left(\frac{l\frac{x' y'' - y' x''}{(x')^2 + (y')^2}}{\pm\sqrt{(x')^2+(y')^2}}\right)\\ &=
    \arctan\left(\pm \frac{l(x' y'' - y' x'')}{\left((x')^2 + (y')^2\right)^{3/2}}\right).
\end{align}
Now we use Proposition \ref{def:flat_chained} and show how a 2-input/3-state chained-form system admits flat outputs. The system is the following:\begin{align}
    z_1'&=\tilde w_1\\ 
    z_2'&=\tilde w_2\\ 
    z_3'&=z_2\tilde w_1
\end{align}
for a chained-form system the flat outputs \textbf{are always the first and the last variables}:\begin{equation}
    \y=\begin{pmatrix}
        z_1\\ z_3
    \end{pmatrix}
\end{equation}
the reconstruction maps are the following:\begin{align}
    \Phi_x(z'_1,z'_3)&=\frac{z'_3}{z'_1}\\
    \Phi_u(z'_1,z''_1,z'_3,z''_3)&=\begin{cases}
        \tilde w_1=z_1'\\
        \tilde w_2=\dfrac{z_1'z_3''-z_1''z_3'}{(z'_1)^2}
    \end{cases}.
\end{align}
\subsection{Path Planning for the Unicycle}
Any flat-output profile is automatically mapped to an admissible path. An algorithm for path planning exploiting differential flatness is the following:\begin{enumerate}
    \item Compute the initial and final values $\y_i,\y_f$ for the flat outputs from $\q_i,\q_f$.
    \item Define $\y(s)$ by interpolating $\y_i,\y_f$ with the appropriate boundary conditions for $\q$.
    \item Use the reconstruction formulas to find $\q(s)$ and $\tilde{\mathbf u}(s)$.
\end{enumerate}
The same algorithm is valid for trajectory planning by interpolating over $t$ instead of $s$. Let's apply this algorithm to the unicycle. We use a parametrization with $s\in[0,1]$, from \begin{equation}
    \q_i=\begin{pmatrix}
        x_i\\y_i\\\theta_i
    \end{pmatrix},\quad
    \q_f=\begin{pmatrix}
        x_f\\y_f\\\theta_f
    \end{pmatrix}
\end{equation}
we extract\begin{equation}
    \y_i=\begin{pmatrix}
        x_i\\y_i
    \end{pmatrix},\quad
    \y_f=\begin{pmatrix}
        x_f\\y_f
    \end{pmatrix}
\end{equation}
and perform an interpolation between these two points with a cubic polynomial function:\begin{align}
    &x(s)=s^3x_f-(s-1)^3x_i+\alpha_xs^2(s-1)+\beta_xs(s-1)^2\\ 
    &y(s)=s^3y_f-(s-1)^3y_i+\alpha_ys^2(s-1)+\beta_ys(s-1)^2
\end{align}
this polynomial already satisfies the boundary conditions:\begin{align}
    x(0)=x_i,\quad x(1)=x_f\\ 
    y(0)=y_i,\quad y(1)=y_f
\end{align}
then $\alpha_x,\beta_x,\alpha_y,\beta_y$ must be chosen in order to satisfy two additional boundary conditions that come from the kinematic constraints, $(x',y')$ must be aligned with $\theta$, and $\theta_i,\theta_f$ are given, hence there are the following conditions:\begin{align}
    \text{atan2}(y'(0),x'(0))&=\theta_i\\\text{atan2}(y'(1),x'(1))&=\theta_f.
\end{align}

The initial and final Cartesian velocities must be:\begin{align}
    x'(0)&=k_i\cos\theta_i,\quad x'(1)=k_f\cos\theta_f\\ 
    y'(0)&=k_i\sin\theta_i,\quad y'(1)=k_f\sin\theta_f
\end{align}
with $k_i,k_f$ being two arbitrary non-zero constants, for simplicity we set $k_i=k_f=k$. To impose these conditions, we can solve algebraically for $\alpha_x,\beta_x,\alpha_y,\beta_y$ and obtain:\begin{align}
    \alpha_x&=k\cos\theta_f-3x_f,\quad \beta_x=k\cos\theta_i+3x_i\\
    \alpha_y&=k\sin\theta_f-3y_f,\quad \beta_y=k\sin\theta_i+3y_i.
\end{align}
It will be $\tilde v(0)=\tilde v(1)=k$, hence $k$ can be chosen to shape the trajectory, by affecting the length of the first and last ``linear'' segments of the path, as shown in Figure \ref{k_shape}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/k_shape.eps}
    \caption{Difference between two paths with the same interpolating points but different choice of $k$.}
    \label{k_shape}
\end{figure}
\subsection{Path Planning for a Chained-Form System}
Consider a 2-input/3-state chained-form system, we apply the path planning algorithm to this case. We recall that the flat outputs are $z_1,z_3$, hence we have to interpolate $(z_{1i},z_{3i})$ with $(z_{1f},z_{3f})$. We interpolate linearly $z_1$ and with a cubic polynomial $z_3$:\begin{align}
    z_1(s)&=z_{1i}+s(z_{1f}-z_{1i})\\
    z_3(s)&=s^3z_{3f}-(s-1)^3z_{3i}+\alpha_3s^2(s-1)+\beta_3s(s-1)^2
\end{align}
that already satisfies the boundary conditions on $z_1,z_3$. We must impose the additional boundary conditions for $z_2$:\begin{equation}
    z_{2i}=\frac{z_3'(0)}{z_1'(0)},\quad 
    z_{2f}=\frac{z_3'(1)}{z_1'(1)}
\end{equation}
we solve for $\alpha_3,\beta_3$:\begin{align}
    \alpha_3&=z_{2f}(z_{1f}-z_{1i})-3z_{3f}
    \\
    \beta_3&=z_{2i}(z_{1f}-z_{1i})+3z_{3i}
\end{align}
After having $z_1(s),z_3(s)$ we can reconstruct $z_2(s),\tilde w_1(s),\tilde w_2(s)$ through the reconstruction maps, then $\q(s),\tilde v(s),\tilde\omega(s)$ are computed by inverting
the chained form coordinate and input transformation. 

By recalling that $z_1=\theta$: one problem arises when the initial and final orientations are identical $z_{1i}=z_{1f}$, since we would have:\begin{equation}
    z_1'(s)=z_{1f}-z_{1i}=0
\end{equation}
and then $z_{2i},z_{2f}$ can't be inferred since we would have a division by zero, in that case it is sufficient to set:\begin{equation}
    z_{1f}=z_{1i}+2\pi
\end{equation}
or add a mid-point $\q_m=\begin{pmatrix}
    x_m&y_m&\theta_m
\end{pmatrix}$ in the trajectory with $\theta_m\ne\theta_i$.
\subsection{Path Planning via Parametrized Inputs}
A different approach, not directly based on flatness,
consists of writing the inputs in parametrized form and
then imposing that the robot goes from $\q_i$ to $\q_f$. We assume that the $n$-state robot model can be rewritten in chained form:\begin{equation}\label{chained_form}\begin{cases}
    z_1'=\tilde w_1\\
    z_2'=\tilde w_2\\
    z_3'=z_2\tilde w_1\\\vdots\\
    z_n'=z_{n-1}\tilde w_1
\end{cases}\end{equation}
which is linear in $\mathbf z$ when $\tilde w_1$ is constant. Let $\mathbf z_i,\mathbf z_f$ be the initial and final configurations in the chained-form system coordinates, we define $\Delta$ as the difference between the final and initial values for $z_1$:\begin{equation}
    \Delta=z_{1f}-z_{1i}
\end{equation}
and we choose the following profiles for the geometric inputs:\begin{equation}
    \begin{cases}
        \tilde w_1=\text{sign}(\Delta)\\ 
        \displaystyle\tilde w_2=\sum_{j=0}^{n-2}c_js^j 
    \end{cases}\quad s\in[0,|\Delta|]
\end{equation}
by doing so, we can integrate $z_2'=\tilde w_2$ analytically to get the profiles (as functions of $s$) of $z_2,z_3,\dots,z_n$, and impose $z_j(|\Delta|)=z_{jf}$ for each $j$. This leads to a linear system of the following form:\begin{equation}
    D(\Delta)\begin{pmatrix}
        c_0\\c_1\\\vdots\\ c_{n-2}
    \end{pmatrix}=\mathbf d(\mathbf z_i,\mathbf z_f,\Delta)
\end{equation}
if $D(\Delta)$ is invertible we can find the values for the coefficients. For example, with a system of 2 inputs and 3 states:\begin{equation}
    D=\begin{pmatrix}
        |\Delta|&\nicefrac{\Delta^2}{2}\\ 
        \text{sign}(\Delta)\nicefrac{\Delta^2}{2}&\nicefrac{\Delta^3}{6}
    \end{pmatrix},\quad
    \mathbf d=\begin{pmatrix}
        z_{2f}-z_{2i}\\
        z_{3f}-z_{3i}-z_{2i}\Delta
    \end{pmatrix}
\end{equation}
\subsection{Choice of the Timing Law}
We have separated the timing law $s(t)$ from the geometric path $\q(s)$, now we have to assign a timing law that interpolates $s_i$ to $s_f$:\begin{equation}
    s(t_i)=s_i,\quad s(t_f)=s_f.
\end{equation}
We will select a timing law that is monotonic increasing, since it does not have any meaning for the trajectory to go backwards (in that case, this has to be defined geometrically), hence:\begin{equation}
    \dot s >0.
\end{equation}
The simplest timing law is given by linear interpolation:\begin{equation}
    s(t)=s_i+\frac{s_f-s_i}{t_f-t_i}(t-t_i)
\end{equation}
usually we use $t\in[0,T]$:
\begin{equation}
    s(t)=s_i+(s_f-s_i)\frac{t}{T}.
\end{equation}
One of the most used timing laws is the bang-coast-bang acceleration profile (\textbf{trapezoidal timing law}), since it starts and ends with zero velocity.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth ]{images/trapezoidal_timing_law.eps}
\end{figure}\begin{equation}
    \ddot s(t)= \begin{cases}
        a_{max}&\text{ if }t\in[t_i,t_i+t_m]\\
        0&\text{ if }t\in(t_i+t_m,t_f-t_m]\\
        -a_{max}&\text{ if }t\in(t_f-t_m,t_f]
    \end{cases}.
\end{equation}
Now let's take into account the bounds on velocity, for example, consider a unicycle subject to the following bounds for the linear and angular velocities:\begin{equation}
    |v|\le v_{max},\quad |\omega|\le \omega_{max}
\end{equation}
assume that a path $\q(s)$ has already been generated, with geometric inputs $\tilde v(s)$ and $\tilde\omega(s)$, we choose a linear timing law parametrized by a positive real number $k$:\begin{equation}
    s(t)=s_i+\frac{t}{k},\quad t\in [0,k(s_f-s_i)].
\end{equation}
We assume that $\q(s)$ is defined such that $s$ is the arc length. The timing law derivative is $\dot s = \frac{1}{k}$, with\begin{equation}
    v(t)=\frac{\tilde v(s(t))}{k},\quad \omega(t)=\frac{\tilde\omega(s(t))}{k}
\end{equation}
in order to respect the bounds we have to choose $k$ as follows:\begin{equation}
    k=\max\left\{
        \frac{\tilde v_{peak}}{v_{max}},
         \frac{\tilde \omega_{peak}}{\omega_{max}}
    \right\}
\end{equation}
where\begin{align}
    \tilde v_{peak}&=\max_{s\in[s_i,s_f]}|\tilde v(s)|\\
    \tilde \omega_{peak}&=\max_{s\in[s_i,s_f]}|\tilde \omega(s)|.
\end{align}
\chapter{Motion Control}
In order to follow a desired trajectory, or to regulate the robot into a desired configuration, we can't simply proceed by applying the necessary inputs computed from the flat outputs, in order to reject the disturbances and the errors we must add a feedback action. In previous robotics courses, we have considered the dynamic model of the manipulators, controlled by the torques on the joints, for wheeled mobile robotics we can consider only the kinematic model, since the dynamic model is simpler, can be canceled via feedback and the wheels are always equipped with low-level control loops that can regulate velocities in a very reliable way.

We cover two type of control tasks, \textit{trajectory tracking} and \textit{regulation}, we will provide a full description of this problem for the unicycle model.
In \textbf{trajectory tracking} the robot must converge to a desired Cartesian trajectory $(x_d(t),y_d(t))$, while in \textbf{posture regulation} the robot must converge to a desired configuration $\q_d$. Trajectory tracking is more relevant in practice, since moving along planned trajectories reduces the risk of collision, however, posture regulation does not require any planning.
\section{Trajectory Tracking}
Let $(x_d(t),y_d(t))$ be an admissible desired trajectory for the unicycle, there exists control inputs $v_d,\omega_d$ such that:\begin{equation}
    \begin{cases}
        \dot x_d=v_d\cos\theta_d\\
        \dot y_d=v_d\sin\theta_d\\
        \dot\theta_d=\omega_d
    \end{cases}.
\end{equation}
Thanks to the flatness property, from the desired trajectory $(x_d(t),y_d(t))$ we can compute the evolution of the full state and the required inputs:\begin{align}
    \theta_d(t)&=\text{atan2}(\dot y_d(t),\dot x_d(t))+k\pi\quad k\in\{0,1\}\\
    v_d(t)&=\pm\sqrt{\dot x_d^2(t)+\dot y_d^2(t)}\\
    \omega_d(t)&=\frac{\ddot y_d(t)\dot x_d(t)-\ddot x_d(t)\dot y_d(t)}{\dot x^2_d(t)+\dot y^2_d(t)}.
\end{align}
We recall that an admissible trajectory requires $(\dot x_d(t),\dot y_d(t))$ to be continuous over time, the desired state trajectory $\q_d(t)$ that comes from the flat outputs will be used to compute the state error, then used in the controller. The resulting block diagram will be:
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/motion_control_scheme3.png}
\end{figure}
The objective is to drive the state error to zero, we will express the error in a coordinate frame rotated by $\theta$, with its $x$-axis parallel to the sagittal axis of the robot:\begin{equation}
    \mathbf e = \begin{pmatrix}
        e_1\\e_2\\ e_3
    \end{pmatrix}=\begin{pmatrix}
        \cos\theta&\sin\theta&0\\
        -\sin\theta&\cos\theta&0\\
        0&0&1
    \end{pmatrix}\begin{pmatrix}
        x_d-x\\ y_d-y\\ \theta_d-\theta 
    \end{pmatrix}.
\end{equation}
$(e_1,e_2)$ is the Cartesian error $\mathbf e_p=(x_d-x,\;y_d-y)^\top$ expressed in a frame rotated by $\theta$, shown in Figure \ref{fig:cart_error}. Differentiating $\mathbf e$ and using the unicycle kinematic model together with the desired one, we obtain the \textbf{error dynamics}:\begin{align}
    \dot e_1&=v_d\cos e_3-v+e_2\,\omega\\
    \dot e_2&=v_d\sin e_3-e_1\,\omega\\
    \dot e_3&=\omega_d-\omega
\end{align}
which is \textbf{nonlinear} and \textbf{time-varying}, since it depends on the reference inputs $v_d(t),\omega_d(t)$.

\subsection{Approximate Linearization}
Before applying it to the unicycle, let us recall the idea of stabilization via approximate linearization: to stabilize a nonlinear system at an equilibrium, we stabilize its approximate linearization around it. Consider a generic nonlinear system\begin{equation}
    \dot{\mathbf x}=\boldsymbol\eta(\mathbf x,\mathbf u)=f(\mathbf x)+G(\mathbf x)\mathbf u\qquad \mathbf x\in\R^n,\ \mathbf u\in\R^m
\end{equation}
and assume, without loss of generality, that the origin is the desired \textbf{unforced equilibrium}, i.e. $\boldsymbol\eta(\mathbf 0,\mathbf 0)=\mathbf 0$, or equivalently $f(\mathbf 0)=\mathbf 0$. The first-order Taylor expansion of $\boldsymbol\eta$ around $\mathbf x=\mathbf 0,\mathbf u=\mathbf 0$ gives\begin{equation}
    \boldsymbol\eta(\mathbf x,\mathbf u)\approx\underbrace{\boldsymbol\eta(\mathbf 0,\mathbf 0)}_{=\,\mathbf 0}+\left.\frac{\partial\boldsymbol\eta}{\partial\mathbf x}\right|_{\substack{\mathbf x=\mathbf 0\\\mathbf u=\mathbf 0}}\mathbf x+\left.\frac{\partial\boldsymbol\eta}{\partial\mathbf u}\right|_{\substack{\mathbf x=\mathbf 0\\\mathbf u=\mathbf 0}}\mathbf u
\end{equation}
and the \textbf{approximate linearization} of the system at the origin is\begin{equation}
    \dot{\mathbf x}=A\mathbf x+B\mathbf u
\end{equation}
where $A$ and $B$ are the two Jacobian matrices evaluated at the origin. Let now $\mathbf u=K\mathbf x$, so that\begin{equation}
    \dot{\mathbf x}=A\mathbf x+BK\mathbf x=(A+BK)\mathbf x.
\end{equation}
If $K$ is chosen in such a way that $A+BK$ is \textbf{Hurwitz}\footnote{Its eigenvalues have strictly negative real part.} (certainly possible if $(A,B)$ is controllable), then the approximate linearization is asymptotically stable.
\begin{boxtheorem}{Lyapunov Indirect Method}{}
    If the approximate linearization of a nonlinear system at an equilibrium is asymptotically stable, then the equilibrium is \textbf{locally} asymptotically stable for the nonlinear system.
\end{boxtheorem}
Let us apply this approach to the error dynamics of the unicycle. In the form we derived, the origin is \textbf{not} an unforced equilibrium: for $\mathbf e=\mathbf 0$ the terms $v_d-v$ and $\omega_d-\omega$ must vanish to have $\dot{\mathbf e}=\mathbf 0$. This is easily rectified by the following (invertible) input transformation:\begin{align}
    w_1&=v_d\cos e_3-v\\
    w_2&=\omega_d-\omega
\end{align}
and, by substituting $\omega=\omega_d-w_2$, the error dynamics $\dot{\mathbf e}=\boldsymbol\eta(\mathbf e,\mathbf w)$ takes the form\begin{equation}
    \dot{\mathbf e}=\underbrace{\begin{pmatrix}
        \omega_d e_2\\ -\omega_d e_1+v_d\sin e_3\\ 0
    \end{pmatrix}}_{f(\mathbf e)}+\underbrace{\begin{pmatrix}
        1&-e_2\\ 0&e_1\\ 0&1
    \end{pmatrix}}_{G(\mathbf e)}\begin{pmatrix}
        w_1\\ w_2
    \end{pmatrix}
\end{equation}
which is at rest when $\mathbf e=\mathbf 0,\mathbf w=\mathbf 0$, i.e. $\boldsymbol\eta(\mathbf 0,\mathbf 0)=\mathbf 0$. Both the drift and the input term are nonlinear, and in general the drift is also time-varying. The Jacobian matrices are\begin{equation}
    \frac{\partial\boldsymbol\eta}{\partial\mathbf e}=\begin{pmatrix}
        0&\omega_d-w_2&0\\
        -\omega_d+w_2&0&v_d\cos e_3\\
        0&0&0
    \end{pmatrix}\qquad
    \frac{\partial\boldsymbol\eta}{\partial\mathbf w}=\begin{pmatrix}
        1&-e_2\\0&e_1\\0&1
    \end{pmatrix}
\end{equation}
and by letting $\mathbf e=\mathbf 0,\mathbf w=\mathbf 0$ we obtain\begin{equation}
    A(t)=\begin{pmatrix}
        0&\omega_d&0\\-\omega_d&0&v_d\\0&0&0
    \end{pmatrix}\qquad B=\begin{pmatrix}
        1&0\\0&0\\0&1
    \end{pmatrix}.
\end{equation}
This system is controllable if and only if the matrix\begin{equation}
    \begin{pmatrix}
        B & AB & A^2B & \dots & A^{n-1}B
    \end{pmatrix}
\end{equation}
have full rank, this can be seen by building just $\begin{pmatrix}
        B & AB 
    \end{pmatrix}$:\begin{equation}
        \text{rank}\begin{pmatrix}
        B & AB 
    \end{pmatrix}=\text{rank}\begin{pmatrix}
        1&0&0&0\\ 
        0&0&-\omega_d&v_d\\ 
        0&1&0&0
    \end{pmatrix}=3.
    \end{equation}
This holds if $\omega_d$ or $v_d$ is non-zero, so the system lose controllability when the unicycle is stopping.
Note that $A$ is actually $A(t)$, due to the dependence of the reference inputs $v_d$ and $\omega_d$ on time, hence the linear approximation is still a \textbf{time-varying} system. Let us define the linear feedback\begin{equation}
    \mathbf w=\begin{pmatrix}
        w_1\\w_2
    \end{pmatrix}=\underbrace{\begin{pmatrix}
        -k_1&0&0\\0&-k_2&-k_3
    \end{pmatrix}}_{K}\begin{pmatrix}
        e_1\\e_2\\e_3
    \end{pmatrix}=K\mathbf e
\end{equation}
the closed-loop error dynamics is\begin{equation}
    \dot{\mathbf e}=(A(t)+BK)\mathbf e=A_{cl}(t)\mathbf e=\begin{pmatrix}
        -k_1&\omega_d&0\\-\omega_d&0&v_d\\0&-k_2&-k_3
    \end{pmatrix}\mathbf e
\end{equation}
which is still time-varying. Letting\begin{equation}
    k_1=k_3=2\zeta a\qquad k_2=\frac{a^2-\omega_d^2}{v_d}
\end{equation}
with $a>0$ and $\zeta\in(0,1)$, the characteristic polynomial of $A_{cl}(t)$ becomes time-invariant and Hurwitz:\begin{equation}
    p(\lambda)=(\lambda+2\zeta a)(\lambda^2+2\zeta a\lambda+a^2)
\end{equation}
it has one real negative eigenvalue and two complex eigenvalues with damping $\zeta$ and natural frequency $a$.
\begin{boxobservation}{Caveats}{}
    Having the eigenvalues of $A_{cl}(t)$ fixed at every instant \textbf{does not guarantee} asymptotic stability of a time-varying system, unless $v_d$ and $\omega_d$ are constant (rectilinear and circular trajectories). Even in this case, the asymptotic stability is only \textbf{local} (not global), since it comes from the indirect Lyapunov method. Moreover, $k_2\to\infty$ as $v_d\to 0$, hence this controller can only be used with \textbf{persistent} Cartesian trajectories (stops are not allowed).
\end{boxobservation}
The \textbf{actual} velocity inputs $v,\omega$ are obtained by plugging the feedback controls $w_1,w_2$ in the input transformation:\begin{align}
    v&=v_d\cos e_3-w_1=v_d\cos e_3+k_1e_1\\
    \omega&=\omega_d-w_2=\omega_d+k_2e_2+k_3e_3.
\end{align}
Note that $(v,\omega)\to(v_d,\omega_d)$ as $\mathbf e\to\mathbf 0$, i.e. the control action reduces to the pure feedforward term. The controller is \textbf{static} and based on the state error, it needs $v_d,\omega_d$ (computed via flatness) and it needs $\theta$ both for the error rotation and for the input transformation.
\textbf{Global stability} can be guaranteed by a nonlinear version of the feedback:\begin{align}
    w_1&=-k_1(v_d,\omega_d)\,e_1\\
    w_2&=-k_2\,v_d\frac{\sin e_3}{e_3}\,e_2-k_3(v_d,\omega_d)\,e_3
\end{align}
with $k_2>0$ constant and $k_1,k_3$ bounded, positive and with bounded derivatives. The actual inputs are then recovered from the same input transformation.
\subsection{Output Error Feedback}
Another approach is to develop the feedback action from the \textbf{output (Cartesian) error} only, without computing a desired state trajectory $\q_d(t)$, using as \textbf{feedforward term} the velocity $\dot{\mathbf p}_d$ along the reference trajectory, where $\mathbf p=(x,y)^\top$ is the Cartesian position of the unicycle and $\mathbf p_d$ the desired one.
We will design this controller through the technique of \textbf{exact input-output linearization}.
\subsubsection*{Exact Input-Output Linearization}
Consider a driftless nonlinear system with the same number of inputs and outputs:\begin{align}
    \dot{\mathbf x}&=G(\mathbf x)\mathbf u\qquad \mathbf x\in\R^n,\ \mathbf u\in\R^m,\ \y\in\R^m\\
    \y&=h(\mathbf x)
\end{align}
differentiating the output we obtain\begin{equation}
    \dy=\frac{\partial h}{\partial\mathbf x}\dot{\mathbf x}=\underbrace{\frac{\partial h}{\partial\mathbf x}G(\mathbf x)}_{T(\mathbf x)}\mathbf u=T(\mathbf x)\mathbf u
\end{equation}
where $T$ is an $m\times m$ matrix called the \textbf{decoupling matrix}. If $T$ is invertible, we can set the \textbf{linearizing feedback}\begin{equation}
    \mathbf u=T^{-1}(\mathbf x)\mathbf w\implies\dy=T(\mathbf x)T^{-1}(\mathbf x)\mathbf w=\mathbf w
\end{equation}
i.e. an \textbf{exactly linear} map between the new linearizing inputs $\mathbf w$ and (the time derivative of) the outputs: under the action of the linearizing feedback the system behaves as a simple (vector) integrator from $\mathbf w$ to $\y$.

Given a reference output $\y_d(t)$, the dynamics of the output error $\mathbf e=\y_d-\y$ is\begin{equation}
    \dot{\mathbf e}=\dy_d-\dy=\dy_d-\mathbf w.
\end{equation}
Let $\mathbf w=\dy_d+K\mathbf e$ (feedforward plus proportional feedback), to obtain\begin{equation}
    \dot{\mathbf e}=-K\mathbf e
\end{equation}
which is \textbf{globally exponentially stable} provided that the eigenvalues of $K$ lie in the right half-plane. The final control law is\begin{equation}
    \mathbf u=T^{-1}(\mathbf x)(\dy_d+K\mathbf e).
\end{equation}
\subsection{Static Feedback}
Let us apply the exact input-output linearization to the unicycle, with output $\mathbf p=(x,y)^\top$. However, the decoupling matrix associated to the Cartesian position turns out to be \textbf{singular}:\begin{equation}
    \begin{pmatrix}
        \dot x\\ \dot y
    \end{pmatrix}=\begin{pmatrix}
        \cos\theta&0\\\sin\theta&0
    \end{pmatrix}\begin{pmatrix}
        v\\ \omega
    \end{pmatrix}
\end{equation}
hence exact input-output linearization is \textbf{not possible} for the output $(x,y)$. The solution is to change slightly the output so that the new input-output map is invertible: we displace the output from the contact point of the wheel to a point $B$ along the sagittal axis, at distance $b$:\begin{equation}
    \begin{pmatrix}
        x_B\\ y_B
    \end{pmatrix}=\begin{pmatrix}
        x+b\cos\theta\\ y+b\sin\theta
    \end{pmatrix}.
\end{equation}
Differentiating with respect to time:\begin{equation}
    \begin{pmatrix}
        \dot x_B\\ \dot y_B
    \end{pmatrix}=\underbrace{\begin{pmatrix}
        \cos\theta&-b\sin\theta\\\sin\theta&b\cos\theta
    \end{pmatrix}}_{T(\theta),\ \det T=b}\begin{pmatrix}
        v\\ \omega
    \end{pmatrix}=T(\theta)\begin{pmatrix}
        v\\ \omega
    \end{pmatrix}.
\end{equation}
If $b\neq 0$ we may set\begin{equation}
    \begin{pmatrix}
        v\\ \omega
    \end{pmatrix}=T^{-1}(\theta)\begin{pmatrix}
        w_1\\ w_2
    \end{pmatrix}=\begin{pmatrix}
        \cos\theta&\sin\theta\\-\dfrac{\sin\theta}{b}&\dfrac{\cos\theta}{b}
    \end{pmatrix}\begin{pmatrix}
        w_1\\ w_2
    \end{pmatrix}
\end{equation}
obtaining an input-output linearized system:\begin{align}
    \dot x_B&=w_1\\
    \dot y_B&=w_2\\
    \dot\theta&=\frac{w_2\cos\theta-w_1\sin\theta}{b}.
\end{align}
We achieve \textbf{global exponential convergence} of $x_B,y_B$ to the desired trajectory by letting\begin{align}
    w_1&=\dot x_d+k_x(x_d-x_B)\\
    w_2&=\dot y_d+k_y(y_d-y_B)
\end{align}
with $k_x,k_y>0$. The orientation $\theta$ is \textbf{not} controlled by this scheme, which is based on output error feedback: there is a \textbf{zero dynamics} (the last equation above). Still, $\theta$ must evolve as dictated by flatness. An advantage of this approach is that the desired trajectory for $B$ can be \textbf{arbitrary}, in particular square corners may be included. The controller is \textbf{static}, based on the output error, it needs $\dot{\mathbf p}_d$, and it needs $x,y,\theta$ for the output reconstruction and $\theta$ also for the input transformation.
\subsection{Dynamic Feedback}
Rather than displacing the controlled output to $B$, we can keep the (flat) output $(x,y)$ and achieve exact linearization by using a \textbf{dynamic compensator}. To do this, we perform a \textbf{dynamic extension} on the driving velocity channel (we ``slow down'' the input), by considering the velocity $v$ as a state of the system and its acceleration $a$ as a new input:\begin{equation}
    \dot v=a.
\end{equation}
We can now differentiate further the output:\begin{align}
    \ddot x&=a\cos\theta-v\sin\theta\,\omega\\
    \ddot y&=a\sin\theta+v\cos\theta\,\omega
\end{align}
the new decoupling matrix is\begin{equation}
    \begin{pmatrix}
        \ddot x\\ \ddot y
    \end{pmatrix}=\underbrace{\begin{pmatrix}
        \cos\theta&-v\sin\theta\\\sin\theta&v\cos\theta
    \end{pmatrix}}_{T(v,\theta),\ \det T=v}\begin{pmatrix}
        a\\ \omega
    \end{pmatrix}=T(v,\theta)\begin{pmatrix}
        a\\ \omega
    \end{pmatrix}
\end{equation}
which is nonsingular if $v\neq 0$. Under this assumption we may set\begin{equation}
    \begin{pmatrix}
        a\\ \omega
    \end{pmatrix}=T^{-1}(v,\theta)\begin{pmatrix}
        w_1\\ w_2
    \end{pmatrix}=\begin{pmatrix}
        \cos\theta&\sin\theta\\-\dfrac{\sin\theta}{v}&\dfrac{\cos\theta}{v}
    \end{pmatrix}\begin{pmatrix}
        w_1\\ w_2
    \end{pmatrix}
\end{equation}
obtaining a fully linearized system $\ddot x=w_1$, $\ddot y=w_2$. We achieve \textbf{global exponential convergence} of $x,y$ to the desired trajectory by letting\begin{align}
    w_1&=\ddot x_d+k_{p,x}(x_d-x)+k_{d,x}(\dot x_d-\dot x)\\
    w_2&=\ddot y_d+k_{p,y}(y_d-y)+k_{d,y}(\dot y_d-\dot y)
\end{align}
with $k_{p,x},k_{p,y},k_{d,x},k_{d,y}>0$. Since we are controlling the original flat output, there is \textbf{no zero dynamics} with this approach. The desired trajectory must be twice differentiable and \textbf{persistent}, i.e. it must be $v_d\neq 0$ always (this singularity is structural in nonholonomic systems). The controller is \textbf{dynamic} (the velocity $v$ is the state of the compensator, obtained by integrating $a$), based on the output error, it needs $\dot{\mathbf p}_d$ and $\ddot{\mathbf p}_d$, and it needs $x,y$ for the error computation and $\theta$ for the input transformation.
\subsection{Comparison of the Controllers}
The three controllers have been compared in simulation while tracking a circle, a square and a figure 8, with the following outcomes.
\begin{itemize}
    \item \textbf{Approximate linearization}: only \textbf{local} stability is guaranteed (and only for constant $v_d,\omega_d$). When tracking a circle it converges to zero error; when tracking a square a new transient appears at each corner; for the figure 8 local stability is not guaranteed, but the observed performance is good.
    \item \textbf{Static input-output linearization}: the steady-state error norm is equal to $b$, since it is the point $B$ that converges to the desired trajectory, while the contact point of the wheel stays at distance $b$ from it. The displaced output provides a \textbf{lookahead} behavior when tracking a square. Reducing $b$ reduces the steady-state error, but the steering velocity increases (the term $1/b$ appears in $T^{-1}$).
    \item \textbf{Dynamic input-output linearization}: zero steady-state error, reasonable velocities and faster transients (e.g. at the corners of the square).
\end{itemize}
\section{Regulation}
Let's address the problem of posture regulation: we want to bring a mobile robot from a starting configuration $\q_i$ to a configuration $\q_d$ with a feedback control law. One may ask, why can't we just use trajectory tracking with a trajectory that ends in the desired configuration $\q_d$? None of the methods described in the previous section works for regulation: the controllers based on approximate linearization and input-output linearization via dynamic feedback require a persistent trajectory. For example, the decoupling matrix $T(v,\theta)$ is not invertible if the desired velocity $v$ is zero. Furthermore, the input-output linearization via static feedback would lead the point $(x_b\quad y_b)^\top$ to the desired destination, and not the wheel contact point.\bigskip

There is a \textit{general result} that shows that nonholonomic systems, like wheeled mobile robots, do not admit universal controllers, i.e., controllers that can stabilize arbitrary
trajectories, whether persistent or not.
\subsection{Recall on Lyapunov Theory}
Let's recap some of the basic results of Lyapunov theory. Consider a general control system:\begin{equation}
    \dot{\mathbf x}=f(\mathbf x,\mathbf u)
\end{equation}
let $\mathbf u=g(\mathbf x)$ be our control input, the closed loop system is:\begin{equation}\label{closed_loop_cs}
    \dot{\mathbf x}=f(\mathbf x,g(\mathbf x))=f'(\mathbf x)
\end{equation}
let $\mathbf x_e$ be an equilibrium point, without loss of generality we can assume that $\mathbf x_e=\mathbf 0$:\begin{equation}
    f'(\mathbf x_e)=f'(\mathbf 0)=\mathbf 0.
\end{equation}
\begin{boxtheorem}{Lyapunov Stability}{}
    Consider the closed loop control system of Equation \eqref{closed_loop_cs}. If there exists a positive definite function $V(\mathbf x)$ such that the following holds:\begin{itemize}
        \item If $\dot V$ is negative definite, then the equilibrium $\mathbf x_e=\mathbf 0$ is asymptotically stable.
        \item If $\dot V$ is negative semi-definite, then the equilibrium $\mathbf x_e=\mathbf 0$ is stable (not asymptotically).
    \end{itemize}
\end{boxtheorem}
\begin{boxlemma}{Barbalat}{}
    Consider the closed loop control system of Equation \eqref{closed_loop_cs}, and let $V$ be a function of the state such that
    \begin{itemize}
        \item $V$ is positive semi-definite
        \item $\dot V$ is negative semi-definite
    \end{itemize}
    if $\ddot V$ is bounded, then $\displaystyle\lim_{t\rightarrow\infty}\dot V(t)=0$, hence $V$ converges to a limit:\begin{equation}
        \lim_{t\rightarrow\infty} V(t)=V_l\in[0,+\infty).
    \end{equation}
\end{boxlemma}
\subsection{Regulation of the Cartesian Position}
We build our discussion focusing on the unicycle model. Before defining a regulation control law for the whole configuration $\q$, we define a \textbf{partial controller} that stabilizes a desired Cartesian position, regardless of the orientation $\theta$.\bigskip


Without loss of generality, we can assume that the desired Cartesian position is $(x \quad y)^\top=(0 \quad 0)^\top$, this can be done through an appropriate coordinate transformation. Hence we define the Cartesian error as\begin{equation}
    \mathbf e_p=\begin{pmatrix}
        x_d\\ y_d
    \end{pmatrix}-\begin{pmatrix}
        x\\ y
    \end{pmatrix}=\begin{pmatrix}
        -x\\ -y
    \end{pmatrix}
\end{equation}
Let $\mathbf n$ be the unit vector aligned with the sagittal axis; we will find useful the projection of $\mathbf e_p$ on the sagittal axis:\begin{equation}
    \mathbf e_p^\top\mathbf n = \begin{pmatrix}
        -x&-y
    \end{pmatrix} \begin{pmatrix}
        \cos\theta\\\sin\theta
    \end{pmatrix}=-x\cos\theta-y\sin\theta.
\end{equation}
We also define the \textbf{pointing error} $\gamma$:\begin{equation}
    \gamma=\text{atan2}(y,x)+\pi-\theta.
\end{equation}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth ]{images/cartesian_error_1.eps}
\end{figure}
\noindent In order to converge to the desired Cartesian position, we use the feedback control law described in Definition \ref{def:Regulation}.
\begin{boxdefinition}{Unicycle Regulation Control Law (Cartesian Position)}{Regulation}
    Let $k_1,k_2>0$.
    \begin{align}
    v&=-k_1(x\cos\theta+y\sin\theta)=k_1\mathbf e_p^\top\mathbf n\\ 
    \omega&=k_2(\text{atan2}(y,x)+\pi-\theta)=k_2\gamma
\end{align}
\end{boxdefinition}
\noindent The geometrical interpretation is clear:\begin{itemize}
    \item $v$ is proportional to the orthogonal projection of the Cartesian error on the sagittal axis.
    \item $\omega$ is proportional to the pointing error.
\end{itemize}
In order to prove that this control law stabilizes the system on the desired position, we define the following Lyapunov function:\begin{equation}
    V=\frac{1}{2}(x^2+y^2)\ge 0
\end{equation}
It's important to outline that $V(\q)$ is \textbf{not positive definite}, but positive semi-definite, since it is zero when $x=y=0$, but depends also on $\theta$ (the full configuration), hence there are infinitely many non-zero vectors that make $V$ zero:\begin{equation}
    x=y=0\implies V(x,y,\theta)=0 \quad \forall \theta.
\end{equation}
Now we compute the derivative:\begin{equation}
    \dot V = x\dot x+y\dot y 
\end{equation}
here we can use the kinematic model of the unicycle to substitute $\dot x,\dot y$:
\begin{equation}
    \dot V = xv\cos\theta+yv\sin\theta=v(x\cos\theta+y\sin\theta)
\end{equation}
due to the fact that we are considering the closed loop system, we can substitute $v$ with the control law:\begin{equation}
    \dot V = -k_1(x\cos\theta+y\sin\theta)^2=-k_1(\mathbf e_p^\top\mathbf n)^2\le 0.
\end{equation}
For the same reason as for $V$, $\dot V$ is negative semi-definite, zero on all the configurations with $x=y=0$. To apply Barbalat's lemma, we need to show that $\ddot V$ is bounded.
\begin{boxproposition}{}{}
    $\ddot V$ is bounded, i.e. $\exists c\in\mathbb R^+$ such that $|\ddot V|\le c$.
\end{boxproposition}
\noindent\textit{Proof}:
\begin{align}
\ddot{V} &= \frac{d}{dt}\left[ -k_1 (x\cos\theta + y\sin\theta)^2 \right] \\
&= -2k_1 (x\cos\theta + y\sin\theta) \frac{d}{dt}(x\cos\theta + y\sin\theta) \\
&= -2k_1 (x\cos\theta + y\sin\theta) \left( \dot{x}\cos\theta - x\dot{\theta}\sin\theta + \dot{y}\sin\theta + y\dot{\theta}\cos\theta \right) \\
&= -2k_1 (x\cos\theta + y\sin\theta) \left[ (\dot{x} + y\dot{\theta})\cos\theta + (\dot{y} - x\dot{\theta})\sin\theta \right]
\end{align}
we use the unicycle model and the definition of the control law:
\begin{align}
\ddot{V} &= -2k_1 (x\cos\theta + y\sin\theta) \left[ (\dot{x} + y\dot{\theta})\cos\theta + (\dot{y} - x\dot{\theta})\sin\theta \right] \\
&= -2k_1 (x\cos\theta + y\sin\theta) \left[ (v\cos\theta + y\omega)\cos\theta + (v\sin\theta - x\omega)\sin\theta \right] \\
&= -2k_1 (x\cos\theta + y\sin\theta) \left[ v(\cos^2\theta + \sin^2\theta) + \omega(y\cos\theta - x\sin\theta) \right] \\
&= -2k_1 (x\cos\theta + y\sin\theta) \left[ v + \omega(y\cos\theta - x\sin\theta) \right] \\
&= 2k_1 (\mathbf{e}_p^\top\mathbf{n}) \left[ k_1 \mathbf{e}_p^\top\mathbf{n} - k_2\gamma (\mathbf{e}_p^\top\mathbf{n}^\perp) \right] \\
&= 2k_1^2 (\mathbf{e}_p^\top\mathbf{n})^2 - 2k_1 k_2 \gamma (\mathbf{e}_p^\top\mathbf{n})(\mathbf{e}_p^\top\mathbf{n}^\perp)\label{ddotV}
\end{align}
where $\mathbf n^\bot=(-\sin\theta \quad \cos\theta)^\top$. Due to the definition of the Lyapunov function, we can state that $\mathbf e_p$ is bounded, since $V$ is proportional to the squared norm of $\mathbf e_p$, and $V$ never increases, hence $\|\mathbf e_p(t)\|\le\|\mathbf e_p(0)\|$, $\forall t$. Since all the quantities in Equation \eqref{ddotV} are bounded, $\ddot V$ is bounded.\hfill$\blacksquare$\bigskip

Having proved that $\ddot V$ is bounded, by Barbalat's lemma we can say that $\dot V$ will converge to zero at steady state:\begin{equation}
    \dot V = -k_1(\mathbf e_p^\top\mathbf n)^2=0\iff \mathbf e_p^\top\mathbf n=0
\end{equation}
so we can assert that at steady state $\mathbf e_p^\top\mathbf n=0$, this is true only in two possible cases:\begin{itemize}
    \item $\mathbf e_p$ is zero, hence we have correctly regulated the desired Cartesian position.
    \item $\mathbf e_p$ is orthogonal to $\mathbf n$.
\end{itemize}
\begin{boxobservation}{}{}
    At steady state, it is impossible to have a non-zero $\mathbf e_p$ orthogonal to $\mathbf n$.
\end{boxobservation}
This is pretty easy to show, since the control law for $\omega$ is $$\omega=k_2\gamma$$
where $\gamma$ is the pointing error, with a non-zero $\mathbf e_p$ orthogonal to $\mathbf n$ we would have $\gamma=\pm\frac{\pi}{2}$, hence the angular velocity would be non-zero: $\dot\theta=\omega=\pm k_2\frac{\pi}{2}$, and by definition this is not steady state: the only possible steady state condition is $\mathbf e_p=\mathbf 0$.

\subsection{Regulation of the Whole Configuration}
Now we define a control law to achieve any desired posture $\q_d$, including the orientation $\theta$. We will work in polar coordinates, hence we define the following coordinate transformation:\begin{align}
    \rho&=\sqrt{x^2+y^2}\\
    \gamma&=\text{atan2}(y,x)+\pi-\theta\\
    \delta&=\gamma+\theta.
\end{align}
$\rho$ is the Cartesian distance from the origin, $\delta$ the angle between the Cartesian error vector and the horizontal axis, $\gamma$ the angle between the sagittal axis and the Cartesian error vector.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.28\textwidth ]{images/polar_coord.eps}
\end{figure}
\noindent Let's derive the kinematic model, starting from the time evolution of $\rho$:\begin{align}
    \dot\rho&=\frac{1}{\sqrt{x^2+y^2}}(x\dot x+y\dot y)\\
    &=\frac{v}{\rho}(x\cos\theta+y\sin\theta)
\end{align}
we denote by $\beta$ the angle between the horizontal axis and the line from the origin to the wheel contact point:\begin{equation}
    \beta=\text{atan2}(y,x)\implies\begin{cases}
        x=\rho\cos\beta\\ y=\rho\sin\beta 
    \end{cases}
\end{equation}
hence\begin{align}
    \dot\rho&=\frac{v}{\rho}(\rho\cos\beta\cos\theta+\rho\sin\beta\sin\theta)
    \\ &=v\cos(\beta-\theta)\\ 
    &=-v\cos(\beta-\theta+\pi) \\
    &=-v\cos(\text{atan2}(y,x)-\theta+\pi)=-v\cos\gamma.
\end{align}
We proceed with the computation of $\dot\gamma$:
\begin{align}
\dot{\gamma} &= \frac{d}{dt}\left( \text{atan2}(y, x) + \pi - \theta \right) \\
&= \frac{x\dot{y} - y\dot{x}}{x^2 + y^2} - \dot{\theta} \\
&= \frac{x(v\sin\theta) - y(v\cos\theta)}{\rho^2} - \omega \\
&= \frac{v}{\rho^2} (x\sin\theta - y\cos\theta) - \omega \\
&= \frac{v}{\rho^2} \left[ -\rho\cos(\gamma + \theta)\sin\theta + \rho\sin(\gamma + \theta)\cos\theta \right] - \omega \\
&= \frac{v}{\rho} \left[ \sin(\gamma + \theta)\cos\theta - \cos(\gamma + \theta)\sin\theta \right] - \omega \\
&= \frac{v}{\rho}\sin\big((\gamma + \theta) - \theta\big) - \omega \\
&= \frac{\sin\gamma}{\rho} v - \omega
\end{align}
for $\dot\delta$ the computation is straightforward:
\begin{align}
\dot{\delta} &= \frac{d}{dt}(\gamma + \theta) \\
&= \dot{\gamma} + \dot{\theta} \\
&= \left( \frac{\sin\gamma}{\rho} v - \omega \right) + \omega \\
&= \frac{\sin\gamma}{\rho} v.
\end{align}
The kinematic model of the unicycle in polar coordinates is:\begin{align}
\dot{\rho} &= -v\cos\gamma \\
\dot{\gamma} &= \frac{\sin\gamma}{\rho} v - \omega \\
\dot{\delta} &= \frac{\sin\gamma}{\rho} v.\label{dot_delta}
\end{align}
How to define a control law to stabilize $(\rho\quad\gamma\quad\delta)^\top$ to zero? In the previous subsection, we defined a control law and then proved its correctness through Lyapunov analysis, now we first define a Lyapunov candidate, and then design a law for $v$ and $\omega$ in order to make $\dot V$ negative definite. Consider:\begin{equation}
    V=\frac{1}{2}(\rho^2+\gamma^2+\delta^2)=\frac{1}{2}\left\|(\rho\quad\gamma\quad\delta)^\top\right\|^2\ge 0
\end{equation}
differently from the previous case, this $V$ is \textit{positive definite}, zero only at $\rho=\gamma=\delta=0$. Its derivative is\begin{align}
    \dot V &= \rho\dot\rho+\gamma\dot\gamma+\delta\dot\delta \\
    &= -v\cos\gamma\rho + \left(\frac{\sin\gamma}{\rho} v - \omega\right)\gamma + \frac{\sin\gamma}{\rho} v\delta
\end{align}
$v$ and $\omega$ appear in $\dot V$, hence by an appropriate choice we can modify $\dot V$ in order to obtain the desired property. We rewrite $\dot V$ as follows:\begin{equation}
    \dot V=-\rho v\cos\gamma+v\frac{\sin\gamma}{\rho}(\gamma+\delta)-\gamma\omega
\end{equation}
the first choice that we make is $v=k_1\rho\cos\gamma$, in this way:\begin{align}
    \dot V&=-\rho v\cos\gamma+v\frac{\sin\gamma}{\rho}(\gamma+\delta)-\gamma\omega\\
    &=\underbrace{-k_1\rho^2\cos^2\gamma}_{\le 0}+k_1\sin\gamma\cos\gamma(\gamma+\delta)-\gamma\omega
\end{align}
now we can proceed with an appropriate choice of $\omega$, let $\omega=k_2\gamma+\alpha$, with $\alpha$ yet to be chosen:\begin{equation}
    \dot V = 
    \underbrace{-k_1\rho^2\cos^2\gamma}_{\le 0}
    +k_1\sin\gamma\cos\gamma(\gamma+\delta)
    \underbrace{-k_2\gamma^2}_{\le 0}-\gamma\alpha
\end{equation}
at this point we use $\alpha$ to cancel the remaining terms that are not guaranteed to be non-positive:\begin{align}
   &\text{we want: } -\gamma\alpha+k_1\sin\gamma\cos\gamma(\gamma+\delta)=0\\ 
   &\text{we set: } \alpha=\frac{1}{\gamma}k_1\sin\gamma\cos\gamma(\gamma+\delta)
\end{align}
hence:\begin{align}
    \dot V&= 
    {-k_1\rho^2\cos^2\gamma}
    +k_1\sin\gamma\cos\gamma(\gamma+\delta)
    {-k_2\gamma^2}-\gamma\blueText{\alpha}\\
    &=
    {-k_1\rho^2\cos^2\gamma}
    +k_1\sin\gamma\cos\gamma(\gamma+\delta)
    {-k_2\gamma^2}-\gamma\blueText{\frac{1}{\gamma}k_1\sin\gamma\cos\gamma(\gamma+\delta)}\\
    &= -k_1\rho^2\cos^2\gamma-k_2\gamma^2\le 0.
\end{align}
$\dot V$ is negative semi-definite, having its zeros on the line $\gamma=\rho=0$, for any value of $\delta$.
\begin{boxdefinition}{Unicycle Regulation Control Law (Full Configuration)}{}
    The control law found through Lyapunov analysis is:\begin{align}
    v&=k_1\rho\cos\gamma \\
    \omega&=k_2\gamma+k_1\frac{\sin\gamma\cos\gamma}{\gamma}(\gamma+\delta).
\end{align}
\end{boxdefinition}
It can be shown (\underline{proof omitted}) that $\ddot V$ is bounded, hence by Barbalat's lemma $\dot V$ will converge to zero. At steady state we have $\gamma=\rho=0$, and this (from the kinematic model in Equation \eqref{dot_delta}) implies that at steady state $\dot\delta=0$, hence also $\delta$ will converge to a limit, and this will be exactly zero (\underline{proof omitted}).

\end{figure}
