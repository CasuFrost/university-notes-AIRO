\chapter{Exploration and Exploitation}
\begin{boxdefinition}{Reinforcement Learning}{}
With \textbf{Reinforcement Learning} we mean the process to \textit{learn} what to do in order to maximize a numerical reward signal:\begin{itemize}
    \item The learner must discover which actions yield the highest reward by trying them.
    \item The actions might affect not only immediate reward, but also subsequent ones. It is a \textit{trial-and-error} process.
\end{itemize}
\end{boxdefinition}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth]{images/RL_intro.png} 
\end{figure}
\noindent The agent has to:\begin{itemize}
    \item \textbf{Exploit}  what it has already experienced to obtain a reward.
    \item  \textbf{Explore} in order to make better action selections in the future.
\end{itemize}
One of the main challenges of reinforcement learning is the exploration-exploitation trade-off. In stochastic tasks, each action must be tried many times, in order to correctly estimate the expected reward.
\section{Multi-Armed Bandits}\label{bandits}
One of the main problems in reinforcement learning is to decide when we should continue to explore (collect more information about the environment) or to exploit (use the available information in order to get closer to the goal). 
We need to \textit{carefully} and \textit{systematically} explore. The \textbf{multi-armed bandits (MAB)} problem is a simplified problem that describes the exploration paradigm.\bigskip 

\noindent We have $K$ different arms, that are our actions:\begin{equation}
    a_1,a_2,\dots, a_K
\end{equation}
and a reward $r\in [0,1]$, that is the scalar signal representing a feedback. Each single arm has an unknown reward distribution $\nu_i$ with mean $\mu_i$, every time we pull one of the $K$ arms we observe a reward. We interact with the MAB in the following way:\begin{itemize}
    \item for $t=0,1,\dots,T-1$:\begin{enumerate}
        \item pull an arm $I_t\in\{a_1,a_2,\dots, a_K\}$ based on historical information 
        \item observe the reward $r_t\sim \nu_{I_t}$ of the arm $I_t$.
    \end{enumerate}
\end{itemize}
The goal of this process is to minimize the \textbf{opportunity loss}. Assume that the best arm to pull is known ($a^*$), with its mean reward ($\mu^*$):\begin{equation}
    \mu^*=\max_{i\in \{1,\dots, K\}}\mu_i.
\end{equation}
Consider the total expected reward obtained if we pull the best arm for $T$ rounds:\begin{equation}
    T\mu^*
\end{equation}
and the total expected reward of the arms we actually pulled over $T$ rounds:\begin{equation}
    \sum_{t=0}^{T-1}\mu_{I_t}
\end{equation}
the \textbf{regret} is the difference between these two quantities:\begin{equation}
    \text{Regret}_T=T\mu^*-\sum_{t=0}^{T-1}\mu_{I_t}
\end{equation}
the regret is the expression of the opportunity loss, which we want to minimize. In the MAB example, the exploration-exploitation trade-off manifests itself in the form of the following question:\begin{quotation}
    \textit{Should we pull arms that have been tried less frequently in the past (i.e., explore), or should we commit to
    the current best arm (i.e., exploit)?}
\end{quotation}
We consider different strategies. The \textbf{greedy algorithm} tries each arm once, and then commits to the one that has the highest observed reward. This algorithm is not optimal: a low mean arm might generate a high reward the single time we sample it.
\subsection{The Hoeffding Inequality and Regret Calculation}
A better choice of algorithm is the \textbf{Explore \& Commit}: we try each arm multiple times, and we compute the empirical mean of the rewards. Then we commit to the arm with the highest empirical mean.\begin{enumerate}
    \item Let $N$ be a fixed value, and $T\ge NK$
    \item for $k=1,\dots,K$\begin{itemize}
        \item pull the arm $a_k$ for $N$ times
        \item observe the set of observations $\{r_1^{(k)},r_2^{(k)},\dots, r_N^{(k)}\}$
        \item compute the empirical mean $\displaystyle \hat\mu_k=\frac{1}{N}\sum_{i=1}^{N}r_i^{(k)}$
    \end{itemize} 
    \item for $t=NK,\dots,T-1$\begin{itemize}
        \item pull the best empirical arm $\displaystyle I_t=\operatorname*{arg\,max}_{i\in \{1,\dots, K\}}\hat\mu_i$
    \end{itemize} 
\end{enumerate}
\begin{boxproposition}{Hoeffding Inequality}{Hoeffding}
 Given a distribution with mean $\mu$, where we have observed $N$ independent  and bounded samples $r_i\in[0,1]$, the following inequality holds with probability $1-\delta$:\begin{equation}
     \left\vert{}\frac{1}{N}\sum_{i=1}^{N}r_i-\mu \right\vert{}
     \le
     \sqrt{\frac{\ln(\nicefrac{2}{\delta})}{2N}}.
 \end{equation}
\end{boxproposition}
The Proposition \ref{def:Hoeffding} gives us a confidence interval on our empirical mean.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.14\textwidth]{images/Hoeffding.eps} 
    \caption{The true mean is located at a bounded distance from the sampled mean with probability $1-\delta$.}
    \label{img:Hoeffding}
\end{figure}
\noindent For example, if $\delta=0.01$, the bound holds with probability $99\%$. The Hoeffding inequality can also be applied for all the arms at once. During the exploration phase, for \textbf{all the arms}: with probability $1-\delta$ the following inequalities hold:\begin{equation}
    \left\vert{}\frac{1}{N}\sum_{i=1}^{N}r_i^{(k)}-\mu_k \right\vert{}
    \le
    \sqrt{\frac{\ln(\nicefrac{2K}{\delta})}{2N}}\quad\text{for every $k\in \{1,\dots, K\}$}.
\end{equation}
This comes from a union bound over the $K$ arms, which is why $\nicefrac{2}{\delta}$ becomes $\frac{2K}{\delta}$.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.85\textwidth]{images/Hoeffding_multi.eps}
    \caption{Hoeffding inequalities for multiple arms.}
    \label{img:Hoeffding_multi} 
\end{figure}
Figure \ref{img:Hoeffding_multi} qualitatively shows an example of how the Explore \& Commit algorithm would fail: in this case we would choose the arm $a_2$ as the sample mean $\hat\mu_2$ is higher than the sample mean of the other arms, but we can clearly see how the true mean $\mu_3$ of arm $a_3$ is higher than the true mean $\mu_2$ of the arm $a_2$. If we choose the arm $a_2$, the loss of accumulated reward due to this suboptimal decision is called \textbf{regret} and is equal to:\begin{equation}
    \text{Regret}_{exploit}=(T-NK)(\mu_3-\mu_2)
\end{equation} 
where $T-NK$ is the number of remaining steps dedicated to exploitation (total steps $T$ minus those used to explore $NK$). The difference $(\mu_3-\mu_2)$ is small, less than the confidence ranges.

Since we assumed that the reward range is $[0,1]$, the maximum loss for a single round is at most 1, so the regret accumulated in the exploration phase is bounded above by:\begin{equation}
     \text{Regret}_{explore}\le N(\underbrace{K-1}_{\text{one is optimal}})\le NK.
\end{equation}
Let $\hat I$ be the empirical best arm and $I^*$ the true best arm, the worst possible regret in exploitation is\begin{equation}
    \text{Regret}_{exploit}\le (T-NK)(\mu_{I^*}-\mu_{\hat I})
\end{equation}
where\begin{align}
    \mu_{I^*}-\mu_{\hat I}\le&
    \left[\hat \mu_{I^*}+\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}\right]-
     \left[\hat \mu_{\hat I}-\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}\right]\\ 
     =&\underbrace{\hat\mu_{I^*}-\hat\mu_{\hat I}}_{\le 0}+2\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}\le 2\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}
\end{align}
hence the regret is at most twice our confidence interval:\begin{equation}
    \text{Regret}_{exploit}\le2T\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}.
\end{equation}
The total regret is\begin{equation}
    \text{Regret}_T= \text{Regret}_{explore}+\text{Regret}_{exploit}\le NK+2T\sqrt{\frac{\ln(\nicefrac{K}{\delta})}{N}}.
\end{equation}
We want to minimize the regret by choosing the optimal value of $N$, this can be done by taking the derivative with respect to $N$ of the regret and setting it to zero, then we solve for $N$. This leads to:\begin{equation}
    N=\left(
        \frac{T\sqrt{\ln(\nicefrac{K}{\delta})}}{K}
    \right)^\frac{2}{3}
\end{equation}
The following inequality holds\begin{equation}
    \text{Regret}_T= O(T^\frac{2}{3}K^\frac{1}{3}\ln^\frac{1}{3}(\nicefrac{K}{\delta})).
\end{equation}
This \textbf{growth rate} of the regret using the Explore \& Commit algorithm is kind of slow. We would like to get something faster, like $O(\sqrt{T})$ (that is proven to be the minimum we can get). We want to design a new algorithm, first of all we need a list of generic statistics useful to maintain in order to compute our confidence
bounds and the regret:\begin{itemize}
    \item we denote $N_t(i)$ the number of times we have tried the arm $a_i$ so far:\begin{equation}
        N_t(i)=\sum_{\tau=0}^{t-1}\mathbb{1}\{I_\tau=a_i\}
    \end{equation}
    \item the empirical mean so far:\begin{equation}
        \hat\mu_t(i)=\sum_{\tau=0}^{t-1}\mathbb{1}\{I_\tau=a_i\}\frac{r_\tau}{N_t(i)}
    \end{equation}
    \item the confidence with probability $1-\delta$:\begin{equation}\label{conf_interval}
        | \hat\mu_t(i)-\mu_i|\le\sqrt{\frac{\ln(\nicefrac{KT}{\delta})}{N_t(i)}}.
    \end{equation}
\end{itemize}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.85\textwidth]{images/Hoeffding_multi_new.eps}
    \caption{In the confidence interval in Equation \eqref{conf_interval}, the length depends on how many times one arm has been tried.}
    \label{img:Hoeffding_multi_new} 
\end{figure}
For example, in Figure \ref{img:Hoeffding_multi_new} the confidence interval of arm 2 is wider
because we did not try arm 2 as many times as arm
1 and 3. We select the arm with the highest upper confidence bound, and we make an optimistic assumption: the true mean actually corresponds to the upper confidence bound. 

\begin{itemize}
    \item If the bound is large, it means either that arm has been tested few times, therefore if that is
 not good, the more we choose it the more the upper bound decreases and eventually
 another one will be the highest, or that it is actually good.
    \item If a confidence interval is large then we want to explore, a small interval on the selected arm means its high UCB reflects a genuinely high mean.

\end{itemize}
\noindent The \textbf{UCB algorithm} works as follows:\begin{itemize}
    \item For the first $K$ iterations, we pull each arm once
    \item for $t=K,\dots, T-1$:\begin{itemize}
        \item We pick the arm with the highest upper confidence bound:\begin{equation}
            I_t= \operatorname*{arg\,max}_{i=1,\dots,K}\left(
                \hat\mu_t(i)+\sqrt{\frac{\ln(\nicefrac{KT}{\delta})}{N_t(i)}}
            \right)
        \end{equation}
        \item update the statistics.
    \end{itemize}
\end{itemize}
\noindent  Now let's compute the regret at a given time step $t$, we have:\begin{equation}
    \mu^*-\mu_{I_t}\le\hat\mu_t(I_t)+\sqrt{\frac{\ln(\nicefrac{KT}{\delta})}{N_t(I_t)}}-\mu_{I_t}\le 2\sqrt{\frac{\ln(\nicefrac{KT}{\delta})}{N_t(I_t)}}
\end{equation}
if $N_t$ is small, we have a high regret but we have to explore, if it's large, we exploit and the regret is small. The total regret summing over all iterations is:\begin{equation}
    \text{Regret}_T = \sum_{t=0}^{T-1} (\mu^* - \mu_{I_t}) \le \sum_{t=0}^{T-1} 2 \sqrt{\frac{\ln(TK/\delta)}{N_t(I_t)}} \le 2\sqrt{\ln(TK/\delta)} \cdot \underbrace{\sum_{t=0}^{T-1} \sqrt{\frac{1}{N_t(I_t)}}}_{\le O(\sqrt{KT})}.
\end{equation}
\begin{boxtheorem}{Regret of the UCB}{}
    With the UCB algorithm, the following bound holds:
    \begin{equation}
        \text{Regret}_T= O\left(\sqrt{KT\ln\left(\frac{KT}{\delta}\right)}\right)
    \end{equation}
    or
    \begin{equation}
        \text{Regret}_T=\tilde O(\sqrt{KT})
    \end{equation}
    with probability $1-\delta$.
\end{boxtheorem}
\noindent\textit{Proof}:  We want to bound the summation term appearing in the UCB regret bound. First we cluster the pulled arms into $K$ groups, where the $i$-th group contains all steps where arm $i$ is pulled:\begin{equation}
    \sum_{t=0}^{T-1}\sqrt{\frac{1}{n_t(I_t)}}=\sum_{i=1}^{K}\sum_{t=0}^{T-1}\mathbb{1}\{I_t=a_i\}\sqrt{\frac{1}{n_t(i)}}
\end{equation}
where $n_t(i)$ is the size of the specific group. \begin{equation}\label{specific}
    \sum_{i=1}^{K}\sum_{t=0}^{T-1}\mathbb{1}\{I_t=a_i\}\sqrt{\frac{1}{n_t(i)}}=
    \sum_{i=1}^{K}\sum_{t=0}^{n_T(i)}\sqrt{\frac{1}{t}}.
\end{equation}
We use the following inequality:\begin{equation}
    \sum_{k=1}^{N}\frac{1}{\sqrt{k}}\le2\sqrt{N}
\end{equation}
hence from Equation \eqref{specific} we have:\begin{equation}
     \sum_{i=1}^{K}\sum_{t=0}^{n_T(i)}\sqrt{\frac{1}{t}}\le  
     2\sum_{i=1}^{K}\sqrt{n_T(i)}.
\end{equation}
Since all $n_T(i)$ sum to $T$, by the Jensen's inequality (concavity of $\sqrt\cdot$) we have:\begin{equation}
    2\sum_{i=1}^{K}\sqrt{n_T(i)}=2K \left( \frac{1}{K} \sum_{i=1}^K \sqrt{n_T(i)} \right) \le2 K \sqrt{\frac{1}{K} \sum_{i=1}^K n_T(i)} = 2K \sqrt{\frac{T}{K}} = 2\sqrt{KT}.
\end{equation}
\hfill$\blacksquare$
\section{Contextual and Bayesian Bandits}
We introduce the \textit{context}: there is a set $X$ of contexts/states, $x_t\in X$ is the state at time $t$, the reward depends not only on the action but also on the current state: $r(x_t,a_t)$. For simplicity we assume that the reward function is deterministic.\begin{itemize}
    \item At each time step, we are in the state $x_t$.
    \item We choose an action $a_t$ and observe $r(x_t,a_t)$.
    \item The next state $x_{t+1}$ does not depend on the action, but is sampled from a distribution $\mu$.
\end{itemize}
A \textbf{policy} $\pi$ is a mapping from \textit{all} the states to the actions. Is important to emphasize that a policy must assign an action to \textbf{each possible state}; if it is not defined on a particular state, then it is not a policy.\begin{itemize}
    \item Can be deterministic: $a=\pi(s)$,
    \item or stochastic $\pi( a \mid s)$.
\end{itemize}
Note how we denoted $s$ a state, this is a general notation. In the bandits context, we will use $x$ to denote the state. We define the \textbf{optimal policy} as the one that maximizes the expected value for the reward:\begin{equation}
    \pi^\star=\operatorname*{arg\,max}_{\pi}\underset{x\sim\mu}{\mathbb E} r(x,\pi(x)).
\end{equation}
If the set of states $X$ is discrete the expected value is\begin{equation}
        \pi^\star=\operatorname*{arg\,max}_{\pi}\sum_{x\in X} r(x,\pi(x))\mu(x)
\end{equation}
with $\mu(x)$\footnote{
    Formally, we should write $\mu(\{x\})$, since $\mu$ is a measure on $X$.
} being the probability of sampling the state $x$. \bigskip 

Let $\{\pi^0,\pi^1,\dots,\pi^{T-1}\}$ be the sequence of policies that we learned at each time step from the beginning to $t=T-1$. At the $T$-th iteration, we define the \textbf{regret} as the total expected reward obtained using the optimal policy $\pi^\star$ minus the total expected reward obtained by using our sequence of policies:\begin{equation}
    \text{Regret}_T=T\underset{x\sim\mu}{\mathbb E}\left[
        r(x,\pi^\star(x))
    \right]- 
    \sum_{t=0}^{T-1}\underset{x\sim\mu}{\mathbb E}\left[
        r(x,\pi^t(x))
    \right]
\end{equation}
we recall that at every time step, the states are sampled from the distribution $\mu$ independently from the previous states.
\subsection{Explore and Commit}
Let's see how the explore \& commit algorithm works on the contextual bandit, the goal is to build a \textit{table} that assigns to each pair of state and action, the estimated expected value of the reward.
\begin{algorithm}[H]
\caption{Explore \& Commit}\label{alg:explore_commit_context}
\begin{algorithmic}[1]
\For{$t=0,\dots,N-1$ \textbf{(explore)}}
\State observe the current state $x_t\sim\mu$
\State sample a random action from a uniform distribution $a_t\sim\text{Unif}(A)$
\State observe the reward $r_t=r(x_t,a_t)$
\State build an unbiased estimator $\mathbf r_t$ defined as follows:\begin{equation}
    \mathbf r_t[a]=\begin{cases}
        0\quad\text{ if }a\ne a_t\\ 
        r_t\cdot |A|\text{ else }
    \end{cases}
\end{equation}
at each time step $t$ the estimator assigns zero to all the entries of $\mathbf r_t$ except for the one used at time $t$, to which it assigns the reward multiplied by the number of actions.
\EndFor
\State compute the policy as follows:\begin{equation}
    \hat\pi=\operatorname*{arg\,max}_{\pi}\sum_{i=0}^{N-1}\mathbf r_i[\pi(x_i)]
\end{equation}
\For{$t=N,\dots,T-1$ \textbf{(commit)}}
\State observe the current state $x_t\sim\mu$
\State play the arm $a_t=\hat\pi(x_t)$
\EndFor
\end{algorithmic}
\end{algorithm}
\noindent\textbf{About the estimator}: We want to give a description of how the estimator $\mathbf r_t$ works. There are $N$ vectors $\mathbf r_0,\mathbf r_1,\mathbf r_2\dots,\mathbf r_{N-1}$, each of dimension $|A|$ (the number of possible actions). For a given time step $t$, $\mathbf r_t$ is null on each action, except for the action chosen at time $t$:\begin{equation}
    \mathbf r_0=\begin{pmatrix}
        \nicefrac{r_0}{p(a_0)}\\ 0\\ \vdots\\ 0\\ \vdots\\ 0
    \end{pmatrix},\quad
    \mathbf r_1=\begin{pmatrix}
        0\\ \nicefrac{r_1}{p(a_1)}\\ \vdots\\ 0\\ \vdots\\ 0
    \end{pmatrix},\quad\dots\quad,
    \mathbf r_t=\begin{pmatrix}
        0\\ 0\\ \vdots\\ \nicefrac{r_t}{p(a_t)}\\ \vdots\\ 0
    \end{pmatrix},\quad\dots\quad,
    \mathbf r_{N-1}=\begin{pmatrix}
        0\\ 0\\ \vdots\\ 0\\ \vdots\\ \nicefrac{r_{N-1}}{p(a_{N-1})}
    \end{pmatrix}.
\end{equation}
$p(a_t)$ is the probability of choosing the action $a_t$, since they are sampled from a uniform distribution, for each action $a$ we have $p(a)=\frac{1}{|A|}$ hence $\frac{r_t}{p(a_t)}=r_t\cdot|A|$.
The regret for this algorithm has the following asymptotic behavior:\begin{equation}
    O(T^{\nicefrac{2}{3}}\cdot|A|^{\nicefrac{1}{3}}\cdot\ln^{\nicefrac{1}{3}}(|\Pi|))
\end{equation} 
where $\Pi$ is the set of all the policies.
\subsection{$\epsilon$-Greedy}
The $\epsilon$-greedy algorithm never stops exploring, at each time step, with a given probability it selects a random action, else it selects the best action, exploiting the known information. We denote $\pi^t$ the current policy that we are selecting as our best policy at time $t$. Let $\epsilon\in [0,1]$, if $\epsilon=0$, we just exploit the available information, if $\epsilon=1$, we explore by randomly choosing the actions.
\begin{algorithm}[H]
\caption{$\epsilon$-Greedy}\label{alg:eps_greedy_context}
\begin{algorithmic}[1]
\For{$t=0,\dots,T-1$}
\State observe the current state $x_t\sim\mu$
\State select a random number $c\sim \text{Unif}([0,1])$
\If{$c\le \epsilon$}
\State sample a random action from a uniform distribution $a_t\sim\text{Unif}(A)$ (\textbf{explore})
\Else
\State choose the best action $a_t=\pi^t(x_t)$ (\textbf{exploit})
\EndIf
\State observe the reward $r_t=r(x_t,a_t)$
\State build an unbiased estimator $\mathbf r_t$ defined as follows:\begin{equation}\mathbf r_t[a]=\begin{cases}0\quad\text{ if }a\ne a_t\\ \frac{r_t}{p_t(a_t)}\text{ else }\end{cases}\end{equation}where\begin{equation}p_t(a)=\frac{\epsilon}{|A|}+(1-\epsilon)\mathbb 1\{a=\pi^t(x_t)\}\end{equation}
\State update the policy\begin{equation}
    \pi^{t+1}=\operatorname*{arg\,max}_{\pi}\sum_{i=0}^{t}\mathbf r_i[\pi(x_i)]
\end{equation}
\EndFor
\end{algorithmic}
\end{algorithm}
$\epsilon$ can also be time-varying, by making it high at the beginning (first explore) and then decaying as the time goes on (then exploit), for example $\epsilon(t)=0.9\exp(-t)+0.1$.
\subsection{Gaussian Bayesian Bandits}
In the previous discussion, we treated the reward $r$ as deterministic. Now let $r$ be random again. We denote $\nu(i)$ the reward distribution, for the specific action $a_i$ (hence we have a reward distribution for each action), we are making a step back by removing the context, the following discussion assumes that there is only one state.
We exploit  prior knowledge by \textit{assuming} that the distributions $\nu(i)$ are \textbf{Gaussians}:\begin{equation}
    \nu(i)=\mathcal N\big(\mu(i),\sigma^2(i)\big)
\end{equation}
with $\mu(i)$ and $\sigma^2(i)$ being the mean and variance for the reward by choosing the action $a_i$.
\begin{center}
\begin{tikzpicture}
\begin{axis}[axis x line=bottom,axis y line=none,xtick=\empty,ytick=\empty,enlargelimits=true,width=10cm,height=6cm,domain=-6:6,samples=100,declare function={gauss(\x,\mu,\sigma)=1/(\sigma*sqrt(2*pi))*exp(-((\x-\mu)^2)/(2*\sigma^2));}]
\addplot[thick,blue]{gauss(x,0,1)};
\addplot[thick,red]{gauss(x,-2,0.5)};
\addplot[thick,green!70!black]{gauss(x,2,1.5)};
\end{axis}
\end{tikzpicture}\end{center}
Usually, at the beginning we assume as prior knowledge that the mean of all the Gaussians is zero and the standard deviation is 1. In the algorithm we will start exploring and trying different actions, sampling the rewards in order to fit the Gaussians with the correct values for the mean and the standard deviation.\bigskip 

Assume that we have fitted the Gaussians, we can apply the UCB to this case, the best action is the one with the highest upper bound for the reward, hence we choose the action with the Gaussian with the highest  standard deviation (considering also the mean). Let $K$ be the number of actions:\begin{equation}
    a_t=\operatorname*{arg\,max}_{1\le i \le K}\mu_t(i)+\frac{c\sigma_t(i)}{\sqrt{N_t(i)}}
\end{equation}
where\begin{itemize}
    \item $\mu_t(i),\sigma_t(i)$ are the current estimation at time $t$ for the mean and the standard deviation of the distributions of the $i$-th action.
    \item $c$ is an exploration parameter.
    \item $N_t(i)$ is the total number of times that the $i$-th action has been selected.
\end{itemize}
\chapter{Planning in MDPs}
\section{Markov Decision Processes}
First of all we introduce a \textit{sequential} decision making approach. We see the agent that has to learn the policy as an entity that can interact with the world/environment through actions $a_t$, and can receive from the environment an observation $o_t$ and a reward $r_t$ after each action. The agent interacts at discrete time steps; such discrete interaction generates a \textbf{trajectory} (or history) of tuples (observation-action-reward):\begin{equation}
    \underbrace{h_t}_{\text{history at time $t$}} = (o_0,a_0,r_1,o_1,a_1,r_2,\dots, r_t,o_t,a_t).
\end{equation}
We define a state function $s_t=f(h_t)$ that describes the current state of the agent at time $t$ and depends on the history $h_t$ and is typically hidden or unknown.
\begin{boxdefinition}{Markov Assumption}{}
    A state $s_t$ is \textbf{Markovian} if the future is independent of the past information, given the present state: the probability of ending up in a given state $s_{t+1}$ by applying $a_t$ at time $t$, depends only on the current state $s_t$ and not on the history $h_t$:\begin{equation}
        \Prob(s_{t+1} \mid s_t,a_t)=\Prob(s_{t+1} \mid h_t,a_t).
    \end{equation}
\end{boxdefinition}
\noindent A state can always be made Markovian if we define the state exactly as the previous history:\begin{equation}
    s_t=h_t.
\end{equation}
In practice the current state is defined as the \textit{latest observation}:\begin{equation}
    s_t=o_t
\end{equation}
in this case the state is said to be \textbf{fully observable}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\textwidth]{images/MDP.eps} 
    \caption{Markov Decision Process scheme.}
    \label{fig:MDP}
\end{figure}
A \textbf{Markov Decision Process (MDP)} is a sequential decision making scheme under the Markov assumption. The transition dynamics is generally stochastic: $\Prob(s_{t+1} \mid s_t,a_t)$. An alternative notation to denote the fact that the next state is stochastic by applying $a_t$ on $s_t$ is the following:\begin{align}
    &s_{t+1}\sim \Prob(\cdot  \mid s_t,a_t)\\
    \text{ or }\quad &s'\sim \Prob(\cdot  \mid s,a)
\end{align}
A \textbf{reward} $r_t$ is a scalar signal representing feedback on the actions taken by the agent, and indicates how well an agent is doing at a given time step $t$. The reward is a function of the state and action (reward taken by applying a given action at a given state):\begin{equation}
    r_{t+1}=R(s_t,a_t).
\end{equation} 
We define the \textbf{cost} as the opposite of the reward. Although in reinforcement learning the objective is always to maximize the reward function, the fact that this is the best way to reach a goal is not guaranteed, in fact the so-called \textbf{Reward Hypothesis}:
\begin{quote}
``\textit{all goals can be described as the maximization of expected cumulative reward.}''
\end{quote}
remains an open question today.
\begin{boxdefinition}{Markov Decision Process}{MDP}
    An MDP is defined by a 5-tuple:\begin{equation}
        (S,A,\Prob,R,\gamma) 
    \end{equation}
    where:\begin{itemize}
        \item $S$ is the set of all possible states.
        \item $A$ is the set of all the actions the agent can take.
        \item $\Prob$ is the transition probability, which defines the dynamics of the environment.
        \item $R$ is the reward function.
        \item $\gamma$ is the \textbf{discount factor}, a real value within the interval $[0, 1)$ that determines the importance of future rewards compared to immediate ones.
    \end{itemize}
\end{boxdefinition}
\noindent The behavior of an agent is given by a policy, a function that determines how agents select actions.
\begin{boxdefinition}{Policy}{}
    A \textbf{policy} is a function $\pi:S\to \Delta(A)$ that assigns a distribution over the set of actions to every state.
\end{boxdefinition}
\noindent A policy can be deterministic (special case where $\pi:S\to A$) and we write:\begin{equation}
    \pi(s)=a
\end{equation}
\noindent or stochastic:\begin{equation}
    \pi(a \mid s)\in [0,1] \quad \text{ with } \quad \sum_{a\in A}\pi(a \mid s)=1.
\end{equation}
We can also write $a\sim \pi(\cdot  \mid  s)$. Let's define the \textbf{probability of a trajectory}: What's the probability of seeing a given trajectory at time $t$ 
according to $\pi$ starting at $s_0$? We have the trajectory\begin{equation}
    (s_0,a_0,s_1,\dots,s_t,a_t)
\end{equation}
and
\begin{align}
    &\Prob^\pi(a_0,s_1,\dots,s_t,a_t \mid s_0)\\
    =& \pi(a_0 \mid s_0)\Prob(s_1 \mid s_0,a_0)\pi(a_1 \mid s_1)\Prob(s_2 \mid s_1,a_1)\dots 
    \Prob(s_t \mid s_{t-1},a_{t-1})\pi(a_t \mid s_t)
\end{align}
notice how we added $\pi$ as superscript to denote the fact that this probability depends on the given policy function. We can also define the \textbf{state visitation probability}, i.e. the probability of visiting a particular state $\hat s$ at time $t$ according to $\pi$ starting from $s_0$:\begin{equation}\label{state_visitation}
    \Prob^\pi_t(s_t=\hat s \mid s_0)=\sum_{a_0,s_1\dots a_{t-1}} \Prob^\pi(s_0,a_0,s_1,\dots,s_t=\hat s).
\end{equation}
The summation in equation \eqref{state_visitation} sums over all trajectories of length $t$ that start at $s_0$ and end in $\hat{s}$.

A basic example of a Markov decision process is a robotic manipulator with a hand gripper that can grab and carry a ball:\begin{itemize}
    \item the states are the possible robot configurations (joint values) and the ball position,
    \item the actions are the possible torques on the arm and the finger joints,
    \item the transition is stochastic, given by the physics (how the torques update the joint values over time) and by the noise,
    \item the policy maps each configuration+ball position to a torque for the joints,
    \item the cost (opposite of the reward) is the magnitude of the torque and the distance to the goal.
\end{itemize}
\subsection{MDP Horizon}
In Definition \ref{def:MDP} we introduced a discount factor $\gamma\in[0,1)$. This term weights the importance of immediate rewards with respect to future rewards:\begin{itemize}
    \item $\gamma=0$: Our agent only cares about immediate rewards.
    \item $\gamma=1$: Immediate and future rewards are equally important.
\end{itemize}
The discount factor is used in the \textbf{Value Function} $V^\pi$, a function that estimates the goodness of a state based on its value. It is also a measure to compare different policies.\begin{boxdefinition}{Value Function}{}
    The \textbf{Value Function} $V^\pi$ measures the expected cumulative reward (the sum of all future rewards, possibly discounted by the $\gamma$ factor) starting from $s$ and continuing to follow the policy $\pi$ for all subsequent actions. 
    \begin{align}
    V^\pi(s)=&\VA_\pi\left[ 
    \sum_{h=0}^\infty  \gamma^hr_{h+1}  
    \mid  s_0=s
    \right]\\ 
    =&\VA\left[
        \sum_{h=0}^\infty \gamma^h\cdot\underbrace{r_{h+1}}_{R(s_h,a_h)}  \mid  s_0=s,\  a_h\sim \pi(\ \cdot \mid s_h),\ s_{h+1}\sim \Prob(\cdot  \mid  s_h,a_h)
    \right].
\end{align}
\end{boxdefinition}
With $\VA$ we denote the expected value. The value function $V^\pi$ considers all the possible infinite trajectories that are generated by applying $\pi$ starting from the argument $s$, since the transition and the policy are (or might be) stochastic, a probability is assigned to each trajectory, so the expected value is considered, i.e. the sum over the cumulative reward of a given trajectory, weighted by the probability of that trajectory.\bigskip 

\noindent \textbf{Example}: Let's assume that there is an MDP with three possible trajectories starting from $s_a$:\begin{align}
    &\text{trajectory 1}: (s_a, a,s_c)\\
    &\text{trajectory 2}: (s_a, a, s_b, a,s_c)\\
    &\text{trajectory 3}: (s_a, a, s_b, a,s_b,a,s_c)
\end{align}
There is only one action (always chosen by the policy) and the reward function is deterministic:\begin{align}
    &R(s_a,a)=2\\ 
    &R(s_b,a)=1\\ 
    &R(s_c,a)=0
\end{align} Usually these trajectories are infinite, but in this case we assume that they all end up in $s_c$, an ending state where all actions have a reward of zero with probability 1:\begin{equation}
    \Prob(s_c|s_c,a)=1.
\end{equation}
The expected value of the cumulative reward assuming the following probabilities:\begin{align}
    &\Prob(s_a, a,s_c)=0.2\\
    &\Prob(s_a, a, s_b, a,s_c)=0.1\\
    &\Prob(s_a, a, s_b, a,s_b,a,s_c)=0.7
\end{align}
assuming $\gamma=1$ is\begin{equation}
    2\cdot 0.2+3\cdot 0.1+ 4\cdot 0.7=3.5.
\end{equation}
The Action-Value function $Q^\pi$ goes one step further than $V^\pi$, tying the value not only to the state, but also to the action you choose to take.
\begin{boxdefinition}{Action-Value Function}{}
    The \textbf{Action-Value Function} $Q^\pi$  measures the expected value of the cumulative reward starting from a state $s$, performing a specific action $a$ and then continuing to follow the policy $\pi$.
    \begin{align}
    Q^\pi(s,a)=\VA\left[
         \sum_{h=0}^\infty\gamma^h\cdot\underbrace{r_{h+1}}_{R(s_h,a_h)} \mid 
         (s_0,a_0)=(s,a),\ \underbrace{a_h\sim \pi(\ \cdot \mid s_h)}_{\forall \ h \ge 1},\ s_{h+1}\sim \Prob(\cdot \mid s_h,a_h)
    \right].
\end{align}
\end{boxdefinition}
\begin{boxtheorem}{The Bellman Equation}{}
    The value of a certain state can be expanded in terms of the 
current reward and the value of the next states according to 
the policy:\begin{equation}\label{Bellman_V}
   V^\pi(s)=\sum_{\greenText{a}\in A}\pi(\greenText{a} \mid s)\left[
    R(s,\greenText{a})+\gamma\sum_{s'\in S}\Prob(s' \mid s,\greenText{a})V^\pi(s')
   \right].
\end{equation}
\end{boxtheorem}
\noindent The Bellman equation can be applied to the action-value function:\begin{equation}\label{Bellman_Q}
    Q^\pi(s,\greenText{a})=R(s,\greenText{a})+\gamma\sum_{s'\in S}\Prob(s' \mid s,\greenText{a})V^\pi(s').
\end{equation}
In Equation \eqref{Bellman_V} $V^\pi$ is a function of $s$ and $\pi(s)$ while in equation \eqref{Bellman_Q} $Q^\pi$ is a function of $s$ and $a$ (as highlighted by the \greenText{ green } characters). As a result of these equations we have the following identity:
\begin{equation}
    V^\pi(s)=\sum_{a\in A}\pi(a \mid s)Q^\pi(s,a)
\end{equation}
if $\pi$ is deterministic:
\begin{equation}
    V^\pi(s)=Q^\pi(s,\pi(s))
\end{equation}
$V^\pi$ can be expressed in terms of $Q^\pi$. One last quantity that we introduce is the following.
\begin{boxdefinition}{Discounted State-Action Distribution}{}
    The discounted state-action distribution quantifies how often (and with what discounted time weight) the pair $(s, a)$ is visited along the entire infinite horizon.
    \begin{equation}
        d_{s_0}^\pi(s,a)=(1-\gamma)\sum_{h=0}^\infty \gamma^h\Prob^\pi(s_h = s \mid s_0)\pi(a \mid s).
    \end{equation}
    Since there is a discount factor $\gamma < 1$, events that occur far away in time matter less and less.
\end{boxdefinition}
$\Prob^\pi(s_h = s \mid s_0)\pi(a \mid s)$ is the exact probability of being in state $s$ and executing action $a$ exactly at time step $h$, conditioned on having started in $s_0$ and having followed the $\pi$ policy for all previous steps.
\section{Optimality of a Policy}
For an infinite horizon MDP there always exists a deterministic \textbf{optimal policy} $\pi^\star$ that satisfies:\begin{equation}
    V^{\pi^\star}(s)\ge V^\pi(s), \quad \forall s, \ \forall \pi
\end{equation}
This means that the policy $\pi^\star$ is the one that guarantees the greatest expected reward, since it dominates all other policies in each state. We will use also the following notation:\begin{align}
    &V^{\pi^\star}=V^*\\ 
    &Q^{\pi^\star}=Q^*.
\end{align}
The \textbf{Bellman Optimality} condition states that:\begin{equation}\label{BellmanOptimality}
    V^*(s)=\max_{a\in A}Q^*(s,a).
\end{equation}
\noindent\textbf{Example}: Consider the MDP in Figure \ref{MDP_example}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.3\textwidth]{images/MDP_example.eps} 
    \caption{Three-states MDP example.}
    \label{MDP_example}
\end{figure}
We assume that $V^*$ is known in the states $s'$ and $s''$. We want to try $a'$ and $a''$ in $s$ in order to get the rewards and compute $Q^*$ in $s$ for the actions:\begin{itemize}
    \item We apply $a'$ and get $R(s,a')$. We can compute $Q^*(s,a')=R(s,a')+\gamma \underbrace{V^*(s')}_{\text{known}}$.
    \item We apply $a''$ and get $R(s,a'')$. We can compute $Q^*(s,a'')=R(s,a'')+\gamma \underbrace{V^*(s'')}_{\text{known}}$.
\end{itemize}
Now we can use the identity in Equation \eqref{BellmanOptimality} to compute $V^*(s)$:\begin{equation}
    V^*(s)=\max\{Q^*(s,a'), \ Q^*(s,a'')\}.
\end{equation}
\begin{boxtheorem}{Bellman Optimality (Existence)}{}
    Let $\gamma\in[0,1)$. The optimal value function $V^*(s)$ satisfies the nonlinear Bellman equation:
    \begin{equation}\label{BellmanEquation}
        V^*(s) = \max_{a \in {A}} \left[ R(s,a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^*(s') \right]
    \end{equation}
    hence the policy:\begin{equation}\label{optimal_policy}
        \hat \pi(s) = \operatorname*{arg\,max}_{a\in A} Q^*(s,a)
    \end{equation}
    is the optimal policy: $V^{\hat \pi}=V^*$.
\end{boxtheorem}
\noindent\textit{Proof}: First we prove that $V^*$ satisfies the Bellman Equation \eqref{BellmanEquation}.
For a generic policy $\pi$, we can write the Bellman equation by isolating the first action $a\sim\pi(\cdot \mid s)$:\begin{equation}
    V^\pi(s) = \sum_{a \in {A}} \pi(a \mid s) \left[ R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^\pi(s') \right].
\end{equation}
The optimal value function can be written as follows:\begin{equation}
    V^*(s)=\max_\pi\sum_{a \in {A}} \pi(a \mid s) \left[ R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^\pi(s') \right].
\end{equation}
Consequently, the maximum over $\pi$ coincides with the maximization over a single action $a \in {A}$ by placing $V^*(s')$ in the future steps:\begin{equation}
    V^*(s) = \max_{a \in {A}} \left[ R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^*(s') \right]
\end{equation}
hence $V^*$ satisfies the Bellman equation. Now we have to prove that $\hat \pi$ is the optimal policy. We define the deterministic policy $\hat\pi$ as in Equation \eqref{optimal_policy}. Since $\hat\pi(s)$ selects the action that maximizes $Q^*$ we can write:\begin{align}
    V^*(s) =&\max_{a \in {A}} \left[ R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^*(s') \right]\\ =&R(s, \hat{\pi}(s)) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) V^*(s').\label{hatPi}
\end{align}
On the other hand, from the Bellman expectation equation applied to $\hat \pi$ we can write:\begin{equation}\label{expectation}
    V^{\hat{\pi}}(s) = R(s, \hat{\pi}(s)) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) V^{\hat{\pi}}(s')
\end{equation}
if we subtract \eqref{expectation} from \eqref{hatPi} we get:\begin{equation}
    V^*(s) - V^{\hat{\pi}}(s) = \gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \Big( V^*(s') - V^{\hat{\pi}}(s') \Big).
\end{equation}
Now we take the absolute value of both sides:
\begin{equation}
    |V^*(s) - V^{\hat{\pi}}(s)| = \big\vert{}\gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \Big( V^*(s') - V^{\hat{\pi}}(s') \Big)\big\vert{}.
\end{equation}
By the triangle inequality:
\begin{align}  
     |V^*(s) - V^{\hat{\pi}}(s)| =&\big\vert{}\gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \Big( V^*(s') - V^{\hat{\pi}}(s') \Big)\big\vert{}\\
    \le&\gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \big\vert{} V^*(s') - V^{\hat{\pi}}(s')\big\vert{}\\ 
    \le&\gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \| V^* - V^{\hat{\pi}}\|_\infty
\end{align}
we used the $L_\infty$ norm, the following inequality holds:
\begin{equation}
    |V^*(s) - V^{\hat{\pi}}(s)| \le \gamma \sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s)) \|V^* - V^{\hat{\pi}} \|_\infty.
\end{equation}
$\|V^* - V^{\hat{\pi}} \|_\infty$ is constant and $\displaystyle\sum_{s' \in {S}} \Prob(s' \mid s, \hat{\pi}(s))=1$, hence
\begin{equation}
    |V^*(s) - V^{\hat{\pi}}(s)| \le \gamma\|V^* - V^{\hat{\pi}} \|_\infty.
\end{equation}
this holds for each $s$ hence:
\begin{align}
    &\|V^* - V^{\hat{\pi}} \|_\infty \le \gamma\|V^* - V^{\hat{\pi}} \|_\infty\implies \\ 
    &\|V^* - V^{\hat{\pi}} \|_\infty=0\implies \\ 
    &V^{\hat{\pi}}(s)=V^*(s), \quad \forall s.
\end{align}
\hfill$\blacksquare$
\begin{boxtheorem}{Bellman Optimality (Uniqueness)}{}
    Let $\gamma\in[0,1)$. If a value function $V$ satisfies the Bellman equation:\begin{equation}
       V(s) = \max_{a \in A} \left[ R(s,a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V(s') \right] \quad \forall s \in {S}
    \end{equation}
    then $V(s)=V^*(s)$ for all $s\in S$ ($V$ is the value function of the optimal policy).
\end{boxtheorem}
\noindent\textit{Proof}: Let $V$  be any value function satisfying the Bellman optimality equation for all $s \in S$. Since $V^*$ is also a solution, we can write (for any state $s$):\begin{align}
    &\vert{}V(s) - V^*(s)\vert{}\\ =&\left\vert{} \max_{a \in {A}} \left( R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V(s') \right) - \max_{a \in {A}} \left( R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^*(s') \right) \right\vert{}. 
\end{align}
Using the property $\displaystyle\vert{}\max_a f(a) - \max_a g(a)\vert{} \le \max_a \vert{}f(a) - g(a)\vert{}$: \begin{align}
    &\vert{}V(s) - V^*(s)\vert{}\\ \le &\max_{a \in {A}} \left\vert{} \left( R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V(s') \right) - \left( R(s, a) + \gamma \sum_{s' \in {S}} \Prob(s' \mid s, a) V^*(s') \right) \right\vert{} 
\end{align}
we can cancel out $R(s,a)$ and move $\gamma$ outside the max function:\begin{equation}
    \vert{}V(s) - V^*(s)\vert{} \le \gamma \max_{a \in {A}} \left\vert{} \sum_{s' \in {S}} \Prob(s' \mid s, a) \big( V(s') - V^*(s') \big) \right\vert{} 
\end{equation}
by the triangle inequality we can move the absolute value inside the sum:\begin{equation}\label{after_triangle_ineq}
    \vert{}V(s) - V^*(s)\vert{} \le \gamma \max_{a \in {A}}  \sum_{s' \in {S}} \Prob(s' \mid s, a)\left\vert{}  V(s') - V^*(s')  \right\vert{} .
\end{equation}
We use the definition of $L_\infty$ norm:\begin{equation}
    \vert{}V(s') - V^*(s')\vert{} \le \max_{y \in {S}} \vert{}V(y) - V^*(y)\vert{} = \Vert{}V - V^*\Vert{}_\infty
\end{equation}
Equation \eqref{after_triangle_ineq} becomes:\begin{equation}
    \vert{}V(s) - V^*(s)\vert{} \le \gamma \max_{a \in {A}} \sum_{s' \in {S}} \Prob(s' \mid s, a) \Vert{}V - V^*\Vert{}_\infty 
\end{equation}
$\Vert{}V - V^*\Vert{}_\infty$ is a constant hence can be moved out of the summation:\begin{equation}
    \vert{}V(s) - V^*(s)\vert{} \le \gamma \max_{a \in {A}} \left( \Vert{}V - V^*\Vert{}_\infty \sum_{s' \in {S}} \Prob(s' \mid s, a) \right)
\end{equation}
trivially
$$\sum_{s' \in {S}} \Prob(s' \mid s, a)=1$$
hence
\begin{equation}
    \vert{}V(s) - V^*(s)\vert{} \le \gamma \max_{a \in {A}} \Big( \Vert{}V - V^*\Vert{}_\infty \cdot 1 \Big) = \gamma \Vert{}V - V^*\Vert{}_\infty
\end{equation}
since this inequality holds for each state $s\in S$, we can write:\begin{align}
    &\underbrace{\max_{s \in {S}} \vert{}V(s) - V^*(s)\vert{}}_{\Vert{}V - V^*\Vert{}_\infty} \le \gamma \Vert{}V - V^*\Vert{}_\infty\implies\\[1.5ex]
    &\Vert{}V - V^*\Vert{}_\infty \le \gamma \Vert{}V - V^*\Vert{}_\infty \implies \\[1.5ex]
    &(1 - \gamma) \Vert{}V - V^*\Vert{}_\infty \le 0\implies  \Vert{}V - V^*\Vert{}_\infty =0.
\end{align}
This holds since $\gamma\in[0,1)$, hence $(1-\gamma)> 0$. By definition:\begin{align}
    &\Vert{}V - V^*\Vert{}_\infty =0\implies \\ 
    &V(s) = V^*(s) \quad \forall s \in {S}.
\end{align}
\hfill$\blacksquare$\bigskip


This formulation reduces the multi-step problem to a one-step greedy choice plus the continuation value $V(s')$. By uniqueness of the fixed point, any function $V$ satisfying this optimality equation coincides with $V^*$.
\section{Value iteration}
We have seen how the value function estimates the goodness of a state based on its value, by applying a given policy, hence it is also a measure to compare policies.\begin{equation}
    V^\pi(s_t)=\VA_\pi[r_t+\gamma r_{t+1}+\gamma^2 r_{t+2}\dots\mid s_t]=\VA\left[
        \sum_{h=0}^{\infty}\gamma^hr_{h}\mid  
        s_0=s_t,\ a_h=\pi(s_h),\ s_{h+1}\sim p(\cdot\mid s_h,a_h)
    \right].
\end{equation}
\noindent About the notation: from now we will also use $p(\cdot\mid s_h,a_h)$ to denote the probability instead of the symbol $\Prob$.
\subsection{Exact Policy Evaluation}
In this section we will describe a method to \textit{compute exactly the value function} $V^\pi$ of a given policy $\pi$, by assuming that the reward function is deterministic, and the transition probabilities are known.
For all the states, the Bellman expectation equation holds:\begin{equation}
    V^\pi(s)=r(s,\pi(s))+\gamma\VA_{s'\sim p(\cdot\mid s,\pi(s))}[V^\pi(s')]
\end{equation}
with the explicit expression of the expected value being:
\begin{equation}
    V^\pi(s)=
    r(s,\pi(s))+\gamma\sum_{s'\in S}V^\pi(s')p(s'|s,\pi(s))
\end{equation}
this can be written as a system of $|S|$ equations (one for each state), hence the value function $V^\pi$ and the rewards $\mathbf r^\pi$ can be seen as vectors in $\R^m$:\begin{equation}
    \mathbf V^\pi=\begin{pmatrix}
        V^\pi(s_1)\\\vdots\\ V^\pi(s_m)
    \end{pmatrix},\quad 
    \mathbf r^\pi=\begin{pmatrix}
       r(s_1,\pi(s_1))\\\vdots\\ r(s_m,\pi(s_m))
    \end{pmatrix}
\end{equation}
by defining $m=|S|$. Then, for the transition probabilities we have the $m\times m$ matrix $P^\pi$ defined as follows:\begin{equation}
    P^\pi(i,j)=p(s_j\mid s_i,\pi(s_i))
\end{equation} 
The element at row $i$ and column $j$ represents the conditional probability $p(s_j \vert{} s_i, \pi(s_i))$ of moving from state $s_i$ to state $s_j$ (given by the transition function):
\begin{equation}
     P^\pi=\begin{pmatrix}
        p(s_1\mid s_1,\pi(s_1))&\dots&p(s_m\mid s_1,\pi(s_1))\\
         \vdots&\ddots&\vdots\\
         p(s_1\mid s_m,\pi(s_m))&\dots&p(s_m\mid s_m,\pi(s_m))
     \end{pmatrix}
\end{equation}
hence the Bellman expectation can be expressed in matrix form:\begin{equation}
    \mathbf V^\pi=\mathbf r^\pi+\gamma P^\pi \mathbf V^\pi
\end{equation}
if the rewards $\mathbf r^\pi$ and the transition probabilities $P^\pi$ are known, we can solve this system of equations for $\mathbf V^\pi$ by inverting the matrix:\begin{equation}
     \mathbf V^\pi=(I-\gamma P^\pi)^{-1}\mathbf r^\pi. 
\end{equation}
If $m=|S|$ is big (large number of states) this inversion becomes computationally expensive, since the number of operations is in $O(m^3)$.
\subsection{Fixed Point Iteration}
We will describe a computationally less expensive method to compute $V^\pi(s)$ for each $s$. Given a metric space $M$ and a function $f:M \rightarrow M$, a point $\mathbf x\in M$ is called \textbf{fixed} if:\begin{equation}
    f(\mathbf x)=\mathbf x.
\end{equation}
These points are related to a particular class of functions.
\begin{boxdefinition}{Contraction Mapping}{}
    A function $f:M \rightarrow M$ is a contraction mapping if  there exists a constant $k\in [0,1)$ such that, for every pair of points $\mathbf x,\mathbf y$ the following condition holds:\begin{equation}
        \|f(\mathbf x)-f(\mathbf y)\|\le k\|\mathbf x-\mathbf y\|
    \end{equation}
\end{boxdefinition}
\noindent The following result is crucial.
\begin{boxtheorem}{Banach}{}
    If $f:M\rightarrow M$ is a contraction mapping and $M$ is complete, then there exists a unique fixed point $\mathbf x^*\in M$
  $$
        f(\mathbf x^*)=\mathbf x^*
$$
    and, by starting from an arbitrary $\mathbf x_0\in M$, and applying iteratively  $$\mathbf x_{i+1}=f(\mathbf x_i)$$ for $i=0,1,\dots \infty$, the sequence will converge to $\mathbf x^*$.
\end{boxtheorem}
\noindent In the simplest case, the contraction mapping $f$ is just a matrix $O$:
\begin{equation}
        \|O\mathbf x-O\mathbf y\|\le \gamma \|\mathbf x-\mathbf y\|
\end{equation}
instead of $k$ we are  using the discount factor $\gamma\in [0,1)$. We will use the fact that the value function $\mathbf V^\pi$ \textbf{is a fixed point} of a given operator, and can be found by applying that operator (that is a contraction mapping) iteratively.\bigskip 


The metric space we work in, of which $\mathbf V^\pi$ is part, is $\R^m$. The contraction mapping $\mathcal B$ that we will use is the following:\begin{equation}
    \mathcal B(\mathbf x)=\mathbf r^\pi+\gamma P^\pi\mathbf x
\end{equation}
this is an affine operator, defined through the rewards $\mathbf r^\pi$ and the probabilities of the transitions $P^\pi$. The value function $V^\pi$ is \textbf{the fixed point of} $\mathcal B$. Hence we have an iterative algorithm.

\begin{algorithm}[H]
\caption{Fixed Point Iteration}\label{alg:fixed_point_iteration}
\begin{algorithmic}[1]
\State initialize $\mathbf V_0=\mathbf 0$ 
\State let $t=0$ 
\Do
\State $\mathbf V_{t+1}=\mathbf r^\pi+\gamma P^\pi\mathbf V_t$
\State $t\leftarrow t+1$
\doWhile{convergence is not met}
\end{algorithmic}
\end{algorithm}
\noindent We can stop the iterations when the difference between $\mathbf V_{t+1}$ and $\mathbf V_{t}$ is less than a defined threshold $\epsilon$:\begin{equation}
    \text{stop if }\|\mathbf V_{t+1}-\mathbf V_{t}\|\le\epsilon.
\end{equation}
We have to prove the fact that the Algorithm \ref{alg:fixed_point_iteration} converges to the value function $\mathbf V^\pi$.
\begin{boxtheorem}{Iterative Policy Evaluation}{}
    Let $\mathbf V_0$ be our starting guess for the value function $\mathbf V^\pi$, and\begin{equation}
        \mathbf V_{t+1}=\mathcal B ( \mathbf V_t).
    \end{equation}
    We denote $V_t(s)$ the component of $\mathbf V_t$ relative to the state $s$.
    For each single state $s\in S$ we have:\begin{equation}\label{iterative_policy_eval}
        |[\mathcal BV_t](s)-\mathcal [BV^\pi](s)|=|V_{t+1}(s)-V^\pi(s)|\le\gamma^{t+1}\|
        \mathbf V_0-\mathbf V^\pi\|_\infty.
    \end{equation}
\end{boxtheorem}
\noindent\textit{Proof}:
If Equation \eqref{iterative_policy_eval} holds, by applying $\mathcal B$ for a large number of steps $(t\rightarrow\infty)$, we would have:\begin{align}
    &\lim_{t\rightarrow\infty}|V_{t+1}(s)-V^\pi(s)|\le\lim_{t\rightarrow\infty}\gamma^{t+1}\|
        \mathbf V_0-\mathbf V^\pi\|\implies \lim_{t\rightarrow\infty} |V_{t+1}(s)-V^\pi(s)|=0\\ 
        &\implies  \lim_{t\rightarrow\infty}V_{t}(s)=V^\pi(s),\quad \forall s\in S
\end{align} 
Let's start with the proof, the following reasoning holds for all the states $s\in S$. We have \begin{equation}
    |V_{t+1}(s)-V^\pi(s)|
\end{equation}
we expand $V_{t+1}(s)$ and $V^\pi(s)$:\begin{align}
    &V_{t+1}(s)=r(s,\pi(s))+\gamma\sum_{s'\in S}V_t(s')p(s'\mid s,\pi(s))\\ 
    &V^\pi(s)=r(s,\pi(s))+\gamma\sum_{s'\in S}V^\pi(s')p(s'\mid s,\pi(s))
\end{align}
hence we have\begin{align}
    &|V_{t+1}(s)-V^\pi(s)|\\ 
    =&\left|\sapText{r(s,\pi(s))}+\gamma\sum_{s'\in S}V_t(s')p(s'\mid s,\pi(s))
    \sapText{-r(s,\pi(s))}-\gamma\sum_{s'\in S}V^\pi(s')p(s'\mid s,\pi(s))\right|
\end{align}
$r(s,\pi(s))$ can be canceled:\begin{equation}
    \left|\gamma\sum_{s'\in S}V_t(s')p(s'\mid s,\pi(s))
   -\gamma\sum_{s'\in S}V^\pi(s')p(s'\mid s,\pi(s))\right|
\end{equation}
the two terms are summing over the same set hence:\begin{equation}
      \left|\gamma\sum_{s'\in S}V_t(s')p(s'\mid s,\pi(s))
   -V^\pi(s')p(s'\mid s,\pi(s))\right|
\end{equation}
we apply the triangle inequality:\begin{align}
    & \left|\gamma\sum_{s'\in S}V_t(s')p(s'\mid s,\pi(s))
   -V^\pi(s')p(s'\mid s,\pi(s))\right|\\[1.5ex]
   \le & \gamma\sum_{s'\in S}\left|V_t(s')p(s'\mid s,\pi(s))
   -V^\pi(s')p(s'\mid s,\pi(s))\right|
\end{align}
we can group $p(s'\mid s,\pi(s))$\begin{equation}
    \gamma\sum_{s'\in S}\left|p(s'\mid s,\pi(s))\big(V_t(s')
   -V^\pi(s')\big)\right|
\end{equation}
since $$|V_t(s')
   -V^\pi(s')|\le\|V_t-V^\pi\|_\infty $$
   we can proceed as follows:\begin{align}
    &\gamma\sum_{s'\in S}\left|p(s'\mid s,\pi(s))\big(V_t(s')
   -V^\pi(s')\big)\right|\\ 
   \le&\gamma\sum_{s'\in S}p(s'\mid s,\pi(s))\|V_t-V^\pi\|_\infty
   \end{align}
$\|V_t-V^\pi\|_\infty$ is constant hence we can move it out of the sum and get:\begin{align}
    &\gamma\sum_{s'\in S}p(s'\mid s,\pi(s))\|V_t-V^\pi\|_\infty\\[1.5ex] &=
    \gamma\|V_t-V^\pi\|_\infty\underbrace{\sum_{s'\in S}p(s'\mid s,\pi(s))}_{\text{sum up to 1}}=
    \gamma\|V_t-V^\pi\|_\infty.
\end{align}
We have obtained the following inequality\begin{equation}
    |V_{t+1}(s)-V^\pi(s)|\le  \gamma\|V_t-V^\pi\|_\infty,\quad \forall s\in S
\end{equation}
since it holds for each $s$, we switch to the $L_\infty$ norm:\begin{equation}
    \|V_{t+1}-V^\pi\|_\infty\le  \gamma\|V_t-V^\pi\|_\infty
\end{equation}
hence:\begin{equation}
     \|V_{t+1}-V^\pi\|_\infty\le  \gamma\|V_t-V^\pi\|_\infty\le\gamma^{t+1}\|V_0-V^\pi\|_\infty.
\end{equation}
\hfill$\blacksquare$\bigskip

\noindent The computational cost of finding an $\epsilon$-accurate value function is in $O(m^2\ln\frac{1}{\epsilon})$.\bigskip

Now that we know how to compute the value function of a given policy, we are interested in finding the optimal policy $\pi^*$. We can perform a brute force search, by listing all the possible policies and evaluating their value function, but this would be computationally unfeasible, in the order of $O(|A|^m\cdot m^3)$, where $m=|S|$.
We can use the Bellman optimality equation:\begin{equation}
    V^*(s) = \max_{a \in {A}} \left[ R(s,a) + \gamma \sum_{s' \in {S}} p(s' \mid s, a) V^*(s') \right].
\end{equation}
We define the operator $\mathcal B$ as the Bellman optimality equation:\begin{equation}
    [\mathcal BV](s)=\max_{a \in {A}} \left[ R(s,a) + \gamma \sum_{s' \in {S}} p(s' \mid s, a) V(s') \right].
\end{equation}
we call this operator the \textbf{Bellman optimality operator}, it acts on a ``value function'' $V$.
\begin{boxobservation}{}{}
   Note that for a fixed policy, there is a unique value function corresponding to it, rather than multiple ones. As we stated, the Bellman optimality operator acts on a ``value function'', meaning it maps a function that assigns a real number to each state (which can also be viewed as a vector in $\mathbb{R}^m$) to another function of the same type. Specifically, the Bellman optimality operator takes a value function $V$ and produces a new value function $\mathcal{B}V$. Hence, it can be seen as a mapping from $\mathbb{R}^m$ to $\mathbb{R}^m$, though in our context it is more accurate to think of it as an operator acting on the space of ``possible'' value functions.
\end{boxobservation}
\noindent We recall that the infinity norm of a value function is $\|V\|_{\infty}=\max_s|V(s)|$.
\begin{boxtheorem}{Bellman Optimality Operator is a Contraction}{}
    Given two value functions $V_k,V_j$ (that can be seen as vector in $\R^m$), then:\begin{equation}
        \|\mathcal BV_k-\mathcal BV_j\|_\infty\le\gamma\|V_k-V_j\|_\infty
    \end{equation}
\end{boxtheorem}
\noindent\textit{Proof}:\begin{align}
&\|\mathcal{B}V_k - \mathcal{B}V_j\|_\infty\\ =& \left\| \max_{a} \left(r(s,a) + \gamma \sum_{s'\in S} p(s' \mid s, a)V_k(s')\right) - \max_{a'} \left(r(s,a') + \gamma \sum_{s'\in S} p(s' \mid s, a')V_j(s')\right) \right\|_\infty \\[10pt]
\le& \max_{a} \left\| \left(r(s,a) + \gamma \sum_{s'\in S} p(s' \mid s, a)V_k(s') - r(s,a) - \gamma \sum_{s'\in S} p(s' \mid s, a)V_j(s')\right) \right\|_\infty \\[10pt]
=& \max_{a} \left\| \gamma \sum_{s'\in S} p(s' \mid s, a)(V_k(s') - V_j(s')) \right\|_\infty \\[10pt]
\le& \max_{a} \left\| \gamma \sum_{s'\in S} p(s' \mid s, a)\|V_k - V_j\| \right\|_\infty \\[10pt]
=& \max_{a} \left\| \gamma \|V_k - V_j\| \sum_{s'\in S} p(s' \mid s, a) \right\|_\infty \\[10pt]
=& \gamma \|V_k - V_j\|_\infty
\end{align}\hfill$\blacksquare$

\noindent The optimality operator is a $\gamma$-contraction, it makes value functions closer by a factor of at least $\gamma$. Now we define the Bellman operator for the $Q$ function. We recall that $Q$ assigns a value to each pair state-action. The operator is defined as follows:\begin{equation}
    [\mathcal B Q](s,a)=r(s,a)+\gamma\VA_{s'\sim p(\cdot \mid s,a)}\left(\max_{a'}[Q(s',a')]\right).
\end{equation}
Since $Q:S\times A \rightarrow \R$, then also $\mathcal B Q:S\times A \rightarrow \R$.
\begin{boxproposition}{}{}
    The $Q$-function associated to the optimal policy, denoted $Q^*$, is a fixed point of the Bellman operator $\mathcal B$, that is a contraction mapping.
\end{boxproposition}
This is a crucial result, we can obtain the $Q$-function of the optimal policy just by applying the operator iteratively.
\begin{algorithm}[H]
\caption{Value Iteration}\label{alg:value_iteration}
\begin{algorithmic}[1]
\State initialize $Q_0$ as\begin{equation*}
    Q_0(s,a)=0,\quad \begin{matrix}
        \forall s\in S\\\forall a\in A
    \end{matrix}
\end{equation*} 
\State let $t=0$ 
\Do
\State $Q_{t+1}=\mathcal BQ_t$
\State $t\leftarrow t+1$
\doWhile{convergence is not met}
\end{algorithmic}
\end{algorithm}
\noindent The correctness is guaranteed by the fact that the operator is a contraction mapping:\begin{equation}
    \|Q_{t+1}-Q^*\|_\infty=\|\mathcal BQ_{t}-Q^*\|_\infty\le  
    \gamma\|Q_t-Q^*\|_\infty\le  \gamma^{t+1}\|Q_0-Q^*\|_\infty
\end{equation}
Now that we know how to find the $Q$-function of the optimal policy, we have to define the optimal policy, this is easy. Assume that we have executed Algorithm \ref{alg:value_iteration} for $i$ iterations, if $i$ is sufficiently large we have \begin{equation}
    Q_i(s,a)\simeq Q^*(s,a),\quad \begin{matrix}
        \forall s\in S\\\forall a\in A
    \end{matrix}
\end{equation}
at this point we define the policy (relative to $i$ iterations) as\begin{equation}
    \pi_i(s)=\operatorname*{arg\,max}_{a\in A}Q_i(s,a).
\end{equation}
the quality of this policy is described by the following result.
\begin{boxproposition}{Value Iteration}{}
Let $Q_i$ be the $Q$-function at the $i$-th iteration of Algorithm \ref{alg:value_iteration}, and let $\pi_i$ be its associated policy. The value function $V^{\pi_i}$ for policy $\pi_i$ is related to the optimal value function $V^*$ as follows:
\begin{equation}
    V^{\pi_i}(s)\ge V^*(s)-\frac{2\gamma^i}{1-\gamma}\|Q_0-Q^*\|_\infty,\quad \forall s\in S
\end{equation}
hence 
\begin{equation}
    \lim_{i\rightarrow\infty}V^{\pi_i}=V^*\implies  \lim_{i\rightarrow\infty}\pi_i=\pi^*.
\end{equation}
\end{boxproposition}
\noindent\textit{Proof}: The following reasoning holds for each $s\in S$, we consider:\begin{equation}
    V^{\pi_i}(s) - V^*(s)
\end{equation}
the value function can be rewritten in terms of the $Q$-function:
\begin{align}
    V^{\pi_i}(s) - V^*(s)&=Q^{\pi_i}(s,\pi_i(s))-Q^*(s,\pi^*(s))\\[1.5ex]

    -Q^*(s,\pi^*(s))
\end{align}
now we take the first two terms $Q^{\pi_i}(s,\pi_i(s))-Q^*(s,\pi_i(s))$ and we expand them with the Bellman equation:\begin{align}

    -Q^*(s,\pi^*(s))\\

        V^{\pi_i}(s')-V^*(s')

\end{align}
now we add $\blueText{-Q_i(s,\pi_i(s))+Q_i(s,\pi^*(s))}$:\begin{align}

        V^{\pi_i}(s')-V^*(s')
    \right]+Q^*(s,\pi_i(s))\blueText{-Q_i(s,\pi_i(s))+Q_i(s,\pi^*(s))}
    -Q^*(s,\pi^*(s))
    \end{align}
we switched to the inequality $\ge$ since $\blueText{-Q_i(s,\pi_i(s))+Q_i(s,\pi^*(s))}$ is not positive:
$$Q_i(s,\pi_i(s))\ge Q_i(s,\pi^*(s))$$
now we use the $L_\infty$ norm:\begin{align}

    \right]+\underbrace{Q^*(s,\pi_i(s))-Q_i(s,\pi_i(s))}_{\ge \|Q_0-Q^*\|_\infty}+\underbrace{Q_i(s,\pi^*(s))
    -Q^*(s,\pi^*(s))}_{\ge \|Q_0-Q^*\|_\infty}\\[1.5ex]

\section{Policy Iteration}
In the previous section we have described an algorithm that iterates over the value functions (or the $Q$-functions) and provides in the end a $Q$-function that is approximately the optimal $Q$-function, from this we can define an approximation of the optimal policy $\pi^*$. In this section we describe an algorithm that generates a policy at each iteration: $\{\pi_0,\pi_1,\dots,\pi_T\}$. The logic of the algorithm is simple: \begin{itemize}
    \item We start with an initial guess $\pi_0$.
    \item We start iterating, at each iteration we evaluate the $Q$-function for our guess.
    \item We use the $Q$-function to improve the guess for the next iteration.
\end{itemize}
\begin{algorithm}[H]
\caption{Policy Iteration}\label{alg:policy_iteration}
\begin{algorithmic}[1]
\State initialize $\pi_0$ with a random guess
\Do
\State compute $Q^{\pi_t}$ for each pair $(s,a)$
\State perform the \textit{policy improvement}:\begin{equation}
    \pi_{t+1}(s)=\operatorname*{arg\,max}_{a\in A}Q^{\pi_t}(s,a),\quad \forall s\in S 
\end{equation}
\doWhile{convergence is not met}
\end{algorithmic}
\end{algorithm}
\begin{boxproposition}{Monotonic Improvement}{}
    For two consecutive steps in Algorithm \ref{alg:policy_iteration}, the performance progress is monotonic:
    \begin{align}
    &Q^{\pi_{t+1}}\ge Q^{\pi_t} \quad \forall s,a \\ 
    &\|V^{\pi_t}-V^*\|_\infty\le\gamma^t\|V^{\pi_0}-V^*\|_\infty.
\end{align}
\end{boxproposition}
\noindent\textit{Proof}: We want to prove that $Q^{\pi_{t+1}}\ge Q^{\pi_t}$ (the policy get better, its state-action value increase). The following reasoning holds for each pair $(s,a)$. Consider:\begin{equation}
    Q^{\pi_{t+1}}(s,a)- Q^{\pi_t}(s,a)
\end{equation}
expand the definitions and simplify $r(s,a)$:
\begin{equation}
    Q^{\pi_{t+1}}(s,a)- Q^{\pi_t}(s,a)=
    \gamma\VA_{s'\sim p(\cdot\mid s,a)}\left[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))-
        Q^{\pi_{t}}(s',\pi_{t}(s'))
    \right]
\end{equation}
we add and subtract $Q^{\pi_t}(s',\pi_{t+1}(s'))$:\begin{align}
    &\gamma\VA_{s'\sim p(\cdot\mid s,a)}\left[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))-
        Q^{\pi_{t}}(s',\pi_{t}(s'))
    \right]\\[1.5ex]
    =&\gamma\VA_{s'\sim p(\cdot\mid s,a)}\left[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))\blueText{-Q^{\pi_t}(s',\pi_{t+1}(s'))+Q^{\pi_t}(s',\pi_{t+1}(s'))}-
        Q^{\pi_{t}}(s',\pi_{t}(s'))
    \right]\\[1.5ex]
    =&\gamma\VA_{s'\sim p(\cdot\mid s,a)}[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))-Q^{\pi_t}(s',\pi_{t+1}(s'))\underbrace{\sapText{+Q^{\pi_t}(s',\pi_{t+1}(s'))-
        Q^{\pi_{t}}(s',\pi_{t}(s'))}}_{\ge 0}
    ]\\
    \sapText{\ge} &\gamma\VA_{s'\sim p(\cdot\mid s,a)}[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))-Q^{\pi_t}(s',\pi_{t+1}(s'))
    ]
\end{align}
We have obtained the following inequality:\begin{equation}
    Q^{\pi_{t+1}}(s,a)- Q^{\pi_t}(s,a)\ge
     \gamma\VA_{s'\sim p(\cdot\mid s,a)}[
        Q^{\pi_{t+1}}(s',\pi_{t+1}(s'))-Q^{\pi_t}(s',\pi_{t+1}(s'))
    ]
\end{equation}
The term within the expected value has the exact same structure as the left-handed difference, but evaluated at the next time step (state $s'$, action $\pi_{t+1}(s')$). By repeatedly applying the same reasoning (expansion and policy improvement) to the subsequent terms, we will accumulate increasing powers of the discount factor $\gamma$:\begin{equation}
    \ge \gamma^2 \mathbb{E}[\dots] \ge \gamma^3 \mathbb{E}[\dots] \dots \ge \lim_{k \to \infty} \gamma^k \mathbb{E}[\dots]
\end{equation}
Since the discount factor is strictly less than 1 and the rewards (and therefore the $Q$-values) are assumed to be bounded, the limit of $\gamma^k$ for $k \to \infty$ converges to $0$, hence:\begin{equation}
    Q^{\pi_{t+1}}(s,a)- Q^{\pi_t}(s,a)\ge0\implies Q^{\pi_{t+1}}(s,a)\ge Q^{\pi_t}(s,a).
\end{equation}
\hfill$\blacksquare$\bigskip

\section{Finite-Horizon MDPs}
We consider finite-horizon MDPs, by setting $H\ge 0$ as the horizon: every trajectory of the system will be at most long $H$, an MDP of that kind is a 6-tuple:\begin{equation}
    (S,A,r,T,H,\mu_0)
\end{equation}
with $\mu_0$ being the initial state distribution ($s_0\sim \mu_0$). Theoretically we don't need to include a discount factor, we can compute the expected value by summing over all the next states up to a finite number, practically, a discount factor is considered also for these MDPs.

We will consider time-dependent policies:\begin{equation}
    \pi=\{\pi_0,\pi_1,\pi_2,\dots,\pi_{H-1}\}
\end{equation}
hence, a policy $\pi$ assign at each pair state-time step an action:\begin{equation}
    \pi(s,t)=\pi_t(s).
\end{equation}
For example, for the initial time steps $\pi$ might explore, then with $t$ growing, it might start to exploit (this kind of strategy is very common in control). Let's discuss about policy iteration for a finite-horizon MDP with time varying policy. In one execution, the first state is sampled $s_0\sim\mu_0$, and the first action is\begin{equation}
    a_0=\pi_0(s_0)
\end{equation}
the transition function is stochastic, hence $s_1$ is given by:\begin{equation}
    s_1\sim p(\cdot\mid s_0,a_0)
\end{equation}
with $p$ being the transition distribution. Then we select:\begin{equation}
    a_1=\pi_1(s_1)
\end{equation}
the first elements of the trajectory are:\begin{equation}
    (s_0,a_0,s_1,a_1)
\end{equation}
the trajectory goes on up to $H-1$:\begin{equation}
     (s_0,a_0,s_1,a_1,s_2,a_2,\dots,s_{H-1},a_{H-1}).
\end{equation}
The finite-horizon value function is defined as\begin{equation}
    V_h^\pi(s)=\VA_\pi\left[
        r(s,\pi(s))+
        \sum_{\tau=h+1}^{H-1}r(s_\tau,\pi(s_\tau))
    \right]
\end{equation}
where  $s_{\tau+1}\sim p(\cdot\mid s_\tau,\pi(s_\tau))$. The state-action function is\begin{equation}\label{Q_h_pi}
    Q_h^\pi(s,a)=\VA_\pi\left[
        r(s,a)+
        \sum_{\tau=h+1}^{H-1}r(s_\tau,\pi(s_\tau))
    \right]
\end{equation}
where  $s_{\tau+1}\sim p(\cdot\mid s_\tau,\pi(s_\tau))$. We want to find an optimal policy for each time step:
\begin{equation}
    \pi^*=\{\pi^*_0,\pi^*_1,\pi^*_2,\dots,\pi^*_{H-1}\}
\end{equation}
\begin{boxobservation}
    Before the final step, the action-value function is equal to the reward, since there will be no other states (the horizon is $H$).\begin{equation}
        Q_{H-1}^*(s,a)=r(s,a).
    \end{equation}
\end{boxobservation}
This implies that we can easily infer what is the best action on $s$ at the time step $H-1$:\begin{equation}
    \pi^*_{H-1}(s)=\operatorname*{arg\,max}_a r(s,a)
\end{equation}
so we can infer the value:\begin{equation}
    V_{H-1}^*(s)=Q^*_{H-1}(s,\pi^*_{H-1}(s)).
\end{equation}
Thanks to the Bellman equation we can compute the state-action value for $H-2$:\begin{equation}
    Q_{H-2}^*(s,a)=r(s,a)+V^*_{H+1}(s)
\end{equation}
by reasoning backwards in this way we can compute the optimal policy for all the time steps $h=H-1,H-2,\dots , 1,0$.

\chapter{Control Theory and Reinforcement Learning}
In this chapter we briefly discuss the bridge between optimal control and reinforcement learning. In control theory we denote by $\mathbf x\in \R^d$ the state and by $\mathbf u\in\R^k$ the input (action) that we can perform. The goal is to find a control policy $\pi$, which selects the input $\mathbf u$ at each time step, that minimizes the integral over time (the sum, in discrete time) of a given cost function $c(\mathbf x,\mathbf u)$.

In our domain the state $\mathbf x$ is denoted $s$, while the control input $\mathbf u$ is denoted $a$. In this chapter we keep the notation of control theory, and we remark that, differently from the previous chapters, state and input are \textbf{continuous} vectors and not elements of a discrete set. In RL we want to maximize the reward, which is equivalent to minimizing a cost function (the cost is the opposite of the reward). In our context, we formalize an optimal control problem as follows\begin{align}
    \min_\pi&\quad c_H(\mathbf x_H)+\sum_{h=0}^{H-1}c_h(\mathbf x_h,\pi_h(\mathbf x_h))\\ 
    \text{where }&\mathbf x_0\sim\mu_0
\end{align}
the state trajectory that is implicit here is\begin{equation}
    (\mathbf x_0,\mathbf u_0,\dots,\mathbf x_h,\underbrace{\mathbf u_h}_{\pi_h(\mathbf x_h)},\dots,\mathbf x_{H-1},\mathbf u_{H-1},\mathbf x_H)
\end{equation}
that is defined by the transition dynamics\begin{equation}
    \mathbf x_{h+1}=f(\mathbf x_h,\mathbf u_h)
\end{equation}
furthermore: \begin{itemize}
    \item $c_h$ is the cost function at the time step $h$, hence we are assuming that the cost might depend not only on the pair state-action, but also on the time.
    \item $c_H$ is the cost function at the final step, it does not depend on the input since the execution ends here.
\end{itemize}
\noindent We take into account that the transition dynamics $f$, the cost function or the policy might be stochastic, so we consider the expected value:
\begin{align}
    \min_\pi&\quad\VA \left[ c_H(\mathbf x_H)+\sum_{h=0}^{H-1}c_h(\mathbf x_h,\pi_h(\mathbf x_h)) \right] \\ 
    \text{where }&\mathbf x_0\sim\mu_0.
\end{align}

\section{Optimal Control as a Finite-Horizon MDP}
In the previous chapter state and action spaces were finite, hence the functions $V_h^*$ and $Q_h^*$ could be stored in a table. A typical control problem is instead the \textbf{cartpole}: a pole is hinged on a cart that can slide along a rail, and we can push the cart left or right. The state collects the linear position and velocity of the cart and the angular position and velocity of the pole:\begin{equation}
    \mathbf x=(\xi,\dot\xi,\theta,\dot\theta)^\top\in\R^4
\end{equation}
where $\xi$ is the position of the cart along the rail and $\theta$ is the angle of the pole with respect to the vertical. The control input is the force applied on the cart, $u\in\R$ (so $k=1$). The goal is to find the control policy which minimizes the long-term cost $c$ (for instance, a cost that is small when the pole is upright and the cart is close to the center of the rail).

An optimal control problem is exactly a finite-horizon MDP: the state is $\mathbf x$, the action is $\mathbf u$, and the reward is $-c$. Since we minimize a cost, the Bellman optimality equation of the finite-horizon MDP is written with a $\min$ instead of a $\max$:\begin{align}
    V_H^*(\mathbf x)&=c_H(\mathbf x)\\
    V_h^*(\mathbf x)&=\min_{\mathbf u}\left\{c_h(\mathbf x,\mathbf u)+\VA_{\mathbf x'\sim p(\cdot\mid\mathbf x,\mathbf u)}\left[V_{h+1}^*(\mathbf x')\right]\right\}\quad h=H-1,\dots,0
\end{align}
where, for deterministic dynamics, the expectation is simply $V_{h+1}^*(f(\mathbf x,\mathbf u))$. A natural question is: can we treat the problem as a finite-horizon MDP and apply the backward dynamic programming (value iteration) of the previous chapter? The issue is that $\mathbf x$ and $\mathbf u$ are continuous.

\paragraph{Approach 1: discretization.} We can discretize both spaces with a grid of resolution $\epsilon$. Assume for simplicity that every coordinate of the state and of the input has been rescaled to the interval $[0,1]$: then the grid contains $(1/\epsilon)^d$ states and $(1/\epsilon)^k$ inputs, so the number of state-input pairs to be handled at each time step is\begin{equation}
    \left(\frac{1}{\epsilon}\right)^d\cdot\left(\frac{1}{\epsilon}\right)^k=\left(\frac{1}{\epsilon}\right)^{d+k}.
\end{equation}
For the cartpole with $\epsilon=0.1$ ($d=4$, $k=1$) we already have $10^5$ pairs per time step, and each additional dimension multiplies this number by $1/\epsilon$. This is known as \textbf{Bellman's curse of dimensionality}: the number of (discrete) states grows exponentially in the dimension $d$ of the state space. In practice, discretization is useful, but it is computationally feasible only up to state spaces of dimension $5$ or $6$.

\paragraph{Approach 2: continuous space.} The alternative is to work directly in the continuous space, starting from simplified problems for which the dynamic programming recursion can be solved analytically: linear dynamics and quadratic cost. This is the Linear Quadratic Regulator, and then we will see how to bring the other problems back to this one.

\section{Linear Quadratic Regulator}
We will show how the problem of finding an optimal policy can be solved with LQR. We will give a general discussion about linear systems with quadratic cost, and then show how it fits the optimal policy search. A discrete-time linear system is defined as follows:\begin{equation}\label{dynamics}
    \mathbf x_{t+1}=F_x\mathbf x_t+F_u\mathbf u_t
\end{equation}
with $F_x$ being a $d\times d$ matrix and $F_u$ a $d\times k$ matrix. The dynamics is linear both in the state and in the control input, this is our transition function. We will consider only \textbf{quadratic} cost functions:\begin{equation}
    c(\mathbf x,\mathbf u)=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u
\end{equation}
with $C_x$ being a positive semidefinite matrix and $C_u$ a positive definite matrix (both symmetric, of size $d\times d$ and $k\times k$ respectively). The cost is a ``bowl'' with its minimum in the origin: if $C_x$ is positive definite, any non-zero state has a strictly positive cost even with an all-zero control input, hence the policy has to drive the state towards the origin, which plays the role of the goal. (If $C_x$ is only semidefinite, some directions of the state are not penalized.)

Let $V^*_h$ be the value function, with $h<H$ the current time step, i.e. the minimum cost that can be obtained from the state $\mathbf x$ at time $h$ onwards (the \textbf{cost-to-go}). We define the state-action value by using the cost instead of the reward:\begin{equation}
    Q_h^*(\mathbf x,\mathbf u)=c(\mathbf x,\mathbf u)+\VA_{\mathbf x'\sim p(\cdot\mid\mathbf x,\mathbf u)}\left[V_{h+1}^*(\mathbf x')\right]=
    c(\mathbf x,\mathbf u)+\sum_{\mathbf x'}V_{h+1}^*(\mathbf x')p(
        \mathbf x'\mid\mathbf x,\mathbf u
    )
\end{equation}
by expanding the cost we get:\begin{equation}
     Q_h^*(\mathbf x,\mathbf u)=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u+\VA_{\mathbf x'\sim p(\cdot\mid\mathbf x,\mathbf u)}\left[V_{h+1}^*(\mathbf x')\right]
\end{equation}
we have the assumption (for now) that the dynamics is deterministic, defined in Equation \eqref{dynamics}, so:\begin{align}
     Q_h^*(\mathbf x,\mathbf u)&=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u+V_{h+1}^*(\blueText{\mathbf x'})\\
    &=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u+V_{h+1}^*(\blueText{F_x\mathbf x+F_u\mathbf u}).
\end{align}
We will show by \textbf{backward induction} on $h$ that the value function is a quadratic form. The base case is $h=H$: the value is the final cost, $V_H^*(\mathbf x)=c_H(\mathbf x)$, which is a quadratic form (or zero). For the inductive step we make the following assumption:\begin{center}
    The value function $V^*_{h+1}$ is a \textbf{quadratic form}.
\end{center}
So, we can write $V_{h+1}^*(\mathbf x)=\mathbf x^\top P_{h+1}\mathbf x$, with $P_{h+1}$ being a symmetric positive semidefinite $d\times d$ matrix, and we want to prove that the same holds for $V_h^*$. We rewrite the action-value function as:
\begin{align}
     Q_h^*(\mathbf x,\mathbf u)&=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u+\blueText{V_{h+1}^*(F_x\mathbf x+F_u\mathbf u)}\\
 &=\mathbf x^\top C_x\mathbf x+
    \mathbf u^\top C_u\mathbf u+\blueText{(F_x\mathbf x+F_u\mathbf u)^\top P_{h+1}(F_x\mathbf x+F_u\mathbf u)}\label{Q_h_star}
\end{align}
we don't know yet how $P_h$ is constructed, we are just assuming that the value at the next step is a quadratic form. Now that we have an analytic formulation of $Q_h^*(\mathbf x,\mathbf u)$, we know that we can express the best policy (at the time step $h$) as:\begin{equation}
    \pi_h^*(\mathbf x)=\operatorname*{arg\,min}_{\mathbf u}Q_h^*(\mathbf x,\mathbf u)
\end{equation}
notice how we are minimizing and not maximizing since we have a cost instead of a reward (but the two formulations are equivalent). Since $C_u+F_u^\top P_{h+1}F_u$ is positive definite, $Q_h^*(\mathbf x,\cdot)$ is strictly convex in $\mathbf u$, hence to find its minimum we can set the gradient to zero:\begin{equation}\label{grad}
    \nabla_u Q_h^*(\mathbf x,\mathbf u)=\mathbf 0.
\end{equation}
The gradient is:
\begin{equation}
     \nabla_u Q_h^*(\mathbf x,\mathbf u)=
     2C_u\mathbf u+2F_u^\top P_{h+1}(F_x\mathbf x+F_u\mathbf u)
\end{equation}
now we solve Equation \eqref{grad} for $\mathbf u$:
\begin{align}
    & 2C_u\mathbf u+2F_u^\top P_{h+1}(F_x\mathbf x+F_u\mathbf u)=\mathbf 0 \\ 
     \implies&\mathbf u = -(C_u+F_u^\top P_{h+1}F_u)^{-1}F_u^\top P_{h+1}F_x\mathbf x=K_h^* \mathbf x
\end{align}
we have denoted $K_h^* $ that $k\times d$ matrix, in this way we have found the optimal policy at time $h$:\begin{equation}
    \pi_h^*(\mathbf x)=K_h^* \mathbf x
\end{equation}
Now we can replace $\mathbf u =K_h^* \mathbf x $ in Equation \eqref{Q_h_star}, by definition, this is exactly the value function:\begin{align} Q_h^*(\mathbf x,\pi_h^*(\mathbf x))=V^*_h(\mathbf x)=&\,
    \mathbf x^\top C_x\mathbf x+
    (K_h^* \mathbf x)^\top C_u(K_h^* \mathbf x)+\blueText{(F_x\mathbf x+F_uK_h^* \mathbf x)^\top P_{h+1}(F_x\mathbf x+F_uK_h^* \mathbf x)}\\
&=\mathbf x^\top(
    C_x+(K_h^*)^\top C_u K_h^* + 
    (F_x+F_uK_h^*)^\top  P_{h+1} (F_x+F_uK_h^*)
)\mathbf x\\ &=\mathbf x^\top P_h\mathbf x
\end{align}
and is exactly a quadratic form ($\mathbf x^\top P_h\mathbf x$), so the assumption made at the beginning was correct and the inductive step is complete. Notice how $P_h$ can be computed when $P_{h+1}$ is known: due to the finite horizon, we are able to compute in closed form the cost at the final step, hence $P_H$ can be initialized according to the final cost $c_H$ (for instance $P_H=C_x$ if $c_H(\mathbf x)=\mathbf x^\top C_x\mathbf x$, or $P_H=\mathcal O$ if there is no final cost), then we can reconstruct $P_h$ for all $h$ backwards.
\begin{algorithm}[H]
\caption{Value Iteration as LQR}\label{alg:value_iteration_LQR}
\begin{algorithmic}[1]
    \State initialize $P_H$
    \For{$h=H-1,H-2,\dots, 0$ (backwards)}
    \State Set $K_h^*=-(C_u+F_u^\top P_{h+1}F_u)^{-1}F_u^\top P_{h+1}F_x$
    \State Compute the best action $\mathbf u=\pi_h^*(\mathbf x)=K_h^*\mathbf x$
    \State Set $P_h=C_x+(K_h^*)^\top C_u K_h^* + 
    (F_x+F_uK_h^*)^\top  P_{h+1} (F_x+F_uK_h^*)$
    \State Compute the value $V_h^*(\mathbf x)=\mathbf x^\top P_h\mathbf x$
    \EndFor
\end{algorithmic}
\end{algorithm}
Notice how the best action at a given state is a term proportional to that state, in fact this is a \textit{proportional regulator}. Here $V_h^*(\mathbf x)=\mathbf x^\top P_h\mathbf x$ is known as the \textbf{cost-to-go}.
\begin{boxobservation}
    The update of $P_h$ in Algorithm \ref{alg:value_iteration_LQR} is the discrete-time \textbf{Riccati equation}. By substituting $K_h^*$ and expanding, it can be equivalently written as\begin{equation}
        P_h=C_x+F_x^\top P_{h+1}F_x-F_x^\top P_{h+1}F_u\left(C_u+F_u^\top P_{h+1}F_u\right)^{-1}F_u^\top P_{h+1}F_x.
    \end{equation}
    Algorithm \ref{alg:value_iteration_LQR} is exactly the backward value iteration of the finite-horizon MDP, performed \textbf{in closed form}: it is always the same update, it requires no discretization of the state space, and it solves exactly this particular continuous-state system with quadratic cost. The matrices $K_h^*$ and $P_h$ do not depend on the state, so they can be computed once offline; the policy is then executed online with a single matrix-vector product.
\end{boxobservation}

\subsection{Extensions}
The first assumption that we drop is that the system is time invariant: consider dynamics that depend also on the time $t$:\begin{equation}
     \mathbf x_{t+1}=F_{x,t}\mathbf x_t+F_{u,t}\mathbf u_t
\end{equation}
with a cost that also depends on $t$:\begin{equation}
    c_t(\mathbf x_t,\mathbf u_t)=\mathbf x_t^\top C_{x,t}\mathbf x_t+
    \mathbf u_t^\top C_{u,t}\mathbf u_t.
\end{equation}
This is a \textbf{linear time-varying} (LTV) system. Algorithm \ref{alg:value_iteration_LQR} can be performed in the same way; the matrices simply depend on the time. Explicitly, after initializing $P_H$, for $h=H-1,\dots,0$:\begin{align}
    K_h^*&=-(C_{u,h}+F_{u,h}^\top P_{h+1}F_{u,h})^{-1}F_{u,h}^\top P_{h+1}F_{x,h}\\
    P_h&=C_{x,h}+(K_h^*)^\top C_{u,h}K_h^*+(F_{x,h}+F_{u,h}K_h^*)^\top P_{h+1}(F_{x,h}+F_{u,h}K_h^*)
\end{align}
and the optimal policy is $\pi_h^*(\mathbf x)=K_h^*\mathbf x$, with $V_h^*(\mathbf x)=\mathbf x^\top P_h\mathbf x$.\bigskip

\noindent Let us switch back to time invariant systems, and consider a system that is not linear but \textit{affine}:\begin{equation}
    \mathbf x_{t+1}=F_x\mathbf x_t+F_u\mathbf u_t +\mathbf c
\end{equation}
with $\mathbf c\in\R^d$ being a constant vector. We can still apply Algorithm \ref{alg:value_iteration_LQR} by transforming the system into a linear system through the change of coordinates $\mathbf z = \begin{pmatrix}
        \mathbf x^\top & 1 
    \end{pmatrix}^\top$:
\begin{align}
    \mathbf z_{t+1} = \begin{pmatrix}
        \mathbf x_{t+1} \\ 1 
    \end{pmatrix}&=\begin{pmatrix}
        F_x&\mathbf c\\ 
        \mathbf 0^\top & 1
    \end{pmatrix}\begin{pmatrix}
        \mathbf x_t \\ 1 
    \end{pmatrix}+\begin{pmatrix}
        F_u \\ \mathbf 0^\top
    \end{pmatrix}\mathbf u_t \\[1.5ex]  &= F_x'\mathbf z_t+F_u'\mathbf u_t.
\end{align}
The cost is still quadratic in the new coordinates, since $\mathbf x^\top C_x\mathbf x=\mathbf z^\top\begin{pmatrix}
        C_x&\mathcal O\\ 
        \mathcal O & 0
    \end{pmatrix}\mathbf z$ (the new cost matrix is only positive semidefinite, which is allowed). The last coordinate is constantly equal to $1$, hence it is not affected by the control.

\noindent Now we take into account \textit{stochastic systems}; in particular, we consider noisy dynamics that are perturbed by a zero-mean Gaussian noise:\begin{align}
    &\mathbf x_{t+1}=F_x\mathbf x_t+F_u\mathbf u_t +\mathbf w_t\\ 
    &\mathbf w_t\sim \mathcal N(\mathbf 0,\sigma^2 I)
\end{align}
where $I$ is the $d\times d$ identity matrix, $\sigma^2>0$ is the variance of the noise, and $\mathbf w_t$ is independent of the state, of the input and of the noise at the other time steps. Assume $V_{h+1}^*(\mathbf x)=\mathbf x^\top P_{h+1}\mathbf x+p_{h+1}$ with $p_{h+1}$ a scalar; then the expectation in the Bellman equation becomes (the cross term vanishes since $\VA[\mathbf w_t]=\mathbf 0$, and $\VA[\mathbf w_t^\top P_{h+1}\mathbf w_t]=\text{tr}(P_{h+1}\VA[\mathbf w_t\mathbf w_t^\top])=\sigma^2\text{tr}(P_{h+1})$):\begin{align}
    \VA_{\mathbf w_t}\left[V_{h+1}^*(F_x\mathbf x+F_u\mathbf u+\mathbf w_t)\right]=(F_x\mathbf x+F_u\mathbf u)^\top P_{h+1}(F_x\mathbf x+F_u\mathbf u)+\sigma^2\,\text{tr}(P_{h+1})+p_{h+1}.
\end{align}
The additional term does not depend on $\mathbf u$, so the minimization over $\mathbf u$ is unchanged: the optimal policy is the same as in the deterministic case, but the cost-to-go has an additional term that depends on the variance of
the noise and that cannot be controlled: \begin{equation}
    V_h^*(\mathbf x)=\mathbf x^\top P_h\mathbf x+p_h 
\end{equation}
where \begin{align}
    &p_h=\text{tr}\left(\sigma^2P_{h+1}\right)+p_{h+1}\\
    &p_{H}=0.
\end{align}
There is also a formulation that is more suitable for some cases, where we apply a coordinate and input transformation in order to have a cost function that describes the cost of a certain control input and also the cost of \textit{changing} that control input. Starting from a standard system:\begin{equation}
    \mathbf x_{t+1}=F_x\mathbf x_t+F_u\mathbf u_t,
\end{equation}
we consider the following equivalent system:\begin{equation}
    \begin{pmatrix}
    \mathbf{x}_{t+1} \\
    \mathbf{u}_t
\end{pmatrix}
=
\begin{pmatrix}
    F_x & F_u \\
    \mathcal O   & I
\end{pmatrix}
\begin{pmatrix}
    \mathbf{x}_t \\
    \mathbf{u}_{t-1}
\end{pmatrix}
+
\begin{pmatrix}
    F_u \\
    I
\end{pmatrix}
\Delta\mathbf{u}_t
\end{equation}
where $\mathcal O$ is the zero matrix and $\Delta\mathbf u_t=\mathbf u_t-\mathbf u_{t-1}$. The system is equivalent because, writing $\mathbf u_t=\mathbf u_{t-1}+\Delta\mathbf u_t$, we have $\mathbf x_{t+1}=F_x\mathbf x_t+F_u\mathbf u_{t-1}+F_u\Delta\mathbf u_t$. The new state is $\mathbf x_t'=(\mathbf x_t^\top,\mathbf u_{t-1}^\top)^\top$ (the state together with the previous input).
We rewrite the system as\begin{equation}
    \mathbf x_{t+1}'=F_x'\mathbf x_t'+F_u'\Delta\mathbf u_t.
\end{equation}
$\Delta\mathbf{u}_t$ is the new input, and is the change in controls. The new cost is\begin{equation}
    (\mathbf x')^\top \begin{pmatrix}
        C_x& \mathcal O \\ 
        \mathcal O & C_u
    \end{pmatrix}\mathbf x'+\Delta\mathbf u^\top C'_u\Delta\mathbf u,
\end{equation}
where the first term penalizes the state and the magnitude of the input, and $C'_u$ is the (positive definite) matrix that penalizes the change in controls. If $C_u'=\mathcal O$ the change in controls is not penalized and the cost reduces to the standard one (the problem is then equivalent to the standard LQR, provided that the matrix inverted in the recursion remains invertible).

\section{LQR for Non-Linear Systems}
Now we consider a general non-linear system with the dynamics expressed through a non-linear function $f$:\begin{equation}
    \mathbf x_{t+1}=f(\mathbf x_t,\mathbf u_t).
\end{equation}
Let $\mathbf x^*$ be a forced equilibrium:\begin{equation}
    f(\mathbf x^*,\mathbf u^*)=\mathbf x^*
\end{equation}
with $\mathbf u^*$ being the required input: this is the goal, and we want to stabilize the system around it. For instance, in the cartpole the configuration with the pole upright, the cart at rest and zero applied force ($\mathbf u^*=0$) is an equilibrium (an unstable one, so feedback is needed to keep the system there). We linearize the system around that equilibrium using a first order Taylor expansion:\begin{equation}
    \mathbf x_{t+1}\approx f(\mathbf x^*,\mathbf u^*)+\nabla_x f(\mathbf x^*,\mathbf u^*)(\mathbf x_t-\mathbf x^* )+\nabla_u f(\mathbf x^*,\mathbf u^*)(\mathbf u_t-\mathbf u^* )
\end{equation}
with $\nabla_x f(\mathbf x^*,\mathbf u^*)\in\R^{d\times d}$ and $\nabla_u f(\mathbf x^*,\mathbf u^*)\in\R^{d\times k}$ being the Jacobian matrices (with respect to $\mathbf x$ and $\mathbf u$, i.e. the entries are the partial derivatives $\partial f_i/\partial x_j$ and $\partial f_i/\partial u_j$ of the components of $f$) evaluated at the equilibrium. We denote by $A$ and $B$ the Jacobian matrices, by $\mathbf z_t=\mathbf x_t-\mathbf x^*$ the variation in the state with respect to the equilibrium and by $\mathbf v_t=\mathbf u_t-\mathbf u^*$ the variation in the input:
\begin{align}
    &\mathbf x_{t+1}\approx \underbrace {f(\mathbf x^*,\mathbf u^*)}_{\mathbf x^*}+A(\mathbf x_t-\mathbf x^* )+B(\mathbf u_t-\mathbf u^* )\implies \\ 
    &\mathbf x_{t+1}-\mathbf x^*\approx 
    A(\mathbf x_t-\mathbf x^* )+B(\mathbf u_t-\mathbf u^* )\implies \\
    &\mathbf z_{t+1}\approx A\mathbf z_t+B\mathbf v_t.
\end{align}
We have a linear system; clearly, to reach the equilibrium we should bring the new state $\mathbf z$ to zero. We assume that the cost penalizes the deviations from the equilibrium, $\mathbf z_t^\top C_x\mathbf z_t+\mathbf v_t^\top C_u\mathbf v_t$ (when $\mathbf x^*=\mathbf 0$ and $\mathbf u^*=\mathbf 0$ this is the usual quadratic cost). 
The usual way to define the control action is with a proportional controller:\begin{equation}
    \mathbf v_t=K\mathbf z_t\implies \mathbf u_t=\mathbf u^*+K(\mathbf x_t-\mathbf x^*)
\end{equation}
where $K$ is computed with Algorithm \ref{alg:value_iteration_LQR} applied to the pair $(A,B)$. If the cost is not quadratic, it can be approximated with a quadratic function through a second order Taylor expansion, as shown below.

\subsection{Quadratic Approximation of the Cost}
Let $g(\mathbf x,\mathbf u)$ be a general (twice differentiable) cost. We expand it with a second order Taylor expansion around $(\mathbf x^*,\mathbf u^*)$, in terms of the deviations $\mathbf z=\mathbf x-\mathbf x^*$ and $\mathbf v=\mathbf u-\mathbf u^*$ (all the derivatives are evaluated at $(\mathbf x^*,\mathbf u^*)$):\begin{align}
    g(\mathbf x^*+\mathbf z,\mathbf u^*+\mathbf v)\approx\;& g(\mathbf x^*,\mathbf u^*)+(\nabla_x g)^\top\mathbf z+(\nabla_u g)^\top\mathbf v\nonumber\\
    &+\tfrac12\mathbf z^\top\nabla_{xx}^2 g\,\mathbf z+\tfrac12\mathbf v^\top\nabla_{uu}^2 g\,\mathbf v+\mathbf v^\top\nabla_{ux}^2 g\,\mathbf z
\end{align}
where $\nabla_{xx}^2g\in\R^{d\times d}$ and $\nabla_{uu}^2g\in\R^{k\times k}$ are the Hessians, and $\nabla_{ux}^2g\in\R^{k\times d}$ is the matrix of the mixed second derivatives ($\nabla_{xu}^2g=(\nabla_{ux}^2g)^\top$). Hence the cost becomes something like:\begin{equation}\label{LQ_cost}
    \mathbf z^\top C_x\mathbf z+\mathbf v^\top C_u\mathbf v+\mathbf v^\top M\mathbf z+\mathbf z^\top\mathbf q+\mathbf v^\top\mathbf r+g_0
\end{equation}
with $C_x=\frac12\nabla^2_{xx}g$, $C_u=\frac12\nabla^2_{uu}g$, $M=\nabla^2_{ux}g$, $\mathbf q=\nabla_xg$, $\mathbf r=\nabla_ug$ and $g_0=g(\mathbf x^*,\mathbf u^*)$. This is not exactly the LQR cost, because of the cross term $\mathbf v^\top M\mathbf z$, the linear terms and the constant. We handle them in two steps.\begin{itemize}
    \item \textbf{Linear terms and constant}: as in the affine case, we append a constant $1$ to the state, $\mathbf z'=(\mathbf z^\top,1)^\top$; then $\mathbf z^\top\mathbf q$ and $g_0$ become part of a quadratic form in $\mathbf z'$, while $\mathbf v^\top\mathbf r$ becomes a cross term between $\mathbf z'$ and $\mathbf v$ (the explicit matrices are given in Section \ref{sec:iLQR}).
    \item \textbf{Cross term}: we write it as $\mathbf v^\top M\mathbf z=2\mathbf z^\top N\mathbf v$ with $N=\frac12M^\top$, and we use the LQR recursion for the cost $\mathbf z^\top C_x\mathbf z+\mathbf v^\top C_u\mathbf v+2\mathbf z^\top N\mathbf v$. The derivation is identical to the previous one: setting to zero the gradient with respect to $\mathbf v$ of $\mathbf z^\top C_x\mathbf z+\mathbf v^\top C_u\mathbf v+2\mathbf z^\top N\mathbf v+(A\mathbf z+B\mathbf v)^\top P_{h+1}(A\mathbf z+B\mathbf v)$ gives $\mathbf v=K_h\mathbf z$ with\begin{align}
        K_h&=-W_h^{-1}\left(B^\top P_{h+1}A+N^\top\right), \quad W_h=C_u+B^\top P_{h+1}B\\
        P_h&=C_x+A^\top P_{h+1}A-\left(A^\top P_{h+1}B+N\right)W_h^{-1}\left(B^\top P_{h+1}A+N^\top\right)
    \end{align}
    which reduces to Algorithm \ref{alg:value_iteration_LQR} when $N=\mathcal O$. For time-varying systems all the matrices carry the index $h$.
\end{itemize}

\subsection{Trajectory Tracking}
Now we want to define a controller that performs trajectory tracking while minimizing the cost function (for instance, a mobile robot controlled with linear velocity and angular velocity that has to follow a reference trajectory in the plane). The desired trajectory is \begin{equation}
    \mathbf x_0^*,\mathbf x_1^*,\dots, \mathbf x_H^*.
\end{equation}
Each single transition of the trajectory is a forced equilibrium\begin{equation}
    f( \mathbf x_t^*,\mathbf u_t^*)= \mathbf x_{t+1}^*
\end{equation}
(we assume that the reference trajectory is feasible, i.e. that the inputs $\mathbf u_t^*$ realizing it exist and are known). In other words, we are trying to find a control input for each time step\begin{equation}
    \mathbf u_0,\mathbf u_1,\dots,\mathbf u_{H-1}
\end{equation}
that minimizes the overall cost:\begin{align}
    &\operatorname*{\min}_{ \mathbf u_0,\mathbf u_1,\dots,\mathbf u_{H-1}}\quad\sum_{t=0}^{H-1}(\mathbf x_t-\mathbf x_t^*)^\top C_x (\mathbf x_t-\mathbf x_t^*)+(\mathbf u_t-\mathbf u_t^*)^\top C_u (\mathbf u_t-\mathbf u_t^*)\\ 
    &\text{s.t.}\quad \mathbf x_{t+1}=f(\mathbf x_t,\mathbf u_t).
\end{align}
The solution is simple: at each time step we linearize the system around the desired trajectory, i.e. around $(\mathbf x_t^*,\mathbf u_t^*)$ (the linearization point changes with $t$), with $A_t=\nabla_xf(\mathbf x_t^*,\mathbf u_t^*)$ and $B_t=\nabla_uf(\mathbf x_t^*,\mathbf u_t^*)$, and we treat it as a linear time-varying system:\begin{align}
    &\mathbf x_{t+1}-\mathbf x_{t+1}^*\approx A_t(\mathbf x_t-\mathbf x_t^*)+ B_t(\mathbf u_t-\mathbf u_t^*)\\
    &\mathbf u_t-\mathbf u_t^*=K_t(\mathbf x_t-\mathbf x_t^*)
\end{align}
where the gains $K_t$ are computed with the LQR recursion for LTV systems ($A_t$ and $B_t$ play the role of $F_{x,t}$ and $F_{u,t}$).

\section{Iterative LQR}\label{sec:iLQR}
Now we try to solve the most general case of a discrete-time optimal control problem:\begin{align}
    &\operatorname*{\min}_{ \mathbf u_0,\dots,\mathbf u_{H-1}}\quad g_H(\mathbf x_H)+\sum_{h=0}^{H-1}g_h(\mathbf x_h,\mathbf u_h)\\ 
    &\text{s.t.}\quad \mathbf x_{h+1}=f(\mathbf x_h,\mathbf u_h)
\end{align}
by iteratively approximating it with an LQ problem (linear dynamics, quadratic cost) and leveraging the LQR formulation. A problem of this kind can be solved with Algorithm \ref{alg:iLQR}: the initialization is either a control policy $\pi^{(0)}$, or directly a sequence of states and inputs $\{\mathbf x_t^{(0)},\mathbf u_t^{(0)}\}$, in which case the execution step is skipped in the first iteration.

\begin{algorithm}[H]
\caption{Iterative  LQR}\label{alg:iLQR}
\begin{algorithmic}[1]
    \State Initialize a control policy $\pi^{(0)}$ (or a state-input sequence $\{\mathbf x_t^{(0)},\mathbf u_t^{(0)}\}$).
    \For{$i=0,1,\dots, I$}
    \State Execute $\pi^{(i)}$ and collect the state-input trajectory $\{\mathbf x_t^{(i)},\mathbf u_t^{(i)}\}$ for $t=0,\dots, H$.
    \State Obtain an LQ approximation of this problem by linearizing around $\{\mathbf x_t^{(i)},\mathbf u_t^{(i)}\}$ with first order Taylor expansion for the dynamics and second order Taylor expansion for the cost.
    \State Compute $\pi^{(i+1)}$ with the LQR formulation for linear time variant systems.
    \EndFor
\end{algorithmic}
\end{algorithm}

\subsection{The LQ Approximation}
Let us detail steps 4 and 5 at iteration $i$. Define the deviation variables\begin{equation}
    \mathbf z_t=\begin{pmatrix}\mathbf x_t-\mathbf x_t^{(i)}\\ 1\end{pmatrix}\in\R^{d+1},\qquad \mathbf v_t=\mathbf u_t-\mathbf u_t^{(i)}\in\R^k
\end{equation}
(the constant $1$ is appended as in the affine case). The first order Taylor expansion of the dynamics gives\begin{equation}
    \mathbf x_{t+1}-\mathbf x_{t+1}^{(i)}\approx f(\mathbf x_t^{(i)},\mathbf u_t^{(i)})-\mathbf x_{t+1}^{(i)}+\nabla_xf(\mathbf x_t^{(i)},\mathbf u_t^{(i)})(\mathbf x_t-\mathbf x_t^{(i)})+\nabla_uf(\mathbf x_t^{(i)},\mathbf u_t^{(i)})(\mathbf u_t-\mathbf u_t^{(i)})
\end{equation}
which is an LTV system $\mathbf z_{t+1}=F_{x,t}\mathbf z_t+F_{u,t}\mathbf v_t$ with\begin{equation}
    F_{x,t}=\begin{pmatrix}
        \nabla_xf(\mathbf x_t^{(i)},\mathbf u_t^{(i)}) & f(\mathbf x_t^{(i)},\mathbf u_t^{(i)})-\mathbf x_{t+1}^{(i)}\\
        \mathbf 0^\top & 1
    \end{pmatrix},\qquad 
    F_{u,t}=\begin{pmatrix}
        \nabla_uf(\mathbf x_t^{(i)},\mathbf u_t^{(i)})\\ \mathbf 0^\top
    \end{pmatrix}.
\end{equation}
The vector $f(\mathbf x_t^{(i)},\mathbf u_t^{(i)})-\mathbf x_{t+1}^{(i)}$ is the \textit{defect} of the reference sequence: it is zero if the trajectory has been generated by executing the dynamics (as in step 3 of the algorithm), while it may be non-zero if the algorithm is initialized with an arbitrary sequence of states and inputs.

For the cost, let $g_t=g_t(\mathbf x_t^{(i)},\mathbf u_t^{(i)})$ and let all the derivatives be evaluated at $(\mathbf x_t^{(i)},\mathbf u_t^{(i)})$. The expansion of Equation \eqref{LQ_cost} can be written as $\mathbf z_t^\top C_{x,t}\mathbf z_t+\mathbf v_t^\top C_{u,t}\mathbf v_t+2\mathbf z_t^\top N_t\mathbf v_t$ with\begin{equation}
    C_{x,t}=\begin{pmatrix}
        \frac12\nabla_{xx}^2g_t & \frac12\nabla_xg_t\\[0.5ex]
        \frac12(\nabla_xg_t)^\top & g_t
    \end{pmatrix},\qquad 
    C_{u,t}=\tfrac12\nabla_{uu}^2g_t,\qquad 
    N_t=\begin{pmatrix}
        \frac12\nabla_{xu}^2g_t\\[0.5ex]
        \frac12(\nabla_ug_t)^\top
    \end{pmatrix}.
\end{equation}
Indeed, expanding the quadratic form with $\mathbf z_t=(\mathbf x_t-\mathbf x_t^{(i)},1)$ gives exactly the constant, linear, and quadratic terms of the Taylor expansion. When the cost is separable, $g(\mathbf x,\mathbf u)=g(\mathbf x)+g(\mathbf u)$, the mixed term is zero ($\nabla^2_{xu}g_t=\mathcal O$) and the first block of $N_t$ vanishes. At the final step, $P_H=C_{x,H}$ is built in the same way from $g_H(\mathbf x_H)$.

Applying the LQR recursion with cross term (previous section) to this LTV system we obtain gains $K_t\in\R^{k\times(d+1)}$. Splitting $K_t=\begin{pmatrix}K_t^{x}&\mathbf k_t\end{pmatrix}$, with $K_t^{x}\in\R^{k\times d}$ and $\mathbf k_t\in\R^k$ the last column, the new policy is the time-varying affine feedback\begin{equation}
    \pi^{(i+1)}_t(\mathbf x)=\mathbf u_t^{(i)}+K_t^{x}(\mathbf x-\mathbf x_t^{(i)})+\mathbf k_t
\end{equation}
where $\mathbf k_t$ is a feedforward correction.

\subsection{Convergence}
As it is, the algorithm might not converge, because the optimal policy for the LQ approximation might end up not staying close to the linearization points, where the approximation is not valid anymore. A solution is to modify the cost at iteration $i$ as\begin{equation}
    (1-\alpha)g(\mathbf x_t,\mathbf u_t)+\alpha\left(\|\mathbf x_t-\mathbf x_t^{(i)}\|_2^2+\|\mathbf u_t-\mathbf u_t^{(i)}\|_2^2\right)
\end{equation}
with $\alpha\in(0,1)$. The second term penalizes the deviation from the linearization points: if $g$ is bounded and $\alpha$ is close enough to $1$, the second term dominates and ensures that the linearizations are good approximations of the solution trajectory. In terms of the LQ approximation, this simply multiplies the derivatives of $g$ by $(1-\alpha)$ and adds $\alpha I$ to $C_{x,t}$ (on the block of the state deviation) and to $C_{u,t}$. The price to pay is a smaller progress at each iteration.

\subsection{Practical Tricks}
\begin{itemize}
    \item \textbf{Initialization}: a good initialization matters, since the algorithm only finds a local optimum of a non-convex problem and can get stuck. Alternative solutions are to use simulated annealing (a stochastic global search that sometimes accepts worse solutions to escape local optima, usable only if there are no computational constraints) or a line-search on the update (e.g. accept the new trajectory only if the true cost decreases, otherwise take a smaller step).
    \item \textbf{Non-convex cost}: if $g$ is non-convex, the quadratic approximation might lead to matrices $C_{x,t}$ and $C_{u,t}$ that are not positive (semi)definite, and the LQR recursion is no longer well defined (the minimization over $\mathbf v$ may be unbounded or the matrix $W_t$ may not be invertible). The solution is to add more cost for deviating from the linearization points (e.g. increasing $\alpha$ as above) until they become positive (semi)definite.
\end{itemize}

\section{Model Predictive Control}
At iLQR convergence, the system could execute the policy and not be at the expected trajectory, for instance due to inaccurate dynamics, noise, etc. The idea is to \textbf{replan}: at every time step $t$, starting from the state $\mathbf x_t$ that is actually measured, we solve again the problem from $t$ to $H$ and we apply the first input. This is called \textbf{receding horizon control}, or \textbf{Model Predictive Control} (MPC).

Replanning until $H$ at every time step is typically too costly. The practical solution is to replan over a shorter horizon of $L$ steps (with $L\le H-t$), and to account for what happens after the end of the window with a terminal cost $\hat V_{t+L}$, which is an approximation of the cost-to-go from the state $\mathbf x_{t+L}$ (for instance the quadratic form $\mathbf x^\top P\mathbf x$ obtained from an LQR on the linearized system). At time $t$ we solve\begin{align}
    &\operatorname*{\min}_{ \mathbf u_t,\dots,\mathbf u_{t+L-1}}\quad \sum_{h=t}^{t+L-1}g_h(\mathbf x_h,\mathbf u_h)+\hat V_{t+L}(\mathbf x_{t+L})\\ 
    &\text{s.t.}\quad \mathbf x_{h+1}=f(\mathbf x_h,\mathbf u_h),\quad \mathbf x_t\text{ given by the measurement}
\end{align}
with $\hat V_H=g_H$ when the window reaches the end of the horizon. Only the first input $\mathbf u_t$ of the solution is applied; at the next step the window moves forward by one step (hence ``receding'') and the problem is solved again with the new measured state. Since the optimization restarts from the measured state, errors due to model mismatch and disturbances are corrected at every step.
\begin{algorithm}[H]
\caption{Model Predictive Control with an iLQR solver}\label{alg:MPC}
\begin{algorithmic}[1]
    \State Choose the prediction horizon $L$ and the terminal cost $\hat V$.
    \For{$t=0,1,\dots, H-1$}
    \State Measure the current state $\mathbf x_t$.
    \State Set $L_t=\min(L,H-t)$.
    \State Solve the problem above with iLQR (possibly warm-started with the previous solution shifted by one step), obtaining $\hat{\mathbf u}_t,\dots,\hat{\mathbf u}_{t+L_t-1}$.
    \State Apply to the system only the first input $\mathbf u_t=\hat{\mathbf u}_t$.
    \EndFor
\end{algorithmic}
\end{algorithm}
\noindent This is in practice a Model Predictive Controller with an iLQR solver.
\chapter{Approximate Policy Iteration}
From now on we will discuss real reinforcement learning problems, where the transition function is unknown and the state space is too large to be enumerated; the previous chapters were more about planning rather than reinforcement learning. We recall the \textbf{policy iteration} procedure, that at each iteration provides a policy $\pi_t$:\begin{enumerate}
    \item Start with a random guess $\pi_0$.
    \item For $t=0,\dots, T$:\begin{enumerate}
        \item Perform policy evaluation and compute $Q^{\pi_t}$ for all the state-action pairs $(s,a)$.
        \item Perform policy improvement: $\displaystyle\pi_{t+1}(s)=\operatorname*{arg\,max}_{a\in A}Q^{\pi_t}(s,a)$ for all $s\in S$.
    \end{enumerate}
\end{enumerate}
If the state space is large (or uncountable), this algorithm becomes infeasible: we can't iterate over all the states, hence we can't perform policy evaluation. We have to \textit{approximate} $Q^\pi$. The policy improvement step is still feasible since we only have to iterate over the actions, which we assume to be countable (we can still enumerate them or at least discretize them). The policy evaluation instead relies on the following relation:\begin{equation}
    Q^\pi(s,a)=r(s,a)+\gamma\VA_{s'\sim p(\cdot\mid s,a)}[V^\pi(s')]=
    r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)V^\pi(s')
\end{equation}
instead of doing so we will use an \textit{approximation} denoted $\hat Q^\pi$:\begin{equation}
    \hat Q^\pi(s,a)=r(s,a)+\gamma\VA_{s'\sim p(\cdot\mid s,a)}[\hat V^\pi(s')]
\end{equation}
that uses an approximation of the value function $\hat V^\pi$. Our goal is to \textbf{build an approximation} $\hat V^\pi$ sufficiently close to the real value function, in order to obtain a policy that is close to the optimal one. We use a function approximator, such as linear approximators, neural networks and others. Instead of approximating $V$ we will approximate directly $Q$; by doing so, we won't need to know the transition probabilities, hence it will not be required to know exactly the MDP.
\begin{boxobservation}{The MDP is Unknown}{}
    In real scenarios, the transition probabilities are unknown, hence from now on \textbf{we will drop the assumption of knowing the MDP}. Real reinforcement learning starts here.
\end{boxobservation}
\section{Supervised Learning}
In order to approximate $Q$ we need a dataset:\begin{equation}
    \mathcal D = \{(s_i,a_i,y_i)\}_{i=1}^N
\end{equation}
with $s_i,a_i$ being the inputs of $Q$ and $y_i$ the labels (the values of the action value function). We assume the rewards to be in $[0,1]$, hence the action value function takes values in $\left[0,\nicefrac{1}{1-\gamma}\right]$. We are interested in the family of functions that maps $S\times A$ to $\left[0,\nicefrac{1}{1-\gamma}\right]\subset\R$, we denote the set of these functions $\mathcal Q$:\begin{equation}
    \mathcal Q = \{f \ : \ f:S\times A\to \left[0,\nicefrac{1}{1-\gamma}\right]\}.
\end{equation}
One way to find such a function is through \textbf{Least Squares Regression} over the dataset: we have to solve the following minimization problem:\begin{equation}
    \hat Q=\operatorname*{arg\,min}_{Q\in \mathcal Q}\sum_{i=1}^{N}(Q(s_i,a_i)-y_i)^2.
\end{equation}
This problem is numerically tractable and has generalization bounds. Let's see what a general regression problem for supervised learning is.\begin{boxdefinition}{Empirical Risk Minimizer}{}
    Given a data distribution $D$ from which we sample $N$ points and labels $(x_i,y_i)$ with $y_i=f(x_i)+\epsilon_i$, where $\epsilon_i$ is a bounded noise sampled from a zero-mean distribution, we want to approximate $f$ using a finite set of data as follows:\begin{align}
         &\operatorname*{arg\,min}_{\hat f\in \mathcal F}\sum_{i=1}^{N}(\hat f(x_i)-y_i)^2\\
         &\mathcal F\subseteq\{\hat f \ : \ \hat f :X\rightarrow \R\}
    \end{align}
    where $\mathcal F$ is the chosen class of approximators.
\end{boxdefinition}
The points of the dataset $x_i$ are sampled from a distribution $D$, the resulting solution $\hat f$ of the minimization problem will satisfy (with high probability) the following inequality:\begin{equation}
    \VA_{x\sim D}\left[(\hat f(x)-f(x))^2\right]\le \delta
\end{equation}
with $\delta$ being a small number. The expected value is bounded if the points $x$ on which we are testing our approximator are sampled from the same distribution $D$ that we used to create the dataset. If we use a different distribution $D'\ne D$ the expected value \begin{equation}
    \VA_{x\sim D'}\left[(\hat f(x)-f(x))^2\right]
\end{equation}
might be much larger than $\delta$, since the approximator is constructed on a different set of points, hence it didn't ``learn'' appropriately how to behave on the other distribution.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.6\textwidth]{images/distribution_change.eps} 
    \caption{Approximator trained on a subset of $X$.}
    \label{distribution_change}
\end{figure}

\noindent Observe the example in Figure \ref{distribution_change}: the approximator (green line) is close to the real function (dotted line) over the set colored in green, that is the set where we sampled the points to build the approximator; on other areas of $X$, like the red area, the approximator provides values far from the real function.

In the context of \emph{Approximate Policy Iteration} (API), the function approximator is trained by minimizing the empirical error solely over the state-action distribution induced by the current policy, $d^{\pi_t}$ (formally defined in the next subsection). In unexplored regions of the state space, the generalization error can become arbitrarily large; consequently, the \emph{policy improvement} step may select greedy actions guided by unreliable, overestimated values. The resulting updated policy $\pi_{t+1}$ shifts the sampling trajectories toward these unfamiliar regions, degrading performance over the previous distribution and triggering a destructive cycle of \emph{policy oscillation} that undermines monotonic convergence. To theoretically mitigate this distribution shift, standard analysis introduces the \emph{Strong Coverage Assumption}, which asserts the existence of a finite concentrability coefficient, i.e. a distribution $\rho$ over $S\times A$ and a constant $C<\infty$ such that $d^\pi(s,a)\le C\rho(s,a)$ for all the pairs $(s,a)$ and every policy $\pi$ that the algorithm might produce.
\section{Data Generation}
To perform an approximate policy iteration, first we need our dataset $\mathcal D = \{(s_i,a_i,y_i)\}_{i=1}^N$; the generation is divided into two steps, \textbf{roll-in} and \textbf{roll-out}:
\begin{itemize}
    \item \textbf{Roll-In}: The procedure of sampling the state-action pairs $(s_i,a_i)$.
    \item \textbf{Roll-Out}: The procedure of assigning a target value $y_i$ to the previously sampled state-action pairs $(s_i,a_i)$.
\end{itemize}
After having constructed $\mathcal D$ in this way, we can approximate $Q$ through fitting procedures.
\begin{boxclaim}{}{}
    How we roll out to estimate $y_i \approx Q^\pi(s_i, a_i)$ \textbf{determines the RL algorithm} we are using.
\end{boxclaim}

    \centering
    \includegraphics[width=\textwidth]{images/API.eps}
    \caption{The Approximate Policy Iteration (API) is a meta-algorithm/family of methods that uses an approximation of $Q^\pi$ defined by the data generated by the roll-in and roll-out phases. The way we estimate $Q^\pi(s_i, a_i)$ during the roll-out phase \textbf{specifies} the specific algorithm.}
\end{figure}
\subsection{The Roll-In Phase}
The roll-in phase is shared among all the methods of the API family.
Let $\pi$ be a given policy, the \textbf{discounted visit distribution} $d_{s_0}^\pi$ describes the probability (weighted in time) that the agent is in state $s$ and performs action $a$ during its trajectory with the policy $\pi$, starting from $s_0$:\begin{equation}
    d^\pi_{s_0}(s, a) = (1 - \gamma) \sum_{h=0}^\infty \gamma^h \mathbb{P}^\pi_h(s, a\mid s_0)
\end{equation}
with $\mathbb{P}^\pi_h(s, a\mid s_0)$ being the exact probability of being in the pair $(s, a)$ at time step $h$, starting from $s_0$ and choosing the actions according to the policy $\pi$. When the initial state is sampled from $\mu_0$, the distribution becomes $d^\pi(s,a)=\VA_{s_0\sim\mu_0}\left[d^\pi_{s_0}(s,a)\right]$, which is the ideal distribution from which to sample the training data.
\subsubsection{Sampling from $d^\pi$}
\begin{itemize}
    \item We \blueText{ sample } an integer $h\ge0$ from a geometric distribution with parameter $(1-\gamma)$, i.e. $\Prob(h=k)=(1-\gamma)\gamma^k$.
    \item We make the agent perform $h$ steps by using the policy $\pi$, starting from $s_0\sim \mu_0$.
    \item Once the agent reaches the $h$-th step, it is in the state $\tilde{s} = s_h$; we select the action $\tilde{a} \sim \pi(\cdot \mid s_h)$, then add the pair $(\tilde s,\tilde a)$ to the dataset. In this way $(\tilde s,\tilde a)$ is distributed exactly according to the theoretical distribution $d^\pi(s, a)$.
\end{itemize}
\noindent\blueText{\textbf{How to sample $h$}? } In practice, we sample a random number $u$ from a uniform distribution in $[0,1)$, and select:\begin{equation}
    h = \left\lfloor \frac{\ln(1 - u)}{\ln(\gamma)} \right\rfloor.
\end{equation}
\noindent The roll-in sample generation procedure is described in Algorithm \ref{alg:roll-in}.
\begin{algorithm}[H]
\caption{Roll-In of one sample}\label{alg:roll-in}
\begin{algorithmic}[1]
        \State $u\sim \text{Unif}[0,1)$
        \State $h=\left\lfloor \nicefrac{\ln(1 - u)}{\ln(\gamma)} \right\rfloor$
        \State $s_0\sim \mu_0$
        \For{$j=0,\dots, h-1$}
            \State $a_j\sim \pi(\cdot\mid s_j)$
            \State $s_{j+1}\sim p(\cdot \mid s_j,a_j)$
        \EndFor
        \State $a_h\sim \pi(\cdot\mid s_h)$
        \State \Return $(s_h,a_h)$
\end{algorithmic}
\end{algorithm}
\section{Roll-Out Methods}
\subsection{Monte-Carlo Method}
Let's see a method to perform the roll-out phase and estimate the labels: after having the sample $(\tilde s,\tilde a)$, we should find the label $y\approx Q^\pi(\tilde s,\tilde a)$. To get an unbiased estimation of $Q^\pi$, we sample many trajectories starting from the state-action pair $(\tilde s,\tilde a)$, collect the cumulative rewards of these trajectories and compute the average. The horizon is infinite, hence we use $\gamma$ again to randomly choose a horizon in the following way: at each time step, we terminate the current trajectory with probability $1-\gamma$.

\begin{itemize}
    \item Perform the following inner cycle for $j=1,\dots, M$.
    \begin{itemize}
    \item Starting from $\tilde s$, apply $\tilde a$ and collect the reward $r_0=R(\tilde s,\tilde a)$.
    \item Get $s'\sim p(\cdot\mid \tilde s,\tilde a)$.\begin{itemize}
    \item Continue by applying $\pi$ and collect the rewards $r_h$, for $h\ge1$.
    \item At each step, terminate with probability $1-\gamma$.\end{itemize}
    \item When the execution is terminated, $y_j=\sum_h r_h$ is collected (cumulative reward of the $j$-th execution).
    \end{itemize}
    \item Return the approximation $y=\frac{1}{M}\sum_{j=1}^My_j$.
\end{itemize}
$M$ is the number of trajectories/episodes that we use to compute the average cumulative reward.
Each time we execute the MDP, the step $h$ is reached with probability $\gamma^h$, hence $\VA[y_j]=\sum_{h=0}^\infty\gamma^h\VA[r_h]=Q^\pi(\tilde s,\tilde a)$. The roll-out procedure with the Monte-Carlo method is described in Algorithm \ref{alg:roll-out-MC}.

\begin{algorithm}[H]
\caption{Roll-Out (Monte-Carlo)}\label{alg:roll-out-MC}
\begin{algorithmic}[1]
    \State \blueText{\textbf{Roll-Out}}
    \State $\tilde y=0$
    \For{$j=1,\dots,M$}
        \State $s'\sim p(\cdot\mid \tilde s,\tilde a)$
        \State $r=R(\tilde s, \tilde a)$
        \While{true}
            \State with probability $1-\gamma$ exit the while loop.
            \State $a\sim \pi(\cdot\mid s')$
            \State $r=r+R(s', a)$
            \State $s' \sim p(\cdot\mid s',a)$
        \EndWhile
        \State $\tilde y=\tilde y+\frac{r}{M}$
    \EndFor
    \State\Return $\tilde y$
\end{algorithmic}
\end{algorithm}
\subsection{Temporal Difference Method}
Let's switch back to the assumption that the \textbf{state space is enumerable}; if the state space is not huge, why should we do approximation if we can rely on a table? We want to compute our estimate as a mean and update it with new data coming from the
agent's experience. 

The standard formulation of a mean:\begin{equation}
    \mu_k=\frac{1}{k}\sum_{j=1}^{k}x_j 
\end{equation}
can be rewritten with the \textbf{moving average}  formulation:\begin{align}
     \mu_k&=\frac{1}{k}\left(x_k+\sum_{j=1}^{k-1}x_j \right)=\frac{1}{k}\left(x_k+(k-1)\mu_{k-1} \right)\\ &=\mu_{k-1}+\frac{1}{k}(x_k-\mu_{k-1}).
\end{align}
In tabular form, we can update the current estimation of $Q$ as follows:
\begin{equation}
    \text{new estimation}\leftarrow \text{old estimation}+\alpha(\text{target}-\text{old estimation})
\end{equation}\begin{equation}
    Q(s,a)\leftarrow Q(s,a)+\alpha(y-Q(s,a)).
\end{equation}
In the Monte-Carlo (MC) method, the target is the real cumulative reward (so we have to wait for the end of the episode), whereas in the Temporal Difference (TD) method we exploit the Markov property and bootstrapping (i.e. we use an estimate to update another estimate). Instead of waiting for the end, the target is composed of the immediate reward $r$ plus the discounted estimated value of the next state $\gamma Q(s', \cdot)$.\begin{align}
    Q(s,a)& \leftarrow Q(s,a) + \alpha ( \underbrace{r + \gamma Q(s', \cdot) - Q(s,a)}_{\delta} )\\
    Q(s,a)& \leftarrow Q(s,a) + \alpha\delta.
\end{align}
The term denoted $\delta$ inside the brackets is called \textbf{TD error}:\begin{itemize}
    \item $r + \gamma Q(s', \cdot)$ (The Target): It is what we ``discover'' happened (the immediate reward obtained $r$ plus the discounted value of the next state based on our current knowledge).
    \item $Q(s,a)$ (The Prediction): It is what we expected to obtain by being in that state and performing that action.
    \item $\delta$ (The Error): It represents the surprise or discrepancy between the observed reality and our prediction.
\end{itemize}
When an agent uses the moving average update TD approach, it runs this loop at every single timestep (without having to end the episode):\begin{enumerate}
    \item The agent is in state $s$, selects and executes action $a$.
    \item The environment returns a reward $r$ and transitions the agent to the new state $s'$.
    \item The agent looks up in its table the current estimated value for the initial pair, namely $Q(s, a)$.
    \item The agent looks up the estimated value in the new state, namely $Q(s', \cdot)$.
    \item The agent computes the TD error ($\delta$) by comparing the old estimate with the new information ($r + \gamma Q(s', \cdot)$).
    \item The agent updates the entry $Q(s, a)$ in the table by shifting it by a small fraction $\alpha$ in the direction of the error.
\end{enumerate}
\begin{boxobservation}{}{}
    The dot ($\cdot$) inside $Q(s', \cdot)$ represents a generic action in the next state $s'$. In simple words, $Q(s', \cdot)$ indicates the value of the function $Q$ calculated in the state in which the agent will find itself immediately after ($s'$). The real fundamental question, however, is: what action do we choose in state $s'$ to calculate that value? The specific choice of action to consider \textbf{defines the specific reinforcement learning algorithm} we are using (for example, SARSA or Q-Learning).
\end{boxobservation}
\section{Q-Learning and SARSA}
Up to now we have seen how the approximate policy iteration defines a family of methods, which are then specified by the way the roll-out is performed. In detail, if the state space $S$ is huge or not countable we can use the Monte-Carlo method to estimate $Q$, but if $S$ is countable and not huge we can use a tabular format and perform the updates with the temporal difference method. For the latter case, the way in which the generic action for $Q(s',\cdot)$ is selected defines two algorithms, Q-Learning and SARSA.
\subsection{$\epsilon$-Greedy Exploration}
In the next section we will describe the difference between Q-Learning and SARSA, essentially in one algorithm the next action to be performed depends on the current estimate of $Q$, while in another it depends on the current policy $\pi$. In both cases, rather than selecting the best action (according to one of the two criteria), it is possible to make the agent select a random action with a certain probability. Let $\epsilon\in (0,1)$\begin{itemize}
    \item With probability $1-\epsilon$ we choose the greedy action (the best action).
    \item With probability $\epsilon$ we choose a random action.
\end{itemize}
This handles the exploration-exploitation trade-off. Suppose there are $m$ actions and we are using a stochastic policy, the $\epsilon$-greedy policy is defined as follows:\begin{equation}
    \pi(a\mid s)=\begin{cases}
        \nicefrac{\epsilon}{m}+1-\epsilon &\text{if }a=\operatorname*{arg\,max}_{a_j}Q(s,a_j)\\
        \nicefrac{\epsilon}{m} &\text{otherwise}.
    \end{cases}
\end{equation}
What we do, is using a variable $\epsilon$, at each time step $h$ we set $\epsilon=\frac{1}{h}$, in this way, with $k\rightarrow\infty$ we visit all state-action pairs infinitely many times, and the policy converges to a greedy policy.
\subsection{Off-Policy and On-Policy}
\noindent How do we select the action in $Q(s',\cdot)$?
\begin{itemize}
    \item \textbf{Q-Learning} (Off-Policy): The target action is greedy with respect to $Q$, hence it is selected differently from the policy we execute.
    \item \textbf{SARSA} (On-Policy): The target action is selected according to $\pi$ (which can be $\epsilon$-greedy with respect to $Q$), i.e. it is the action that the agent will actually execute.
\end{itemize}
The complete procedures of the two methods are reported in Algorithm \ref{alg:Q-Learning} and Algorithm \ref{alg:SARSA}.

\begin{algorithm}[H]
\caption{Q-Learning}\label{alg:Q-Learning}
\begin{algorithmic}[1]
    \State initialize $Q(s,a)$ for each state-action pair arbitrarily. Let $Q(s^*,a)=0$ for all $a\in A$ if $s^*$ is a terminal state.
    \ForAll{episodes}
    \State choose an initial state  $s$
    \While{$s$ is not a terminal state}
    \State select an action $a$ for $s$ using the policy derived from the current $Q$ \quad\greenText{(e.g $\epsilon$-greedy)}
    \State perform $a$ on $s$ and observe $r=R(s,a)$ and the next state $s'$
    \State $Q(s,a)\leftarrow Q(s,a)+\alpha[
        r+\gamma\max_{a'} Q(s',a')-Q(s,a)
    ]$
    \State $s\leftarrow s'$
    \EndWhile
    \EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[H]
\caption{SARSA}\label{alg:SARSA}
\begin{algorithmic}[1]
    \State initialize $Q(s,a)$ for each state-action pair arbitrarily. Let $Q(s^*,a)=0$ for all $a\in A$ if $s^*$ is a terminal state.
    \ForAll{episodes}
    \State choose an initial state  $s$
    \State select an action $a$ for $s$ using the policy derived from the current $Q$ \quad\greenText{(e.g $\epsilon$-greedy)}
    \While{$s$ is not a terminal state}
    \State perform $a$ on $s$ and observe $r=R(s,a)$ and the next state $s'$
    \State choose the next action $a'$ for $s'$ using the policy derived from the current $Q$ \quad\greenText{(e.g $\epsilon$-greedy)}
    \State $Q(s,a)\leftarrow Q(s,a)+\alpha[
        r+\gamma Q(s',a')-Q(s,a)
    ]$
    \State $s\leftarrow s'$
    \State $a\leftarrow a'$
    \EndWhile
    \EndFor
\end{algorithmic}
\end{algorithm}
